# Agentic Design Patterns 中文翻譯（xindoo/agentic-design-patterns）

資料來源：[官方 README](https://github.com/xindoo/agentic-design-patterns/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

《Agentic Design Patterns》的中文翻譯倉庫，README 列出 21 個核心模式，從提示鏈、路由、並行、工具使用到記憶、RAG、人工參與、護欄及評估監控。它提供章節 Markdown、線上閱讀與術語表，是設計模式讀物，並非可直接啟動的 Agent 服務。

## 2. 對我有什麼用？

你有 Shell／Python 自動化經驗，可拿它當設計評審用的詞彙表。當任務變複雜時，先判斷是否真的需要路由或並行；需要人確認的環節，可讀 Human-in-the-Loop；要改善長期可靠度，可讀異常恢復、評估與監控。翻譯能降低理解門檻，但關鍵術語與做法仍可回查原文。

## 3. 使用情境

例如把客戶設定檢查做成 Codex 工作流程時，可用「工具使用」界定可執行的讀取動作，「人工參與」界定寫入前關卡，再用「例外處理」列出 API 失敗或部分成功時的復原方式。選一個實際流程畫出狀態與責任，而非盲目套用全部模式。

## 4. 我要怎麼用？

直接在 README 目錄點章節 Markdown 或進入其 GitHub Pages 網站。選當前流程最相關的兩三章閱讀，以術語表統一名詞，再將章中模式與你現有步驟逐一比對；若只要閱讀，無需安裝。倉庫另含 Jekyll／GitBook 發布設定，但一般讀者不需先建站；成果應是可討論的流程圖與檢查清單。

## 5. 值不值得研究？

有特定情境才有用：適合作為 Agent 設計參考，尤其在規劃人機交接與失敗復原時。它不是現成實作規格，導入前仍須依你的系統做小規模驗證。
