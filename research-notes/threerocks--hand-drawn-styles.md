# hand-drawn-styles｜GitHub 專案導覽

## 1. 這是什麼？

hand-drawn-styles 是手繪畫風提示詞配方庫，可接入 Codex 等 Agent。你描述要畫的內容並選擇畫風，它會把主題、動作、文字與比例填入對應配方，輸出可交給圖像模型的提示詞。README 目前列出 20 個編號畫風與 3.1 變體，共 21 套，包括極簡線條、蜡筆童塗、水墨、像素與繪本風格。它預設只產生提示詞，圖像生成仍由你選用的模型完成。

## 2. 對我有什麼用？

如果你反覆為筆記、教學或家庭故事製作風格一致的插圖，它能省去每次重新寫畫風描述的時間。你可以先挑一套適合的風格，之後只改場景與文字，保持系列作品的視覺方向一致。需要參考圖錨點的風格則要保留完整安裝包；單純複製幾段文字，可能無法得到相同效果。

## 3. 使用情境

- **教學圖解**：用極簡線條或小豆人風格畫多格說明。
- **家庭故事插圖**：挑選蜡筆、淡彩或繪本風格，讓多張圖保持相近氣質。
- **圖像模型試風格**：同一主題套用不同配方，比較哪一種最適合。
- **系列內容製作**：固定一種配方，持續替不同文章生成提示詞。

## 4. 我要怎麼用？

1. 依 README 下載 Release 的輕量 Skill 包，保留完整 hand-drawn 目錄；若從原始碼安裝，依 INSTALL.md 的方式處理。
2. 把目錄放到 Codex 的 Skills 位置，執行專案提供的 check_skill.py 驗證安裝與參考圖。
3. 告訴 Agent「用手繪風畫……」；若未指定風格，先從選單挑編號或名稱。
4. 取得最終提示詞後，交給自己慣用的圖像生成工具。若配方要求參考圖或分階段流程，照完整呼叫包操作。
5. 對系列作品固定風格、比例與關鍵角色描述，逐張檢查文字與人物一致性。

## 5. 值不值得研究？

**很適合經常做風格化插圖時實際使用。** 它把畫風整理成可重用配方，但仍需圖像模型和人工挑圖；若只偶爾生一張圖，直接下提示詞即可。
