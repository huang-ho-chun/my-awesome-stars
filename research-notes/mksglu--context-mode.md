# context-mode｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/mksglu/context-mode/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

降低 Agent 工具輸出占用上下文的 MCP 工具。把大量終端、檔案與搜尋結果先導到可查詢的環境，再把相關片段送回模型；不同宿主的 hooks、MCP 與路由支援程度各異。

## 2. 對我有什麼用？

你的工作常有很長的命令輸出和測試日誌；將資料索引後按需取用可能減少上下文占用。實用與否應以真實日誌確認，尤其要檢查嚴重錯誤是否被壓縮掉。

## 3. 使用情境

你常處理長測試日誌或大量檔案，若上下文經常被原始輸出塞滿，這類索引與擷取方式有實用性；先量測實際節省與遺漏。

選一份已知有錯誤行的伺服器日誌，讓 Agent 用工具先索引、再找出故障位置，比對直接閱讀全文是否漏掉關鍵訊息；特別檢查多輪查詢可否回到原始行。

## 4. 我要怎麼用？

按 README 先確認 Node.js 版本及對應宿主的安裝章節；Claude Code 可用 plugin，Codex 等環境需依 MCP／路由文件設定。安裝後用 doctor、stats、index、search 測試，再於真實任務比較 token 與完整性。

README 指出不同宿主的 hook 與 MCP-only 安裝能力不同；在 Codex 上應依其專屬章節確認實際路由，而不能照抄 Claude Code 的 slash command 用法。

## 5. 值不值得研究？

有特定情境才有用：當長日誌確實佔滿上下文，才值得加入中介層並驗證是否漏掉錯誤。
