# 詞光 Word Atlas

> 專案：[designfuchen/word-atlas](https://github.com/designfuchen/word-atlas)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是一款以圖像和情境學雅思單字的開源 App，收錄詞卡、英美發音、例句、練習與 FSRS 間隔複習。無需帳號，學習進度存在裝置上；repo 提供開源基礎版與資料集，線上網站可能有不同功能。

## 2. 對我有什麼用？

你可用插畫和例句建立詞義聯想，透過拼字、聽音與回憶練習鞏固單字。若你需要雅思或一般英文詞彙基礎，這比純字表更有吸引力。

## 3. 使用情境

適合每日定量背單字、考試詞彙練習、用視覺方式記憶容易混淆的字。偏口說或程式專用詞彙需求則可搭配別的資源。

## 4. 我要怎麼用？

先打開線上網站或看 README 預覽；若要使用開源版，在本機準備 Node.js 20+ 和 npm，依『本地運行』步驟啟動。開始前選每日學習量，定期用匯出功能備份本機進度，換裝置時再還原。

## 5. 值不值得研究？

有特定情境才有用。若你要系統化練雅思詞彙，值得試用；若只讀技術英文，可先收藏。
