# earshot｜GitHub 專案導覽

> 專案：https://github.com/Leonxlnx/earshot

## 1. 這是什麼？

earshot 是讓 Coding Agent 分析與製作音效的本機 CPU 工具，提供 CLI、Python API 與 MCP server。README 列出描述聲音、依文字比對與排序候選、尋找錄音片段、建立聲音時間線、檢查影片聲畫同步，以及用程式合成音效等功能。部分命令使用下載後的音訊模型，部分量測與音效庫命令不需模型。

## 2. 對我有什麼用？

製作影片或互動介面時，可讓 Agent 取得聲音的可檢查描述與時間點，協助找適合的音效、對齊畫面及檢查混音。它也能生成可調整的音效候選；最終音質與節奏仍需自己聆聽。

## 3. 使用情境

- 對多個音效檔按「鍵盤敲擊」等描述排序，挑出候選。
- 找出長錄音中的特定聲音片段並標記時間。
- 檢查產品短片的音效是否落在切鏡點附近。
- 用音效庫或 `forge` 產生新聲音，再與參考聲音 A/B 比較。

## 4. 我要怎麼用？

依 README 先安裝 `uv`，並讓 `ffmpeg`、`ffprobe` 位於 PATH。從 GitHub 安裝 `earshot[mcp]` 後，可用 `earshot doctor --fetch` 預先下載約 1.1 GB 的兩個模型；先以 `measure`、`describe` 或 `match` 測試自己的音檔。大量連續呼叫可用 MCP server，避免每次 CLI 啟動重載模型。選用 Gemini 聲音評論時需另外安裝可選功能並提供自己的金鑰。

## 5. 值不值得研究？

若 Agent 已參與影片或遊戲聲音製作，值得用少量素材試它的描述、搜尋與同步分析。README 也指出合成音效可能迎合自己的評分模型，因此不要只依工具分數判定品質，應保留人工試聽與客觀量測。
