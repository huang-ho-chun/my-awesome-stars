# ian-xiaohei-illustrations｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/helloianneo/ian-xiaohei-illustrations)；查閱日期：2026-09-16。

## 1. 這是什麼？

這是一個讓 Agent 把中文文章轉成「小黑」風格正文配圖的 Skill。它會先找文章中的核心觀點、認知轉折與可視覺化段落，規劃每張圖的主題與構圖，再生成圖片並檢查風格。它不是通用繪圖模型，也不是把每一段都機械式配一張圖。

## 2. 對我有什麼用？

若你要替技術筆記或 AI 協作文章做更容易理解的插圖，可以拿它試作；不過專案的固定風格未必適合嚴肅的工作報告。對你另一個更直接的價值是學它如何設計 Skill：用 `SKILL.md` 管流程，把風格、構圖、提示詞與 QA 分成按需讀取的資料，未來可套用到自己的技術圖解 Skill。

## 3. 使用情境

- **文章配圖**：對中文長文挑出幾個最值得畫的認知重點。
- **單一概念說明**：替抽象方法或前後對比做一張易懂的圖。
- **Skill 設計參考**：觀察它如何把視覺規格和檢查清單拆開，而不是複製小黑畫風。

## 4. 我要怎麼用？

1. README 的 [安裝說明](https://github.com/helloianneo/ian-xiaohei-illustrations#安装) 以 Codex Skill 為例：下載專案並放到 Codex 可讀取的 Skills 位置。
2. 先提供一篇短文章，要求**只做配圖規劃**，看它選出的 shot list 是否抓到真正重要的段落。
3. 確認規劃後再生成少量圖片；逐張檢查概念、文字標註、留白與畫風。若是工作技術圖，還要對照原文驗證關係是否正確。

## 5. 值不值得研究？

**有特定情境才有用。** 你寫中文文章或設計自己的插圖 Skill 時值得研究；若目前只需要準確的系統架構圖，直接用圖表工具更合適。
