# Umi-OCR 專案指南

來源：[官方 README](https://github.com/hiroi-sora/Umi-OCR/blob/HEAD/README.md)｜查閱日期：2026-09-16

## 1. 這是什麼？

免費離線 OCR 桌面軟體。README 列出截圖 OCR、批量 OCR、文件識別、忽略區域與 QR Code 等介面功能，也提供呼叫接口。它的定位是快速辨識和人工操作，而非完整知識庫。

## 2. 對我有什麼用？

你在 Windows 處理單張截圖、PDF 頁面或批次圖片時，可用它做第一輪文字擷取；離線使用也適合不宜上傳的個人材料。繁體、專名和手寫內容仍需人工校對。

## 3. 使用情境

先用一組掃描日記頁與印刷文件測試批量辨識，觀察行序、頁碼與錯字；把 OCR 結果另存，逐張與原檔對照，不直接覆蓋已確認的筆記。

## 4. 我要怎麼用？

依 README 的下載發行版連結選 Windows 版本，解壓後啟動圖形介面；試截圖 OCR 與文件識別，再設定語言和後處理。若要接 Python 自動化，再依 README 的接口章節確認服務啟動與呼叫方式。

## 5. 值不值得研究？

判斷能否納入正式流程時，先量測一批已知答案頁面的錯字率與漏行率，尤其觀察繁體中文、手寫姓名及標點。若批次輸出缺少可靠頁面對應，就把它定位為初步擷取工具，而非直接匯入 Vault 的來源。
