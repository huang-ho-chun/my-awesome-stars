# VibeVoice｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/microsoft/VibeVoice/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

語音 AI 專案，分成長音訊辨識、多人語音合成和串流合成等模型。

## 2. 對我有什麼用？

若需將訪談或會議音訊轉成文字，再整理到 Obsidian，ASR 方向可能有用；TTS 則偏朗讀和配音，與伺服器測試無直接關係。

## 3. 使用情境

先用已取得同意的短錄音測試辨識，對照人工逐字稿找出人名、專有名詞和說話者切換錯誤；不要直接把草稿當成事實。

## 4. 我要怎麼用？

README 把三種模型分列於 docs；先選 ASR 或 TTS 的對應文件，確認模型權重、環境和硬體，再依示例安裝與推論。輸出文字或音檔後，人工檢查品質與授權限制。

辨識結果可當逐字稿草案；涉及人名、數字與引用時應回聽原錄音，並記下無法辨認的片段供後續補查。

README 將 ASR、多人長語音 TTS、即時串流 TTS 分別連到不同模型文件。若目的是筆記轉錄，先只閱讀 ASR 文件，避免把三種模型的依賴和能力混為一談。

## 5. 值不值得研究？

有特定情境才有用：只有出現穩定的音訊處理需求，研究成本才有回報。
