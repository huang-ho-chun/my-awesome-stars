# Understand-Anything 專案指南

來源：[官方 README](https://github.com/Egonex-AI/Understand-Anything/blob/HEAD/README.md)｜查閱日期：2026-09-16

## 1. 這是什麼？

將程式庫分析成可瀏覽的互動知識圖，呈現檔案、函式、類別、依賴與文字解釋。README 也提到知識庫分析、變更影響和新成員導覽，並列出 Codex 等多個平台的安裝途徑。

## 2. 對我有什麼用？

你維護 Shell/Python 測試系統與報告流程時，可用圖譜辨認模組責任與呼叫關係。它提供導覽線索，但對業務語意和動態設定的判斷仍需回到原始碼與執行結果。

## 3. 使用情境

選一個中型自動化測試專案，請它回答某份報告從資料擷取到生成的路徑；再選一項設定修改，核對圖上影響範圍與實際程式碼。

## 4. 我要怎麼用？

README 的 Quick Start 先安裝相應 Agent 整合，再於專案內執行分析並開啟 Dashboard；它也提供 Codex 等平台的一行安裝方式。首次先在可複製的專案使用，檢查所建立圖譜檔、是否增量分析，以及資料是否適合交給所選模型。

## 5. 值不值得研究？

判斷它是否值得保留，關鍵是能否比 `rg` 與手動追程式更快回答具體問題，以及索引更新後是否仍準確。圖上的關係若來自靜態分析，對執行期載入與設定切換可能需要另外驗證。

**有特定情境才有用。**跨檔案理解有幫助；小專案或熟悉的腳本未必值得額外建圖。
