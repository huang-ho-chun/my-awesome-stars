# 3dcodeverse

> 專案：[gaoypeng/3dcodeverse](https://github.com/gaoypeng/3dcodeverse)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是 3D 程式化創作的研究專案，包含 3DCodeVerse Harness 與大型 3D 程式碼資料集。它讓 Agent 將目標拆解、呼叫 3D 工具，並根據執行與視覺結果迭代。

## 2. 對我有什麼用？

如果你之後想讓 Agent 產生 Blender、OpenSCAD、CadQuery 或 Three.js 作品，可用它了解可行的工作流程與評估方式。它偏研究框架，對一般影片或圖像需求的直接幫助有限。

## 3. 使用情境

適合研究 AI 生成 3D 場景、CAD 物件或可執行 3D 程式碼的人。對只想快速取得單一 3D 模型的使用者，入門成本較高。

## 4. 我要怎麼用？

先看 README 的 Harness 與 Dataset 介紹，再閱讀對應子資料夾文件，挑一個支援的 3D 工具試最小範例。執行前需確認該工具與模型服務的個別安裝、硬體及費用需求；README 沒有提供一鍵成品 App。

## 5. 值不值得研究？

可以先收藏，以後有明確 3D 自動化需求再研究。
