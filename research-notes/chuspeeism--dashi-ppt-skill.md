# dashi-ppt-skill 專案指南

來源：[chuspeeism/dashi-ppt-skill 官方 README](https://github.com/chuspeeism/dashi-ppt-skill/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

由 Agent 生成瀏覽器可編輯簡報與可輸出 PPTX 的 Skill。

## 2. 對我有什麼用？

你可能需要將測試趨勢或伺服器配置成果講給非技術同事；網頁編輯與 PPTX 匯出可縮短排版時間，數字仍須核對。

## 3. 使用情境

用一份去識別的效能比較資料製作五頁簡報：背景、方法、結果、風險、建議；在瀏覽器調整版面，再檢查匯出的圖表數字與文字是否能編輯。

## 4. 我要怎麼用？

README 提供 npx dashi-ppt-skill 的快速入口。先準備受眾、頁數、素材與資料，啟動生成流程；用網頁編輯控制台調整圖表與版面，需要投影片時再依說明匯出 PPTX 或 PDF。

README 說明產物可先在瀏覽器編輯，再匯出 PPTX 或 PDF；也有內建主題。若你要給主管審閱，先在網頁確認文字和圖表，再檢查 PPTX 的可編輯性。

## 5. 值不值得研究？

有特定情境才有用：有正式簡報交付時再投入，比日常 Markdown 報告更合適。
