# WordLink

> 專案：[orionsheep/wordlink](https://github.com/orionsheep/wordlink)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是以單字關係圖為核心的英語學習網站：把同義詞、近義詞、詞族與相似拼字連在一起，並提供測驗、分級閱讀和選用的 AI 家教。專案還附有 WordLink-Edge 模型訓練資料與流程，但一般學習不需碰模型部分。

## 2. 對我有什麼用？

你可以把技術閱讀遇到的新詞放在關係網中理解，再用測驗追蹤熟悉度；比逐個背單字更能看到詞義差異。也可從 CSV 建自己的單字書。

## 3. 使用情境

適合累積英文詞彙、比較容易混淆的詞、閱讀時即時查詞與複習。若你主要要練口說，需搭配其他工具。

## 4. 我要怎麼用？

先試 README 連結的線上 Demo。要自己部署需 Node.js 20+、Docker/PostgreSQL、安裝依賴、匯入字典與關係資料，再啟動本機網站；AI 聊天與故事生成另外需要相容的模型端點與金鑰。

## 5. 值不值得研究？

很適合你目前的英語學習方向，建議先試 Demo 的詞圖與測驗，確認是否適合自己的記憶方式。
