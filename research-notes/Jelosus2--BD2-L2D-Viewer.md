# Brown Dust 2 L2D Viewer｜GitHub 專案導覽

> 依 [專案 README](https://github.com/Jelosus2/BD2-L2D-Viewer) 於 2026-09-16 整理；著重用途與使用判斷。

## 1. 這是什麼？

這是一個網頁式角色動畫檢視器，讓使用者查看遊戲《Brown Dust 2》的 Live2D／Spine 角色動作。repo README 很精簡，只確認專案用途與回報問題的管道；它不是遊戲本體，也不是通用動畫製作軟體。

## 2. 對我有什麼用？

若你玩這款遊戲或想單純欣賞角色動畫，這個網站可以直接看相關動作。它與你目前的工作自動化、英文學習或知識整理沒有明顯關係，不需要為了 Star 而深入研究程式。

## 3. 使用情境

- **遊戲興趣**：搜尋角色並查看動畫表現。
- **視覺參考**：觀察角色動作與呈現方式，但不代表素材可任意再利用。
- **問題回報**：遇到顯示或功能問題時到 repo 開 Issue。

## 4. 我要怎麼用？

1. 從 repo 的 [專案首頁](https://jelosus2.github.io/BD2-L2D-Viewer/) 打開網頁，選擇角色查看動畫。
2. 若頁面功能或素材有問題，依 README 到 GitHub Issues 回報。
3. 因 README 沒有詳細本機安裝或開發教學，一般使用先走網站即可。

## 5. 值不值得研究？

**對我目前用途不大。** 除非你正在玩 Brown Dust 2 或研究角色動畫，否則它只是興趣收藏。
