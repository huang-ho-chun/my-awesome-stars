# qlib｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/microsoft/qlib)；查閱日期：2026-09-16。

## 1. 這是什麼？

Qlib 是面向量化投資研究的 Python 平台，提供資料準備、模型訓練、回測與研究流程範例。它服務的是要驗證投資因子與模型的研究者／開發者，不是直接告訴一般人今天買哪支股票的理財 App。README 有範例資料與快速開始路線，但實際市場資料品質和研究假設仍需自行把關。

## 2. 對我有什麼用？

你有 Python、自動化和資料分析經驗，若想學量化研究，可用 Qlib 練習如何把資料、預測、回測與評估串成可重複的實驗。對你目前的工作與家庭財務決策，它不是立即需要的工具，研究結果也不應直接當投資建議。

## 3. 使用情境

- **學習研究流程**：用範例資料跑一個完整實驗，理解輸入與輸出。
- **模型比較**：在同一資料集下比較不同策略，而非只看單次績效。
- **自建實驗**：有清楚市場、資料來源與評估方法後才擴展。

## 4. 我要怎麼用？

1. 依 README 的 Installation 建立適合的 Python 環境並安裝 `pyqlib`。
2. 使用 README 的範例資料與 Quick Start 跑通一個基準流程，閱讀產出的指標和報表。
3. 在理解資料時間範圍、交易成本與回測偏差後，再替換自己的資料或模型。

## 5. 值不值得研究？

**可以先收藏，以後可能用到。** 若你決定深入量化研究它很有價值；目前沒有明確投資研究題目時，學習成本較高。
