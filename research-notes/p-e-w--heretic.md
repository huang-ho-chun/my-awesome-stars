# heretic｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/p-e-w/heretic)；查閱日期：2026-09-16。

## 1. 這是什麼？

Heretic 是用來修改本機語言模型拒答／審查行為的研究工具。README 說它能自動處理模型，另有分析模型內部向量等研究選項；它屬於模型權重與行為研究，不是一般聊天介面，也不是讓 Codex 更會寫程式的 Skill。使用者需要自行處理模型、PyTorch 環境與輸出評估。

## 2. 對我有什麼用？

你目前主要需要可靠的 AI 協作、文件整理與自動化工作。改變模型的拒答行為並不能直接解決這些問題，還可能改變模型的品質與邊界；除非你未來要研究開源模型行為，否則沒有迫切用途。

## 3. 使用情境

- **模型行為研究**：比較修改前後的回覆分布與能力。
- **可解釋性實驗**：使用 README 的研究選項分析模型內部訊號。
- **本機模型測試**：在隔離環境用非敏感基準題評估結果。

## 4. 我要怎麼用？

1. 若確定有研究題目，先閱讀 README Usage 與模型授權，準備符合硬體的 Python／PyTorch 環境。
2. 只在測試模型上執行，保存原模型與可重現的評估題。
3. 比較修改前後的能力、錯誤與行為，再決定是否有研究價值；不要把改後模型直接當成更可靠的工作助理。

## 5. 值不值得研究？

**對我目前用途不大。** 它處理的是模型行為研究，與你現階段的實用工具需求距離較遠。
