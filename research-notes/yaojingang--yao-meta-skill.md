# yao-meta-skill 專案指南

來源：[yaojingang/yao-meta-skill 官方 README](https://github.com/yaojingang/yao-meta-skill/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

協助建立、檢查與更新其他 Agent Skills 的元技能。

## 2. 對我有什麼用？

README 提供 quickstart、來源掃描、品質檢查與更新指令。你有持續調整 Codex Skills 的需求，這些檢查流程可作為參考。

## 3. 使用情境

挑一個既有的 Obsidian 或測試相關 Skill，在副本跑檢查並記錄指出的缺口；人工決定哪些建議適合你的實際流程。

## 4. 我要怎麼用？

README 提供 npx skills add 的 Codex 安裝方式，安裝後先跑 quickstart 和 status 類指令；對單一 Skill 做解讀、基準與檢視。更新前先看 notice 與變更內容，避免自動覆蓋本地改動。

README 具體列出 install-status、quickstart、reference-scan、review-viewer 等指令。先在一份 Skill 副本做 quickstart 和檢視，再看是否要用更完整的掃描流程。

## 5. 值不值得研究？

有特定情境才有用：需要系統性維護多個 Skills 時值得試，單一簡單 Skill 可手動檢查。
