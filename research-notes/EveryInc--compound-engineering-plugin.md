# Compound Engineering｜GitHub 專案導覽

> 依 [專案 README](https://github.com/EveryInc/compound-engineering-plugin) 於 2026-09-16 整理；著重用途與使用判斷。

## 1. 這是什麼？

Compound Engineering 是一套給 AI Coding Agent 的 Skills 與工作流程，核心想法是每完成一項工程工作，就把新理解、評審和可重用規則回饋到後續工作。README 提供不同 Agent 的安裝方式，包含 Codex。它是一組開發協作方法與外掛，不是新的程式語言或 CI 平台。

## 2. 對我有什麼用？

你常用 Codex 在多個專案中做診斷、實作、檢查和文件整理。這套流程可能幫你把反覆出現的錯誤與決策留下來，讓下一次任務更省力；但若全部 Skills 一起套在小修正上，可能增加不必要的步驟。

## 3. 使用情境

- **持續開發**：在一個長期專案中讓計畫、實作與回顧互相接續。
- **重複問題**：將常見錯誤與修正方式寫回可用規範。
- **團隊試用**：選幾個對現有流程有幫助的 Skills，比較採用前後。

## 4. 我要怎麼用？

1. 先讀 README 的 Philosophy、The loop 和 Skills 清單，選一個真正與當前痛點有關的 Skill。
2. 依 Codex App 或 Codex CLI 的 Install 指南安裝到測試專案，不必一次改所有專案。
3. 用一個跨多步的真實任務試跑，檢查輸出、時間和新增文件是否值得保留。

## 5. 值不值得研究？

**有特定情境才有用。** 長期、重複的工程工作可能受益；簡單任務不一定需要完整流程。
