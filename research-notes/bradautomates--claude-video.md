# claude-video 專案指南

來源：[bradautomates/claude-video 官方 README](https://github.com/bradautomates/claude-video/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

讓 Coding Agent 讀取影片字幕與畫面的 /watch Skill。透過字幕、抽影格及影像分析讓 Agent 回答影片內容問題；README 列出 yt-dlp、ffmpeg、不同宿主安裝方式與影格預算限制。

## 2. 對我有什麼用？

從技術影片找關鍵段落時，可以先讓 Agent 摘要字幕和抽樣畫面，節省完整重看的時間。需要精確操作步驟時仍要回看片段，因為抽影格不等於完整影片理解。

## 3. 使用情境

你若要從技術教學影片擷取步驟，能先得到帶時間點的摘要，再回原片核對；但它不是完整逐格理解，也不保證每部影片可取得字幕。

選一支公開的伺服器教學影片，要求列出關鍵操作和時間點；抽查三段原片，標記影片中未說清的指令與條件，再決定是否整理到 Obsidian。

## 4. 我要怎麼用？

Codex 可依 README 以 npx skills add 安裝；首次執行前確認 yt-dlp、ffmpeg 與必要 Python 依賴，Windows 需按提示補裝。提供可存取影片連結、指定問題和細節程度，取得摘要後回看片段驗證。

README 區分字幕與抽影格兩種取材方式，並說明影格預算和細節模式會影響觀察範圍。第一次使用可問一個有明確答案的片段問題，再檢查時間點與畫面。

## 5. 值不值得研究？

有特定情境才有用：若常從技術影片學習可節省找段落時間，精確步驟仍要看原片。
