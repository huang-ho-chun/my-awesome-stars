# OmniGet｜GitHub 專案導覽

> 專案：https://github.com/OpenSelena/omniget

## 1. 這是什麼？

OmniGet 是 Windows、macOS 與 Linux 的開源桌面下載與媒體管理工具。README 描述的主要流程是貼上連結、預覽可用畫質、加入下載佇列，再於應用程式中管理檔案。它以內建擷取器及 yt-dlp 處理課程、影片、音訊、圖片集等來源，並整合 FFmpeg、播放器、轉錄與其他媒體工具。不同站點的可用功能會受來源網站、登入狀態與實際版本影響。

## 2. 對我有什麼用？

若常從自己可存取的課程或社群頁面保存媒體，可用單一桌面介面處理網址、品質選擇、排隊、續傳與檔案整理，減少反覆記 yt-dlp 參數的負擔。下載後的播放與轉錄工具，也讓素材進一步整理成筆記更方便。

## 3. 使用情境

- 保存已獲授權觀看的課程章節與附件，供離線學習。
- 將影片、播放清單或音訊加入佇列，依需求選擇畫質、字幕與輸出資料夾。
- 對已下載的錄音或影片進行轉錄，作為後續整理重點的素材。
- 在需要網站登入狀態時，選用 README 所述的瀏覽器擴充功能傳送頁面與 cookies；先理解所授予的權限及資料流向。

## 4. 我要怎麼用？

1. 從專案的 [Releases](https://github.com/OpenSelena/omniget/releases/latest) 選擇作業系統版本；Windows 10／11 有安裝版、可攜版與 MSI。
2. 首次啟動時依設定畫面選擇語言、主題，並安裝 README 所述的 yt-dlp 與 FFmpeg 元件。
3. 先用一個自己有權保存的公開連結測試：貼到首頁，檢查預覽、畫質及儲存位置，再開始下載。
4. 如要下載登入後的內容，閱讀擴充功能的安裝及 cookies 說明，確認帳號權限和來源服務的使用條款後再啟用。

README 描述許多外掛及工具，其中部分標示為 beta；特定網站的擷取成功率應以當下版本與自己的來源實測。下載內容仍須遵守著作權及服務條款。

## 5. 值不值得研究？

如果需要跨站下載與整理大量影音，值得先用少量、合法可存取的內容測試佇列、字幕與續傳是否適合工作流程。它的功能範圍很廣，評估時應先聚焦常用的兩三種來源，並留意登入資料、擴充功能權限及外部下載元件的更新方式。
