# 自學是門手藝（selfteaching/the-craft-of-selfteaching）

資料來源：[官方 README](https://github.com/selfteaching/the-craft-of-selfteaching/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

李笑來的開放閱讀教材，透過 Python、Jupyter Notebook 和寫作練習說明如何建立自學能力。README 同時提供 Notebook 與 Markdown 版本，章節從閱讀、程式基礎到練習與輸出。核心是「學習後創作與實作」，不是一個要安裝進現有工作流程的軟體工具。

## 2. 對我有什麼用？

你已用程式解決實務問題，這本書對 Python 語法本身可能太入門；有價值的是用小作品驗證學習、把學到的知識整理成可重用筆記。你有 Obsidian，可把閱讀後的具體問題、親手測試和下一步記在同一則筆記中，而非只摘抄觀點。

## 3. 使用情境

例如學一項新伺服器設定時，先寫下你目前不懂的兩個行為，再照官方文件做最小測試，保存命令、結果和錯誤訊息；最後寫一份能讓同事重做的簡短說明。這符合書中強調的閱讀、練習與創作循環，也能形成可轉移的工作成果。

## 4. 我要怎麼用？

可先在 GitHub 開啟 `markdown/` 直接閱讀；若想操作書中 Notebook，依 README 提示先讀 JupyterLab 安裝與設定附錄，再逐章開 `.ipynb` 執行。閱讀每章後選一個小練習自己完成，對照 Notebook 輸出與文字說明。README 沒有一鍵完成的統一安裝程式，Jupyter 只是互動閱讀的一種方式。

## 5. 值不值得研究？

可以先收藏，以後可能用到：適合回顧自己的學習方式；對你目前的程式技能，內容可能較基礎。
