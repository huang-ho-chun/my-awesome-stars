# effective-html｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/plannotator/effective-html)；查閱日期：2026-09-16。

## 1. 這是什麼？

effective-html 是一組教 Coding Agent 製作 HTML 說明成品的 Skills。它把 HTML 當成溝通媒介：用圖解、線框圖、計畫或可操作原型呈現資訊，讓人可以在瀏覽器看見流程與狀態。它不是前端框架，也不是要求每個問題都做網站；只有文字難以講清楚時才值得使用。

## 2. 對我有什麼用？

你常要釐清測試流程、報告產生鏈與方案差異。這套 Skills 可以讓 Codex 把抽象討論轉成一個可打開的頁面。例如先以 `html-diagram` 呈現測試資料如何進入 Markdown 和 PDF，再用 `html-prototype` 試做一個結果瀏覽器，讓你先看操作方式再決定是否實作。

## 3. 使用情境

- **流程與架構說明**：用 `html-diagram` 看步驟、資料流與相依性。
- **UI 構想**：用 `html-wireframe` 先檢查資訊順序，或用 `html-prototype` 試一條可點擊流程。
- **計畫比較**：把選項、狀態或時程放在 `html-plan`，方便與文字需求一起討論。

## 4. 我要怎麼用？

1. 按 README 的 [Install](https://github.com/plannotator/effective-html#install) 安裝整組 Skills；也可只裝一個需要的 Skill，或使用專案列出的 Codex plugin 方式。
2. 給 Agent 一個具體題目、受眾和想看清的關係，例如「把報告流程做成可開啟的 HTML 圖解」。
3. 在瀏覽器實際打開成果，檢查內容、互動、手機與桌面版的可讀性；需要修正時直接指出哪個流程或狀態不對。

## 5. 值不值得研究？

**很適合你試用。** 當你需要比較方案、看流程或預覽工具介面時，它能讓討論更具體；短問題仍用一般文字回答即可。
