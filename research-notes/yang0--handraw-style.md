# 手繪風格提示詞庫（yang0/handraw-style）

資料來源：[官方 README](https://github.com/yang0/handraw-style/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

以編號管理手繪風格的 Agent Skill 與圖片畫廊。README 說明可先從畫廊選風格，再輸入「編號＋主題」取得中英文提示詞；預設只幫你寫提示，明確要求生圖時才評估是否附上該編號參考圖。它將風格選擇具體化，方便反覆使用同一視覺方向。

## 2. 對我有什麼用？

你已有圖像生成需求，這種編號方式能降低描述畫風的成本，也方便在多張輸出間維持相近風格。對 Obsidian 筆記或家庭影像的插圖可當創意素材；但生成結果仍要檢查主體是否被參考圖帶偏，尤其不能把畫廊中的人物或場景誤當成你要保留的原始照片。

## 3. 使用情境

例如你要替一篇自我學習筆記配圖，先看畫廊選一個簡潔風格編號，描述真正要畫的概念，再查看 Skill 產生的中英文提示。先試一張，確認圖像表達內容與畫風，再批次用在同組筆記；若需要轉換現有照片，另需明確提供原圖與主體保留要求。

## 4. 我要怎麼用？

按 README 的安裝說明選整個倉庫根目錄 `.`，不要只安裝子資料夾，因為畫廊與參考圖也在根目錄。安裝後開 `handdraw-style-prompter/gallery/index.html` 看編號，輸入如「041 號風格，主題：……」取得提示，複製到可用的生圖工具。若要求直接生圖，再檢查是否需要該編號單張參考圖以及輸出是否保留自己的主題。

## 5. 值不值得研究？

有特定情境才有用：當你連續製作插圖時能提高風格一致性；平日工作文件未必需要。
