# diagram-design｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/cathrynlavery/diagram-design/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

提供多種編輯式圖解類型與視覺規則的 Agent Skill。

## 2. 對我有什麼用？

適合把測試流程、決策路徑或系統架構做成較清楚的對外說明圖；與 archify 相比，重心較偏版型、品牌與可讀性。

## 3. 使用情境

將一段已定稿的故障處理流程交給 Skill 產出流程圖，核對分支、文字與配色對比；若要給主管看，確認縮小後仍能讀懂。

## 4. 我要怎麼用？

README 提供 Codex plugin marketplace 安裝方式，也有可編輯安裝。安裝後以一個具體圖表請求開始，必要時做品牌樣式 onboarding；查看圖形、對比度與輸出格式，再修正內容。

README 有可開啟的圖形畫廊，也提供架構圖、四象限與序列圖等示例。先從畫廊挑適合資訊型態的圖，再提供品牌樣式和內容，避免只憑圖名猜版型。

## 5. 值不值得研究？

有特定情境才有用：需要高品質圖解時很合適，日常文字筆記不必每次套用。
