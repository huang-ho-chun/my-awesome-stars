## 1. 這是什麼？

Awesome-Quant-Machine-Learning-Trading 是量化交易與金融機器學習的學習資源清單。它彙整書籍、課程、影片、部落格、訪談、論文、強化學習環境及程式碼，並標記作者特別推薦的項目。這個 repository 本身不提供交易系統、即時行情、回測平台或投資建議；它是尋找下一份學習材料的索引。

## 2. 對我有什麼用？

如果你想理解機器學習如何用在金融資料與交易研究，可以從這裡建立閱讀清單，按「基礎概念 → 方法 → 實作」逐步挑來源。你也可用它比較不同課程與開源程式的主題，再決定是否要進一步試 qlib 等工具。

清單中部分連結與內容可能已較舊，應逐項確認是否仍可存取、作者是否更新，以及方法是否有可信的樣本外檢驗。收藏這份清單不等於已有可用策略，不能直接依列出的研究結果投入資金。

## 3. 使用情境

- **自學路線**：先挑一本基礎書及一門課，建立金融資料與模型概念。
- **論文查找**：按事件、情緒或強化學習等主題找研究入口。
- **工具比較**：從程式碼清單找到可試的資料處理與回測專案。
- **研究筆記**：記錄每項來源的日期、方法、資料、限制與重現結果。

## 4. 我要怎麼用？

1. 打開 README 的分類，先選一個具體問題，例如「如何避免回測過度擬合」。
2. 挑一到兩項書籍或課程作基礎，再追查相應論文與程式碼。
3. 對每個連結確認內容是否仍有效、是否有新版本與公開可重現資料。
4. 若想做實驗，先在不涉及實際交易的資料集上重現方法，記錄假設、費用及失敗情況。
5. 有確切研究題目後，再選擇專門工具，不必把清單中的所有資源逐一讀完。

## 5. 值不值得研究？

**可以先收藏，等有明確量化研究題目時使用。** 它能節省找資料的時間，但不是現成的獲利方法；目前若重點是個人理財記錄，與你的直接需求關聯較低。
