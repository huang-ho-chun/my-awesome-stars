# PDFMathTranslate｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/PDFMathTranslate/PDFMathTranslate/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

面向學術與技術 PDF 的翻譯工具，目標是保留原文件的版面、公式和圖表位置。README 提供命令列、Web 介面與 Docker 路徑；OCR 模式另列為實驗功能。

## 2. 對我有什麼用？

讀英文規格書或論文時，可先得到較容易閱讀的翻譯版，再回查原文術語、數值與公式。它適合輔助閱讀，不宜把譯文當成唯一權威資料。

## 3. 使用情境

找一份有公式、表格、雙欄的非機密英文 PDF，檢查翻譯後的頁面對齊、公式、參照與關鍵技術名詞。若要引用，記錄原 PDF 頁碼。

## 4. 我要怎麼用？

依 README 以 `uv tool install --python 3.12 pdf2zh` 或 pip 安裝，從一份測試 PDF 使用 CLI 處理；偏好介面則按 README 啟動網頁服務，Docker 也有示例。先查所選翻譯服務的模型、金鑰與資料送出位置。

## 5. 值不值得研究？

評估時把原文和譯文一起保存，挑十個關鍵句、公式及數值逐一比對。對保密文件先查清翻譯後端是否將內容送往外部；如果資料不可外傳，就先停在合適的本機模式或改用人工閱讀。

**有特定情境才有用。**英文 PDF 密集閱讀時省力，平常整理中文私人資料不需要常開。
