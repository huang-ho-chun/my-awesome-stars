# ReelMimic

> 專案：[edenfunf/reelmimic](https://github.com/edenfunf/reelmimic)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是以參考影片為起點的 AI 動畫製作工具：拆解鏡頭、節奏、色彩等特徵，先產生可討論的企劃，再由多個 Agent 製作與審查新作品。它在本機運行，使用自己的 Codex 或 Claude Code 帳號；不直接複製原影片素材。

## 2. 對我有什麼用？

你可拿喜歡的解說動畫或短片當風格參考，換成自己的主題、角色與腳本。對需要定期製作同風格內容的人很有幫助，但製作時間與模型額度都不低。

## 3. 使用情境

適合原創 2D 動畫、解說片與風格試作。README 說明目前只支援 2D，不做真人實拍；30–60 秒成片可能需數小時。

## 4. 我要怎麼用？

準備 Node.js 22.18+、Python 3.10+、FFmpeg、Chrome 與已登入的 Codex CLI 或 Claude Code；Windows 使用 repo 的 `install.bat`、`start.bat`，打開本機網頁。上傳參考影片或貼連結，提出新片需求，審核分鏡與素材計畫後開始製作，最後逐秒留言修改。

## 5. 值不值得研究？

有特定情境才有用。若你要做原創風格動畫值得試短樣片；若只想快速剪輯現有影片，流程過重。
