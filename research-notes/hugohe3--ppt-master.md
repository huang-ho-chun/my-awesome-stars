# PPT Master｜GitHub 專案導覽

> 依 [專案 README](https://github.com/hugohe3/ppt-master) 與相關文件於 2026-09-16 重寫；著重用途與使用判斷，不深入原始碼。

## 1. 這是什麼？

PPT Master 是讓具備讀寫檔案與執行命令能力的 AI Agent 製作 PowerPoint 的專案。它從資料、文件或主題規劃簡報內容與視覺，目標是產生可在 PowerPoint 繼續編輯的 PPTX，而非僅把整頁圖片塞進投影片。它比較像一套 Agent 工作流程與產生工具，不是只需打開網頁的簡報服務。

## 2. 對我有什麼用？

你有測試數據、技術報告與可能要對主管說明的成果。你可讓 Agent 先讀報告，再規劃「目的 → 方法 → 結果 → 判斷 → 建議」的簡報，產出後自己調整文字或圖表。另一個適合你的用途是把既有技術文章或教學資料轉成可講解的投影片。

## 3. 使用情境

- **工作報告**：把效能測試與比較結果整理成管理者能閱讀的簡報。
- **教學分享**：把長文件或技術文章轉成有故事線的投影片。
- **公司模板**：在有既定版型時，嘗試依模板產生內容；需額外檢查格式是否真的保留。

## 4. 我要怎麼用？

1. 依 README 的 [Quick Start](https://github.com/hugohe3/ppt-master#quick-start) 準備 Python 3.10+ 與一個可操作檔案的 Agent。你在 Windows 上可先看專案的 [Windows 安裝指南](https://github.com/hugohe3/ppt-master/blob/main/docs/windows-installation.md)。
2. 下載或複製專案並安裝相依套件，在 Agent 中開啟專案資料夾。
3. 放入一份來源文件或直接貼上內容，明確指定聽眾、頁數、要保留的數據與結論；先確認 Agent 提出的簡報規格。
4. 取得 PPTX 後在 PowerPoint 逐頁打開，核對內容、圖表、文字溢出和物件可編輯性。

## 5. 值不值得研究？

**有簡報需求時很值得實際試。** 它與你的報告工作有交集；若只是偶爾做兩三頁簡單說明，安裝與檢查成本可能高於手動製作。
