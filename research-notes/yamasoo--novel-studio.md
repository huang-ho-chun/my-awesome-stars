# 小說工作台 Novel Studio｜GitHub 專案導覽

> 來源：[yamasoo/novel-studio](https://github.com/yamasoo/novel-studio) README；查閱日期：2026-10-27。

## 1. 這是什麼？

小說工作台是協助寫**繁體中文長篇連載小說**的本機網頁工作台。小說的設定、大綱、章綱、正文與追蹤資料保存在 Markdown 和 YAML 檔；網頁介面負責管理書庫與流程，AI 可選 Claude Code、DeepSeek、llama.cpp 或其他 OpenAI 相容服務。它的重點是讓長篇作品中的人物狀態、時間線、伏筆與已定稿事實有地方可追，而不只是叫模型「寫下一章」。

它提供開書訪談、章節候選稿、審查與逐段修訂、設定集、插圖、舊稿匯入及 EPUB/TXT 匯出等功能。寫作時先產生候選稿，作者審閱採用後才移入正文並回寫追蹤資料。

## 2. 對我有什麼用？

如果你想寫長篇故事，或已有分散的 TXT、Markdown、Word 草稿，可以用它建立一個能持續追蹤角色與伏筆的專案。候選稿與正文分開、審查先列意見、修訂對照由你選擇套用，能讓你保有定稿權。你也可以觀察它如何把複雜的 AI 工作流程拆成可停下、可恢復的步驟，作為其他創作工具的設計參考。

若你目前主要寫短文或筆記，整套角色、章綱與追蹤系統可能過重，先看示範書即可。

## 3. 使用情境

- **長篇連載**：安排全書、卷與章節大綱，追蹤角色狀態及尚未收束的伏筆。
- **舊稿整理**：匯入既有章節，預覽拆章結果，再補建設定與追蹤資料。
- **人機協作改稿**：生成候選稿、檢查章綱、查看審查意見，逐段比較原稿與修訂稿後採用。
- **成書輸出**：把已定稿章節與選定資料匯出為 EPUB 或 TXT。

## 4. 我要怎麼用？

README 指出需要 Python 3.9+；若選 Claude Code，還需先安裝並登入。下載或 clone 專案，Windows 執行 `start.bat`（macOS/Linux 為 `./start.sh`），首次啟動會建立虛擬環境並安裝依賴，然後在本機 `http://127.0.0.1:8765` 開啟介面。先選書庫資料夾，按「加入示範書」看流程，再用一個短篇測試章綱、候選稿與採用。

若使用 DeepSeek 等服務，到設定頁配置模型端點和金鑰並測試連線；本機模型也可透過相容端點使用。大批量「整章自動」流程先在短章與非正式作品測試，檢查生成品質、費用估算及追蹤回寫結果。插圖功能另需配置 Forge Neo 或 ComfyUI，純文字寫作不用先處理。

## 5. 值不值得研究？

**有長篇小說計畫時很適合試用。** 它把定稿、連續性與人工審閱放在流程中心；如果只是偶爾請 AI 寫短文，先收藏即可。
