## 1. 這是什麼？

lanshu-create-ai-presenter-video 是一個 Agent Skill，帶 Codex 等程式代理走完解說影片製作流程。它有兩條路線：用已取得使用權的人像製作數位主持人影片，或不用主持人、改用九種畫面風格製作解說動畫。輸入可以是主題或已寫好的講稿。

它會安排腳本、旁白、畫面、字幕、剪輯、輸出與品質檢查。主持人路線需選用能產生語音、人物影片與對嘴內容的服務；風格化解說路線可用 MiniMax 配音，也可提供自己的旁白。專案本身是製作流程與腳本集合，不是直接開啟就能用的影片編輯 GUI，也不內建所有付費生成服務。

## 2. 對我有什麼用？

如果你想把已整理好的知識筆記、工具介紹或教學稿轉成短影片，可以讓 Codex 依固定步驟做出試片，檢查腳本、聲音與畫面後再產出正式影片。用自己的旁白製作無主持人的風格化解說，可以先避開數位人像與部分語音生成成本。

它特別適合需要多次製作同類解說片的情況：產製狀態以檔案證據確認，旁白時間軸作為字幕與畫面切換依據，成片還會做解碼和音量檢查。這些步驟有助於減少「檔案生成了卻不能正常播放」的情況。若你目前只是要快速剪輯家庭影片，這套流程會顯得較重。

## 3. 使用情境

- **工具教學**：把一篇 GitHub 專案介紹改寫成 45–75 秒的概念解說片。
- **知識筆記分享**：將已確認內容做成字幕、圖像與旁白同步的影片。
- **數位主持人**：在擁有人像使用權、願意配置生成服務時，製作有人物出鏡的直式短片。
- **無主持人動畫**：從九種風格選一種，將抽象概念演成畫面。
- **批次內容流程**：對每支影片先做試片、核對成本，再輸出經播放與音量檢查的版本。

## 4. 我要怎麼用？

1. 準備 Python 3.9 以上、FFmpeg/ffprobe，以及 README 列出的 Bash、jq、awk、sed 等命令。風格化解說路線另需 Node.js、rsync、numpy。Windows 使用前先確認這些命令在所選終端或 WSL 中可用。
2. 依 README 將倉庫安裝到 Codex 的 Skills 目錄；在 Codex 呼叫 `$lanshu-create-ai-presenter-video`。
3. 提供主題或講稿，選擇「數位主持人」或「風格化解說」。主持人路線要提供已授權的成年人人像；後者可提供自己的旁白，或設定所需的語音服務。
4. 先確認腳本、風格、長寬比及是否會使用付費服務，再讓 Skill 製作試片。檢查字幕、語音、畫面和時間點，必要時修改。
5. 確認試片後完成正式輸出，檢查最終影片能完整解碼、音量合適，再發布或分享。

若只是想體驗，建議先用短主題、無主持人路線和自備旁白，減少人像與生成服務的準備工作。

## 5. 值不值得研究？

**有持續製作知識解說影片的情境才值得投入。** 它涵蓋從講稿到驗證成片的完整流程，適合重視品質與可重複製作的人。初次設定所需工具與服務較多；如果只做一支簡單影片，現成剪輯工具可能較快。
