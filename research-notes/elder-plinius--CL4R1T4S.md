# CL4R1T4S 專案指南

來源：[elder-plinius/CL4R1T4S 官方 README](https://github.com/elder-plinius/CL4R1T4S/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

蒐集各種 AI 服務與 Agent 系統提示、指引和工具定義的資料庫。

## 2. 對我有什麼用？

可用來了解不同產品如何約束 Agent 行為與工具使用；它不是可直接安裝的 Agent 框架，來源與版本亦需逐筆判斷。

## 3. 使用情境

讀一份與你常用的 Coding Agent 有關的提示資料，整理明確的限制與可借鏡規則；回到該產品官方文件確認仍適用。

## 4. 我要怎麼用？

在 GitHub 瀏覽目錄及感興趣的提示檔案，記下來源與擷取時間，對比官方公開文件；若要建立自己的規範，僅抽取一般設計原則，不把未驗證內容當成產品保證。

其內容包含擷取與轉載材料，可靠性和時效性各異，閱讀時應避免推論目前產品一定依照同一套提示運作。

README 要求貢獻內容附模型版本、擷取日期與背景資訊；這也提醒讀者，同一服務在不同時期可能有不同提示。查資料時應先看檔案來源和時間。

## 5. 值不值得研究？

可以先收藏，以後可能用到：適合做 Agent 行為研究，對目前的測試管線沒有直接操作價值。
