# Concat｜GitHub 專案導覽

> 來源：[jub0t/Concat](https://github.com/jub0t/Concat) README；查閱日期：2026-10-26。

## 1. 這是什麼？

Concat 是免費、開源、以本機處理為主的影片剪輯軟體，定位為 CapCut 的替代選擇。它提供多軌剪輯、字幕、文字轉語音、去背、關鍵影格、特效、標題與最高 4K 輸出。桌面介面之外，另有 MCP 伺服器與 JSON-RPC API，讓腳本或 Agent 操作剪輯流程。README 表示素材留在本機，字幕與語音模型可先下載再離線使用。

## 2. 對我有什麼用？

若你需要製作短影片、教學錄影或 Podcast 片段，可以用一套不需帳號與訂閱的工具完成基本剪輯、字幕和輸出。若未來想把影片工作納入 Agent 流程，它的 MCP 介面值得研究，例如讓 Agent 協助整理片段或設定剪輯步驟；正式成果仍應人工預覽。

## 3. 使用情境

- 剪輯社群短片、教學影片與螢幕錄影。
- 為口語內容產生並調整字幕、清理人聲。
- 對重複性剪輯任務嘗試腳本或 Agent 操作。

## 4. 我要怎麼用？

在 [官方下載頁](https://concatenate.pages.dev/#download) 或 [GitHub Releases](https://github.com/jub0t/Concat/releases) 選 Windows x86_64 等對應版本，安裝後匯入素材，先試分割片段、加標題與輸出一段短片。要用字幕、語音或去背，再到設定下載相應模型。若要接 Agent，再依 `docs/MCP.md` 設定 `concat --mcp`；一般剪輯無須碰 API。專案目前仍標示 beta，重要影片先用短樣本檢查輸出效果。

## 5. 值不值得研究？

**有影片製作需求時很適合實際試用。** 你可從桌面剪輯開始；MCP 是日後需要自動化時才值得投入的功能。
