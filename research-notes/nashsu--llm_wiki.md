# llm_wiki｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/nashsu/llm_wiki/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

跨平台桌面知識庫。它匯入文件後用 LLM 逐步建立持久 Wiki、連結與圖譜；README 列出多格式匯入、原始來源檢視、人工待審佇列、Chrome 擷取、HTTP API 和 MCP。它不是只在每次提問時重新檢索文件。

## 2. 對我有什麼用？

這與你整理 Obsidian、個人文件和 Codex 工作知識很接近，尤其可比較自動分類和來源回溯是否減少手動整理。它會生成新頁面，應以副本試用並把自動內容與原始資料明確分開。

## 3. 使用情境

挑選一組已整理好的技術手冊與非敏感筆記，測試匯入、Wiki 頁面、圖譜、人工審核和 Read Sources Only。看生成頁面是否保留可定位原文，以及重新匯入會否造成重複。

## 4. 我要怎麼用？

到 Releases 取得對應平台預編譯桌面版；依 Quick Start 建立專案、設定 Chat 與 Ingest 模型，再匯入測試資料夾。若要供 Codex 查詢，README 提供本機 API、MCP 和獨立 Skill；先確認每項權限與輸出位置再連接。

## 5. 值不值得研究？

試用成功的標準可以設成：每個重要結論能回到原始檔；系統新增的頁面不覆蓋既有 Obsidian 筆記；修改或刪除原文後，Wiki 也能標示過時內容。這三項比圖譜畫得漂亮更影響你能否安心使用。

**很適合我，可以實際使用。**能直接服務你的個人知識庫流程，但需用副本驗證生成品質與資料邊界。
