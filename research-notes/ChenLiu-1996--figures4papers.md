# figures4papers

> 專案：[ChenLiu-1996/figures4papers](https://github.com/ChenLiu-1996/figures4papers)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是作者製作學術論文圖表的 Python 程式與範例集合，涵蓋長條圖、雷達圖、概念圖、趨勢圖等，也提供 `scientific-figure-making/` Agent Skill。它偏向範例與製圖規範，不是一般拖拉式圖表軟體。

## 2. 對我有什麼用？

你做技術報告、測試結果比較或研究整理時，可參考配色、版面與輸出規格，讓圖表更清楚。若只需要快速畫一般統計圖，現有試算表工具可能更省事。

## 3. 使用情境

適合論文、報告中的量化比較、趨勢與概念示意，或讓 Coding Agent 根據資料產生可重現圖表。

## 4. 我要怎麼用？

先看 README 圖例，選與需求相近的 `figure_*` 專案，再閱讀該範例程式與資料需求。若交給 Agent，可在專案中指向 `scientific-figure-making/SKILL.md`，不必先安裝 plugin；輸出後仍需核對數值、標籤與引用。

## 5. 值不值得研究？

有特定情境才有用。你若要做正式技術報告或研究圖表，值得參考其範例與 Skill。
