# DSPy｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/stanfordnlp/dspy/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

用程式定義並最佳化語言模型流程的 Python 框架。以模組、輸入輸出簽名和評估資料集組成 LLM 程式，再讓最佳化器搜尋更合適的提示或參數；特別適合輸出可評分的分類、擷取與 RAG。

## 2. 對我有什麼用？

當你想將日誌分類或報告摘要變成可重複執行的功能，它提供比手動反覆改提示詞更清楚的實驗方式。需要先有少量高品質標註範例，才能知道最佳化是否真的有效。

## 3. 使用情境

你已有 Python 自動化能力。若報告摘要常因提示詞變動而不穩，可把任務與評分條件寫成可重跑的實驗，避免只憑主觀感覺改 prompt。

例如從測試日誌擷取故障類型與證據行，準備人工核對的正確案例，比較最佳化前後的召回與錯誤率；也可為知識庫問答設定引用與拒答標準。

## 4. 我要怎麼用？

依 README 用 pip 安裝 dspy，選擇模型提供者與認證方式；先寫最小 Signature/Module，再準備有代表性的訓練與驗證樣本，跑基準輸出後才試最佳化器。保留測試集，人工查錯誤例子與費用。

README 將分類、RAG 與 Agent loop 都列為可組合的應用；若只試第一個案例，可先用 pip 安裝 dspy，寫一個明確的輸入輸出簽名，再拿既有的正確案例評分。

## 5. 值不值得研究？

有特定情境才有用：當 LLM 步驟要正式進入測試或報告管線，且已有可評分樣本時，這套方法很有價值。
