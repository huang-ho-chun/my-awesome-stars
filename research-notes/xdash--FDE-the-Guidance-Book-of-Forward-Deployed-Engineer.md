# 前線部署工程師指南（xdash/FDE-the-Guidance-Book-of-Forward-Deployed-Engineer）

資料來源：[官方 README](https://github.com/xdash/FDE-the-Guidance-Book-of-Forward-Deployed-Engineer/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

范冰撰寫的 FDE（Forward Deployed Engineer）職涯與交付指南，從角色定位、找對客戶問題、部署到續約和規模化複製，結合案例與來源。README 提供官網、GitHub 章節和整本 PDF。它是作者的研究整理與論述，不等於所有公司的職缺描述，也不是求職保證。

## 2. 對我有什麼用？

你有客戶伺服器設定與自動化測試的實務經驗，可藉此比較自己喜歡的是深入客戶現場解決問題，還是建立可重複的內部產品。FDE 可能涵蓋技術、需求澄清和溝通；對你最重要的判斷仍是實際職責、工時與可轉移技能，不能只看角色名稱。

## 3. 使用情境

例如研究一個 FDE 職缺時，將書中的交付旅程對照職務描述：是否需要到場、誰承擔客戶溝通、如何定義完成、是否有文件與產品團隊承接。接著把你目前的一個客戶問題寫成案例，拆出需求、實作、驗收與可複製部分，判斷哪些能力已具備。

## 4. 我要怎麼用？

可在 `fde4.ai` 線上閱讀，或在 README 目錄按章節開 Markdown；需要離線則下載倉庫提供的合併 PDF，更新時以章節版為準。先讀角色定位與解決正確問題兩章，再挑一個案例核對附錄來源。無需安裝程式；成果是一份自己的職務適配問題清單。

## 5. 值不值得研究？

有特定情境才有用：當你實際評估相關職缺或職務轉型時很有價值；目前可先當比較框架收藏。
