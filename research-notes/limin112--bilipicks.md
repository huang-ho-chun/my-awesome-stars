# BiliPicks｜GitHub 專案導覽

> 專案：https://github.com/limin112/bilipicks

## 1. 這是什麼？

BiliPicks 是家長自行挑選 B 站影片的靜態播放頁。README 說它只播放清單內的影片，沒有推薦演算法，並提供分類瀏覽、闖關式學習路線、觀看進度及適合遙控器的電視版。播放使用 B 站官方嵌入播放器，不抓取影片串流；專案並非 B 站官方產品。

## 2. 對我有什麼用？

若要為孩子安排可檢查的影片學習清單，可以先選出內容、寫明推薦理由與提醒，再讓孩子依路線觀看。影片看完的狀態存在本機瀏覽器，不需建置後端。家長仍須親自核對影片品質、年齡適合度及 B 站當下的可播放狀態。

## 3. 使用情境

- 將科普、數學或程式影片排成逐步解鎖的學習路線，並附動手任務。
- 在手機、電腦或電視上播放預先挑選的清單，避免接著滑到清單外的推薦影片。
- 定期檢查失效影片與封面、時長等資料，再調整選片。

## 4. 我要怎麼用？

先看[線上示範](https://minlibuilds.com/bili/)確認介面是否合適。要建立自己的版本，可 fork 或下載 repository，開啟 `index.html`，並按 README 修改 `data.js` 的影片、分類、路線及頻道資料；`update.py add` 可依 BV 號補入影片資訊，`update.py --check` 只產生檢查報告。修改後可部署到靜態網站服務。進度保存在瀏覽器本機；不同裝置的進度是否共用，應以實際使用方式核對。

## 5. 值不值得研究？

若想為孩子建立有邊界、可由家長審核的影片清單，值得從少量影片試用。這個專案的重點是選片與學習路線，而不是替家長自動判斷內容；定期維護清單仍是必要工作。
