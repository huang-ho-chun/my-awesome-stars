# OpenMAIC 專案指南

來源：[THU-MAIC/OpenMAIC 官方 README](https://github.com/THU-MAIC/OpenMAIC/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

多 Agent 互動課堂與課程生成系統。把資料或主題變成有教師、學生互動的課程體驗，README 提供網頁示範與自行部署方式，並列出本地模型、語音辨識及 Agent 工作台等選項。

## 2. 對我有什麼用？

它能把伺服器架構或測試流程講成有互動的課程，適合教育新同事或回顧知識。若目前只需要精確的操作手冊，製作互動內容的成本未必划算。

## 3. 使用情境

適合把難懂的伺服器配置或自動化測試概念變成新同事能參與的教學；但主軸是學習體驗，對生產報告管線沒有直接必要性。

可拿一份不含客戶資料的測試流程教材生成短課，再檢查角色問答是否正確；對照原文件找出杜撰的步驟，觀察互動形式是否真能幫助理解。

## 4. 我要怎麼用？

先看線上 Demo 與 User Guide；自行部署需按 README 安裝 pnpm、取得模型服務設定與環境變數，執行 pnpm install、pnpm dev，再於瀏覽器建立課程。正式服務可參考 build/start 或 Docker 路徑。

README 的 Quick Start 以 pnpm 啟動網頁，並提供 Docker 部署、可選的本地 AI 提供者和語音辨識方案。先不要同時啟用所有選項，才容易分辨課程內容和部署環境造成的問題。

## 5. 值不值得研究？

有特定情境才有用：需要製作技術教學時可試一個小課程；目前提高測試效率的優先度較低。
