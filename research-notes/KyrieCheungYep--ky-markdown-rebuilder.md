# ky-markdown-rebuilder 專案指南

來源：[官方 README](https://github.com/KyrieCheungYep/ky-markdown-rebuilder/blob/HEAD/README.md)｜查閱日期：2026-09-16

## 1. 這是什麼？

給 Codex 等 Agent 的文件重建 Skill，將視覺複雜的 PDF、投影片、掃描件與長截圖重建成 Markdown。README 強調逐頁渲染、檢查、頁數對齊和品質契約，重點在可核對的產物。

## 2. 對我有什麼用？

這符合你要求保留原始日記與文件版面的習慣。它可作為需忠實重建的流程骨架；實際 OCR 與視覺判讀仍受輸入品質影響，姓名和不清楚的字應保留疑問。

## 3. 使用情境

拿一份含表格、跨頁標題與圖像的文件，在副本中試 `page-aligned` 等輸出模式，逐頁比對內容與原圖；檢查驗證腳本是否抓出漏頁或錯位。

## 4. 我要怎麼用？

依 README 的 Codex 安裝章節把 Skill 放到指定技能目錄，先跑環境預檢，再讓 Codex 在獨立輸出資料夾重建測試文件。產出後執行內建 `check_output.py` 等檢查，人工覆核完才考慮進入筆記庫。

## 5. 值不值得研究？

這套 Skill 會安排多步渲染和人工可讀檢查，因此比單一轉檔命令耗時；它適合少量高價值文件。採用標準應放在漏頁數、表格與圖說位置、原文不確定處是否保留，而不是只看文字流暢程度。

**很適合我，可以實際使用。**與你目前重視逐頁可驗證的文件整理方式相符。
