# planning-with-files｜GitHub 專案導覽

## 1. 這是什麼？

planning-with-files 是幫 AI Coding Agent 把長任務的計畫與進度留在檔案中的 Skill。它主張用任務計畫、研究發現和進度三份文件記住已做與未做的事，減少對話變長、清除上下文或中斷後重頭探索。它不是專案管理服務；主要成果是 Agent 在工作目錄中的可讀檔案。

## 2. 對我有什麼用？

你有跨多天的資料整理和自動化任務，常需要保留原件、清楚記錄進度與下一步。這個模式能讓 Codex 在長任務中有可審查的狀態；但如果只是改一行或回答一個問題，三份文件反而多餘。

## 3. 使用情境

- **長時間實作**：跨多輪對話持續追蹤需求與未完成項目。
- **中斷恢復**：重開任務時先讀現有紀錄，而不是重問背景。
- **複雜研究**：把來源、已排除假設與後續檢查分開保存。

## 4. 我要怎麼用？

1. 依 README Quick Install 選 Codex 可用的 Skills 路線，在一個測試專案安裝。
2. 給 Agent 一個真正多步驟的任務，要求先建立計畫與發現／進度檔，再逐步更新。
3. 中途暫停並恢復，檢查這些檔案是否足以還原狀態；確認有用後才在其他任務啟用。

## 5. 值不值得研究？

**很適合我，可以實際使用。** 你的長任務與人類檢查點需要清楚狀態；以任務規模決定是否啟用即可。
