# i-have-adhd｜GitHub 專案導覽

> 依 [專案 README](https://github.com/ayghri/i-have-adhd) 與相關文件於 2026-09-16 重寫；著重用途與使用判斷，不深入原始碼。

## 1. 這是什麼？

這是一個給 Coding Agent 的輸出風格 Skill／Plugin，解決「答案很長，真正要做的事卻埋在後面」的問題。它要求 Agent 先寫可執行的下一步、把步驟編號、保持進度清楚，減少空泛開場與岔題。它改變的是**回答方式**，不是 Agent 的程式能力或事實準確度。

## 2. 對我有什麼用？

你常和 Codex 一起排查錯誤，也會讓它完成多步驟工作。這個 Skill 可以讓每一輪回答更容易接上前一輪，例如先列出「已確認 A、已排除 B、接著檢查 C」，你不必再從一大段背景中找指令。你也能參考它的規則，做成更符合自己偏好的版本。

## 3. 使用情境

- **多輪除錯**：每輪只說目前證據、下一個檢查動作，以及回傳什麼結果。
- **執行既定任務**：把長計畫轉成當下能做的步驟，完成後更新狀態。
- **快速決策**：先給建議與理由；若你想理解原理，再要求詳細解釋。

## 4. 我要怎麼用？

1. 先讀 [安裝說明](https://github.com/ayghri/i-have-adhd/blob/main/INSTALL.md)，依你使用的 Agent 選擇安裝方式；README 也提供了讓 Coding Agent 協助安裝的提示。
2. 在一段真實的 Codex 除錯對話中使用，觀察它是否把行動放前面、是否還保留必要證據。
3. 若輸出太短，依專案的調整方式修改規則，例如保留「簡短執行模式」與「需要原理時的解釋模式」。

## 5. 值不值得研究？

**很適合你，可以直接試用。** 它處理的是你日常 AI 協作的閱讀與執行成本；但精簡不應刪掉不確定性、錯誤證據或風險。
