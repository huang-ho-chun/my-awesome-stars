# lecture-to-notes｜GitHub 專案導覽

> 依 [專案 README](https://github.com/drpwchen/lecture-to-notes) 於 2026-09-16 整理；著重用途與使用判斷。

## 1. 這是什麼？

lecture-to-notes 把講座的影片、音訊、投影片 PDF 或照片整理成有來源依據的筆記，並可產生把影片、逐字稿與摘要同步放在一起的 HTML 檢視頁。它是一組可逐步執行的本機腳本與工作流程，不只是把影片丟給模型要一段摘要。README 的路由腳本會先判斷輸入並列出應執行的步驟，不會直接修改檔案。

## 2. 對我有什麼用？

你有保存資料、核對原始內容的習慣，也可能會整理教學或會議影片。這個專案能讓筆記對回影片與投影片，減少摘要失去上下文。若只是短影片或已有字幕，一套多階段流程可能太重；對長講座與需要回查證據的內容則很合適。

## 3. 使用情境

- **課程筆記**：將講座片段與投影片對齊，形成可查的 Markdown。
- **會議或分享整理**：保留音訊與逐字稿，方便核對說法。
- **Obsidian 匯入**：把完成的 Markdown 放進筆記庫，同時留住來源連結。

## 4. 我要怎麼用？

1. 依 README 的 Requirements 準備 Python、FFmpeg；它在 Windows 11 測試過，GPU 可加速但不是唯一途徑。
2. 將一段短影片與相關投影片放在測試資料夾，先執行 `route_inputs.py` 查看計畫和需要你決定的問題。
3. 再按輸出的次序執行轉錄、投影片處理和筆記生成，打開 HTML 檢視頁，對照原影片抽查重點。

## 5. 值不值得研究？

**有特定情境才有用。** 需要可回溯的長影音筆記時很有價值；首次設置與處理時間較高。
