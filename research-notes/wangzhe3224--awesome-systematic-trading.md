# Awesome Systematic Trading｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/wangzhe3224/awesome-systematic-trading/blob/master/Readme.md)；查閱日期：2026-09-28。

## 1. 這是什麼？

這是一份量化與系統化交易資源清單，涵蓋回測、實盤交易、機器學習、因子、風險、最佳化、時間序列、資料來源、券商 API、加密貨幣與基礎設施。它主要提供分類、連結與簡短說明，本身不是交易程式。
清單包含多種語言、商業與開源服務，品質、維護狀態和適用市場各不相同。

## 2. 對我有什麼用？

你可以用它快速了解量化交易工具生態，從資料、研究、回測到下單逐層找候選方案。若你在評估金融工具或想做研究型專案，它比零散搜尋更有效率。
它不能替代投資策略驗證或風險管理。被收錄只代表資源值得查看，不代表安全、正確、合規或能獲利。

## 3. 使用情境

- 尋找回測框架：比較通用、加密貨幣或機器學習取向的工具。
- 建立資料管線：尋找市場資料、資料庫、訊息佇列與分析套件。
- 研究因子與風險：瀏覽 alpha、指標、定價、風險和最佳化資源。
- 串接券商或交易所：找到 API 與客戶端，再到官方文件確認現況。

## 4. 我要怎麼用？

1. 先定義市場、資產類別、研究語言與目標，例如只做台股研究、不要實盤。
2. 從對應分類挑 2 至 3 個仍有維護的候選專案，檢查授權、更新時間、文件和社群。
3. 用歷史資料做可重現的小型回測，納入手續費、滑價、資料偏誤與失效情境。
4. 若要連接真實帳戶，必須另外核對券商規則、API 權限、資安與所在地法規，先使用模擬環境。

## 5. 值不值得研究？

**適合當工具索引，需有明確研究目標才深入。** 對金融研究有參考價值，但清單龐大且變動快。建議先收藏，需要特定資料源或回測工具時再精準篩選。
