# ownscribe｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/nczz/ownscribe/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

這是 ownscribe 的繁中語音辨識分支，偏重台灣國語與中英混合會議。README 說可即時字幕、錄音轉寫、說話者辨識及摘要；預設本機運作，遠端摘要需主動選擇。它是 macOS 專用的 CLI。

## 2. 對我有什麼用？

如果你將來在 Mac 上處理中文技術會議，逐字稿與說話者分段可能改善會議紀錄；但你目前在 Windows 工作，無法照 README 的環境需求直接試。

## 3. 使用情境

在符合硬體條件的 Mac 上，拿一段同意使用的中英混合會議音訊，比對專有名詞、說話者和繁體輸出。任何摘要都要用原音檔回查。

## 4. 我要怎麼用？

README 要求較新的 macOS、Apple Silicon、Python、磁碟與記憶體；在 Mac 上複製專案，以 `uv` 建環境、安裝依賴，再設定 ASR backend 和音訊權限。可用即時模式或轉錄既有錄音；高品質 speaker 模型另需權限或 token。

## 5. 值不值得研究？

若未來換到 Mac，還需確認會議參與者同意錄音、模型對專有名詞的錯誤率，以及音訊檔保存與刪除週期。README 的語言模型比較並非同一資料集的公平排名，因此仍要用你的真實會議樣本驗證。

**可以先收藏，以後可能用到。**語言場景很合適，但目前 Windows 環境是明確限制。
