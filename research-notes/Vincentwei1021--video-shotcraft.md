# video-shotcraft

> 專案：[Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是面向產品宣傳片的 Agent Skill。它把真實產品截圖、分鏡配方、Remotion 動畫、節拍與音效串成影片製作流程，還提供 Motion Workbench 和剪映草稿輸出。

## 2. 對我有什麼用？

你可以用實際介面截圖快速做軟體展示、功能發布片或短影音廣告；來源仍可編輯，方便改文案與鏡頭。若沒有產品畫面或不需要宣傳片，價值較低。

## 3. 使用情境

適合 SaaS 產品介紹、功能更新展示、社群短片與需要反覆調整的商業畫面。

## 4. 我要怎麼用？

先準備產品截圖、目標觀眾與片長，按 README 用 `npx skills add Vincentwei1021/video-shotcraft` 安裝到 Codex/Claude。讓 Agent 提出鏡頭方案，核對產品畫面與文案，再渲染 MP4；需要細修時打開 Motion Workbench 或匯出剪映草稿。

## 5. 值不值得研究？

有特定情境才有用。若你要展示自己做的工具或服務，很值得試；一般影片剪輯可先收藏。
