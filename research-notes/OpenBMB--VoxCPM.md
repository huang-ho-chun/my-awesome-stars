# VoxCPM 專案指南

來源：[OpenBMB/VoxCPM 官方 README](https://github.com/OpenBMB/VoxCPM/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

VoxCPM 是多語言文字轉語音模型與工具，README 介紹 VoxCPM2 的聲音設計、參考聲音複製、可控制的朗讀以及批次處理。

## 2. 對我有什麼用？

如果你日後要把技術教材、Obsidian 筆記或個人內容轉成語音，它可用於本地試作。現在的 Shell/Python 測試與伺服器報告以文字為主，語音生成不會直接改善核心流程。若使用聲音複製，應只用有權使用並取得同意的錄音。

## 3. 使用情境

挑一段公開的中文技術教學短文，先用預設聲音產出朗讀，檢查專有名詞、停頓與錯讀；再與雲端語音方案比較延遲和成本。若要做多段教材，測試批次輸出、檔名與文字片段的對應，避免音檔混淆。

## 4. 我要怎麼用？

README 的 Quick Start 提供 pip 安裝 voxcpm，再從 Python API、CLI 或 Web Demo 選一條路徑。先取得對應模型與相依套件，執行一個短文字範例並聽輸出；網頁範例可用 app.py 啟動。確認品質後再考慮較複雜的服務化方式，並評估裝置資源與模型授權。

README 同時列 Python API、CLI、Web Demo 和批次語音處理。選路徑時先看是否只需單次朗讀；只有需要重複產出許多音檔時，才把批次和服務化納入測試。

## 5. 值不值得研究？

可以先收藏，以後可能用到：有明確語音教材或配音需求時值得測試，眼下並非你的主要工作瓶頸。
