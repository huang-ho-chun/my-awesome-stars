# OpenStock｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/Open-Dev-Society/OpenStock/blob/main/README.md)；查閱日期：2026-09-22。

## 1. 這是什麼？

OpenStock 是一個可自行部署的開源股票追蹤與研究 Web 平台。它提供股票搜尋、個人觀察清單、公司資料與財務資訊、TradingView 圖表和市場熱圖，也可設定個人化提醒、每週新聞摘要，以及選用跨新聞與社群來源的情緒資訊。

它是以 Next.js、MongoDB 和多個外部資料服務組成的完整網站專案，比較像可客製化的**自架市場資訊儀表板**。它不是券商交易軟體，README 也沒有把它描述為可直接下單的投資平台。

## 2. 對我有什麼用？

如果你想把追蹤股票、圖表、公司資訊與觀察清單集中在自己的介面，OpenStock 可以作為自架起點。你可以依自己的市場與研究習慣調整頁面，也能把它當成學習金融網站如何整合登入、行情 API、圖表、資料庫、排程和電子郵件的範例。

實際資料主要來自 Finnhub、TradingView 等外部服務，免費方案可能有延遲、額度和市場限制。非美國市場的即時性尤其要查證；README 明確提醒部分行情可能延遲 15 分鐘以上。它適合資訊整理與個人研究，不應把畫面上的價格、情緒或 AI 產出直接當成交易依據。

對你而言，若只想看盤或維護觀察清單，現成金融 App 會更省時間；若想掌控介面、資料保存方式，或研究如何打造自己的投資工具，這個專案才更有價值。

## 3. 使用情境

- **自架觀察清單：** 登入後保存追蹤標的，集中查看價格、公司資訊與圖表。
- **市場總覽：** 使用熱圖、行情與新聞元件快速掃描市場狀況。
- **公司研究入口：** 將公司資料、財務資訊、技術圖表和選用的情緒資訊放在同一頁。
- **提醒與摘要：** 透過背景工作發送個人化歡迎信或每週新聞摘要。
- **開發練習：** 研究 Next.js、MongoDB、Better Auth、Finnhub、TradingView 和 Inngest 的整合方式。

## 4. 我要怎麼用？

1. 先確認有 Node.js 20 以上與 npm 或 pnpm。
2. 準備 MongoDB、Finnhub API key、登入用密鑰；若要寄信、AI 介紹或情緒資訊，還要設定相應的郵件與第三方服務。
3. 複製專案、安裝套件並建立 `.env`，先執行資料庫連線測試。
4. 啟動開發環境後，在本機建立帳號，測試股票搜尋、觀察清單、公司頁面和圖表。
5. 部署前檢查每個外部服務的費率、延遲、額度、資料使用條款與密鑰保護方式。也可用 Docker Compose 一起啟動應用與 MongoDB。

這不是下載後立即使用的桌面軟體，完整功能需要多個服務和環境變數。專案採 AGPL-3.0；若修改、再散布或作為網站服務部署，README 要求依相同授權公開原始碼並保留作者資訊，正式部署前應閱讀完整授權條款。

## 5. 值不值得研究？

**可以先收藏，以後可能用到。** 若你想建立或客製自己的股票研究儀表板，它提供了相當完整的基礎；若目標只是可靠地查看台股或美股行情，部署成本、外部 API 和資料延遲使它不一定比現成工具實用。
