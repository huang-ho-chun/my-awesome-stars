# Agentic AI 繁中學習地圖（WenyuChiou/awesome-agentic-ai-zh）

資料來源：[官方 README](https://github.com/WenyuChiou/awesome-agentic-ai-zh/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

繁體中文的 Agent 學習路線圖，將 Stage 0–2 基礎、CLI Agent 使用者路線、Agent Builder 路線，以及評估與安全等進階階段串起來。README 說明它同時提供精選外部資源和可執行的小練習；完整概念會導向其他官方文件或教材。

## 2. 對我有什麼用？

這份地圖很適合你把「使用 Codex」與「自己開發 Agent」分開規劃。你已有 Python、Git 和工具使用經驗，可跳過太初階內容，沿 Track A 補強命令列 Agent 的權限、任務切分與驗收，再視工作需要才走 Track B。繁中敘述可直接收進 Obsidian 作為學習索引。

## 3. 使用情境

例如要改善反覆處理的伺服器設定任務，先沿 CLI 路線讀如何給 Agent 明確範圍、觀察操作結果與保留人工批准，再選一項小練習套到副本環境。若發現需要自己寫工具迴圈，再轉向 Builder 路線，而非因為有 Agent 熱潮就一次學完整框架。

## 4. 我要怎麼用？

先開 README 的路線表：新手從 Stage 0，會 Python／Git／API 可從 Stage 1；日常使用選 Track A，自行建 Agent 選 Track B。按各 Stage 頁面的練習與前置條件操作，或使用線上文件站閱讀。若希望離線學習可 clone 倉庫；完成每階段的明確產出，再用名詞表與外部參考補缺。

## 5. 值不值得研究？

很適合我，可以實際使用：路線選擇與你的現況高度吻合，成本可控制。重點是挑選真正改善現有工作的一條路，而非把整張地圖當待辦清單。
