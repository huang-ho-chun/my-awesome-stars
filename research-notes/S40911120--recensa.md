# recensa 專案指南

來源：[官方 README.md](https://github.com/S40911120/recensa/blob/HEAD/README.md)｜查閱日期：2026-09-16

## 1. 這是什麼？

Recensa 是自架的 Claude Code 工作紀錄檢視器，將 `~/.claude/projects/` 的 JSONL 建本機 SQLite 索引，在網頁中搜尋、重播與稽核 Session。README 說原始紀錄維持唯讀，索引可重建。

## 2. 對我有什麼用？

你重視 Codex 工作證據與回溯，但本工具明確只讀 Claude Code 的紀錄格式，不能假定直接支援 Codex。若日後同時使用 Claude Code，它才有明確用途。

## 3. 使用情境

在有 Claude Code 歷史紀錄的測試環境，用幾段非敏感 Session 檢查搜尋、工具呼叫與時間線；確認索引資料與原始 JSONL 的對應。

## 4. 我要怎麼用？

README 的 Quick Start 以 Docker 將 Claude 目錄唯讀掛入，並在 `localhost:7788` 開啟介面；Windows 有 PowerShell 專用範例。先檢查掛載路徑與本機監聽位址，再啟動容器。沒有 Claude 紀錄時安裝後也無資料可看。

## 5. 值不值得研究？

它的安全邊界取決於本機 Docker 掛載、監聽埠和歷史紀錄內容。即使 README 說不會上傳，Session 中仍可能含有路徑、提示或工具輸出；若將來使用，先限定本機存取並檢查索引備份與刪除方法。

**對我目前用途不大。**資料格式鎖定 Claude Code，你目前主要用 Codex。
