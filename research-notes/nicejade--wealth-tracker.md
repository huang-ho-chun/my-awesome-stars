# wealth-tracker｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/nicejade/wealth-tracker)；查閱日期：2026-09-16。

## 1. 這是什麼？

Wealth Tracker 是記錄與分析個人資產的應用程式。它提供資產視圖，也描述以 AI 協助解讀財務狀況；README 列出桌面 Electron 安裝包，以及 Docker／自架服務路線。它偏向個人資產追蹤，不是券商交易終端。

## 2. 對我有什麼用？

若你想定期看資產分布或比較一段時間的變化，可以用它建立清楚的個人紀錄。你重視資料留存與原件可控，桌面版的本機保存方式可能比先架一套服務適合；但在匯入真實財務資料前，應先確認資料格式、備份和匯出方式。

## 3. 使用情境

- **個人資產總覽**：手動建立少量分類，觀察資料呈現是否有幫助。
- **長期紀錄**：定期更新資產狀態，檢查變化。
- **自架服務**：熟悉 Docker 且需要跨裝置時才考慮。

## 4. 我要怎麼用？

1. 先從 GitHub Releases 取得桌面版，用測試資料建立幾筆資產；README 說此路線不需另外部署後端。
2. 檢查輸入、圖表、資料保存位置及備份／匯出能力，確認能承受長期維護。
3. 若桌面版不符合需求，再依 README 評估 Docker 或其他部署方式。

## 5. 值不值得研究？

**有特定情境才有用。** 想要自行維護資產紀錄時可試；AI 建議僅作輔助，重大財務決定仍需獨立核對。
