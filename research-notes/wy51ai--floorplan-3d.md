# floorplan-3d｜GitHub 專案導覽

> 專案：https://github.com/wy51ai/floorplan-3d

## 1. 這是什麼？

floorplan-3d 是純前端戶型裝修設計工具。使用者可在 2D 平面圖擺放家具、測量尺寸、調整非承重牆，並切換到 Three.js 3D 場景鳥瞰或第一人稱漫遊。應用主要放在一個 `index.html`，不需要建置流程。

它提供 60 多種家具家電、房間面積統計、地面材料及估算費用、撤銷重做，並可匯出 PNG 與方案 JSON。方案自動儲存在瀏覽器本地。

## 2. 對我有什麼用？

可用來快速試排家具尺寸、檢查動線和房間配置，並從 3D 視角理解平面圖。匯出的 JSON 適合保留不同方案；PNG 則方便與家人或設計者討論。費用估算與畫面是規劃參考，實際施工仍需現場量測及專業確認。

## 3. 使用情境

- 比較床、桌、沙發或櫃子的擺放位置和尺寸。
- 在 2D 平面圖標記家具與測量距離，再切換 3D 看空間感。
- 測試不同地面材料的面積與初步造價。
- 將方案匯出 PNG 分享，或以 JSON 備份並再次匯入。

## 4. 我要怎麼用？

1. 下載 repository 後直接用瀏覽器開啟 `index.html`，或在目錄啟動本機靜態伺服器。
2. 在 2D 畫面拖入家具，移動、旋轉、調尺寸，使用測量工具及圖層開關。
3. 按 `T` 切換 2D／3D；3D 中可選鳥瞰或漫遊，並調整日照時間。
4. 完成後匯出 PNG 或方案 JSON。若要套用自己的戶型，需修改 `index.html` 中的房間、牆、窗與材料等資料。

Three.js 由 jsDelivr 載入，首次使用 3D 場景需要網路。README 指出承重牆會單獨標示，拆改功能針對非承重牆；不能用此工具的畫面代替結構鑑定。

## 5. 值不值得研究？

若正在比較空間配置，值得先試用，因為開啟門檻低且 2D、3D 同步。現成戶型未必吻合自己的房屋；要實際使用，先確認比例與牆體資料，再決定是否投入修改原始資料。
