# Horizon｜GitHub 專案導覽

> 專案：https://github.com/horizon-rust/horizon

## 1. 這是什麼？

Horizon 是以 Rust 重寫 Minecraft: Java Edition 的非官方遊戲與啟動器。README 說明可遊玩生存、創造等模式，開啟原版世界，連入伺服器，並提供原生版本的圖形與效能功能。它仍要求玩家擁有正版 Java Edition；不是 Mojang 或 Microsoft 的官方版本。

## 2. 對我有什麼用？

如果已擁有 Minecraft Java Edition，可在自己的電腦測試不同遊戲執行方式、載入速度與畫面設定。它也提供理解遊戲相容性與 Rust 遊戲工程的實際案例，但 README 的效能數據來自特定硬體與測試條件。

## 3. 使用情境

- 在既有世界的副本上試玩，檢查存檔與玩法是否符合預期。
- 比較同一台電腦上原版與 Horizon 的載入、畫面及記憶體使用。
- 研究其原生模組、資源包及伺服器支援；Java 模組不能直接執行。

## 4. 我要怎麼用？

從專案列出的 [官方下載頁](https://playhorizon.dev) 或 GitHub launcher releases 取得適用系統的啟動器。依安裝指南登入擁有 Java Edition 的 Microsoft 帳號，先備份要試的世界，再從啟動器啟動。先在沒有模組的情況下檢查世界、效能與多人連線；要加入模組時，先看其支援的 Horizon 格式與限制。

## 5. 值不值得研究？

若想試非 Java 的 Minecraft 執行方式，值得以備份世界做小規模比較。特定世界、伺服器與模組能否符合自己的需求仍須實測，不應直接把 README 的基準數據套用到不同硬體。
