# archify 專案指南

來源：[tt-a1i/archify 官方 README](https://github.com/tt-a1i/archify/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

將程式碼或系統描述轉成互動架構圖的 Agent Skill。

## 2. 對我有什麼用？

適合把 Shell、Python、伺服器測試與報告產出間的關係畫清楚，供自己或同事討論；圖形可幫助溝通，但不能取代程式碼核對。

## 3. 使用情境

用一個已知的小型測試專案先產生架構圖，標出輸入、處理、輸出與外部服務；逐項檢查圖上的箭頭是否真的存在，再將確認版放進文件。

## 4. 我要怎麼用？

依 README 使用 npx skills add 安裝至 Codex 等宿主，也可從 repo 原始碼或描述開始。向 Agent 提供專案範圍、目標讀者與想看的流程；產出後在互動圖中細化與檢查，再匯出分享。

圖可作為討論入口，但不能把自動推得的模組關係當成已驗證的架構文件。

README 說明既可從 repo 產圖，也可從文字描述開始；適合先畫沒有程式碼的伺服器測試流程，再用真實 repo 校對模組關係。互動圖的每條連線都應有來源。

## 5. 值不值得研究？

很適合我，可以實際使用：你常需解釋跨檔案工作流，先用小專案試圖就能驗證價值。
