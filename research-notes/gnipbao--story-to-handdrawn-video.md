## 1. 這是什麼？

story-to-handdrawn-video 是一套 Agent Skill 加 Remotion 渲染器，可將中文故事文字或依序排列的圖片製作成 3:4 直式手繪動畫。它提供兩種動畫方式：逐層顯示文字、灰階畫面與彩色插畫，或完整保留每頁內容的翻書效果。

Agent 負責理解故事、安排分鏡、建立角色參考與呼叫生圖工具；本機腳本處理已確認的母圖，Remotion 再依分鏡渲染。專案內含大量畫風與配色示意，也能分析參考圖後把個人風格保存在本機。輸出是 H.264 靜音 MP4，預覽為 720×960，正式成片為 1080×1440。

## 2. 對我有什麼用？

你可以把短篇故事、家庭回憶、育兒內容、知識解說或已完成的插畫做成翻頁短片。它特別重視角色連續性、中文字檢查、畫面留白與母圖重用，能避免每個動畫階段重新生圖造成構圖漂移。

它也適合你用 Codex 以自然語言操作：先選風格、生成預覽、人工檢查文字和角色，再輸出正式成片。若你已有一組排版好的圖片，可以跳過故事生圖流程，直接用圖片生成翻書動畫。

## 3. 使用情境

- **家庭故事短片**：把親子回憶或旅行故事做成手繪日記動畫。
- **兒童繪本展示**：用完整頁面與翻書效果保留原文字及插畫。
- **知識解說**：逐步顯示文字、線稿與彩色圖，形成視覺節奏。
- **現有圖片成片**：依檔名順序匯入圖片，產生統一尺寸的直式影片。
- **風格實驗**：從內建風格庫選擇畫材與配色，或保存自己的參考圖風格。

## 4. 我要怎麼用？

1. 準備 Node.js 20 以上、Python 3.10 以上、npm、FFmpeg 與 Chrome 或 Remotion 支援的瀏覽器。
2. 複製倉庫後執行 `npm ci` 和 `npm run check`，確認渲染器與資產完整。
3. 將 `skill-package/story-to-handdrawn-video` 複製到 Codex 的 Skills 目錄；從其他資料夾呼叫時設定 `STORY_VIDEO_PROJECT` 指向專案絕對路徑。
4. 在 Agent 中提供故事或圖片路徑，選擇畫風、配色和動畫方式，並先要求產生預覽。
5. 逐頁檢查中文字、角色、構圖與留白；有錯誤時修圖或重新生成母圖。
6. 確認預覽後輸出正式靜音 MP4，再到剪輯軟體加入配音、字幕或背景音樂。

## 5. 值不值得研究？

**很適合想把故事或圖片做成有一致視覺風格短片的人。** 它將 Agent 規劃、生圖、素材校驗和 Remotion 渲染拆得清楚，也保留預覽確認步驟。主要成本是安裝依賴、產生每頁插畫與人工視覺檢查；若只需要簡單圖片輪播，會顯得較重。
