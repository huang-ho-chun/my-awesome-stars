# SRT 白板動畫 Skill（geeklee/srt-whiteboard-animation）

資料來源：[官方 README](https://github.com/geeklee/srt-whiteboard-animation/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

把 SRT 字幕轉成依敘事順序繪製的白板手繪動畫 Skill。README 描述分鏡、線稿、區域標註、預覽、逐幕渲染及合併 MP4 的流程；它會在重要階段停下等確認，讓字幕與畫面一致。這是影片製作流程，不是任意文字一鍵變成完美成片。

## 2. 對我有什麼用？

如果你未來要把技術教學、讀書摘要或社團內容做成短影片，這項工具能用既有字幕安排畫面順序。你現在主要處理測試和報告，影片需求不常見，且分鏡、線稿與標註需要人工時間；評估時應把這些步驟算入成本。

## 3. 使用情境

例如你已有 30 秒的測試流程講解字幕，可先讓 Skill 解析 SRT，檢查它是否把「執行、發現異常、人工覆核」拆成合理場景。確認線稿和區域順序，再渲染短片；若只是要在文件說明相同流程，一張流程圖可能已足夠。

## 4. 我要怎麼用？

先準備時間軸正確的 `.srt`。依 README 在 Skill 目錄執行 `python scripts/prepare_env.py --check` 與 `python scripts/prepare_env.py` 準備隔離環境；再用解析腳本產分鏡，審核線稿、建立對應的 PNG 與 annotation JSON，在預覽台調整區域與字幕時序，最後逐幕渲染 MP4 並合併。先用一幕短字幕驗證環境與畫面。

## 5. 值不值得研究？

可以先收藏，以後可能用到：若要製作教學影片很有特色；目前對主要工作投入的時間回報較低。
