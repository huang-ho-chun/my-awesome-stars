# 生成式 AI 入門課程（microsoft/generative-ai-for-beginners）

資料來源：[官方 README](https://github.com/microsoft/generative-ai-for-beginners/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

微軟整理的 21 課生成式 AI 課程，把概念課與實作課分開。主題由模型與提示設計延伸至文字、聊天、搜尋、函式呼叫及應用安全；每課附閱讀材料，實作課提供 Python、TypeScript 範例。它是循序學習資源，不是安裝後自動替你建好產品的平台。

## 2. 對我有什麼用？

你已用 Codex 解決實際問題，可用這套課補上「模型為何這樣回應、何時需要工具與檢索」的共同語言。與其全修，不如優先讀模型選擇、提示工程、搜尋及函式呼叫，再把內容對照你的 Shell／Python 報告流程。課程也有繁體中文（台灣）翻譯入口，但程式與雲端服務設定仍應以當前各課說明核對。

## 3. 使用情境

例如準備替測試結果寫摘要時，先在概念課界定模型輸入、可驗證的輸出與錯誤情境；再挑一個實作課跑最小範例，比較純提示和有結構資料的回應。將樣本限制為非敏感測試資料，記錄哪個步驟真的省時，而非直接導入整條工作流程。

## 4. 我要怎麼用？

先開啟課程設定的第 00 課，選 Python 或 TypeScript 路線；需要執行範例時，依課程選 Azure OpenAI、Microsoft Foundry Models、OpenAI API，或可離線執行的 Foundry Local。再進入單課 README，按該課指示設定環境與憑證、執行對應範例、檢查輸出，最後做課後延伸。僅閱讀概念課不需要模型金鑰；服務費用與可用模型須另查當前供應商資訊。

## 5. 值不值得研究？

很適合我，可以實際使用：與你使用 Codex 和設計可控自動化的需求直接相連。先完成三個最貼近工作的小節即可評估價值，無須為了「修完課程」花 21 課的時間。
