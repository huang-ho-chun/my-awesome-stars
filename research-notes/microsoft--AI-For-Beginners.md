# 人工智慧入門課程（microsoft/AI-For-Beginners）

資料來源：[官方 README](https://github.com/microsoft/AI-For-Beginners/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

微軟的 12 週、24 課 AI 入門課程，包含閱讀、測驗、實驗，涵蓋傳統機器學習、神經網路、TensorFlow、PyTorch 與倫理議題。它建立的是較廣的 AI 基礎，與專門教生成式 AI 應用的課程側重不同。

## 2. 對我有什麼用？

如果你想釐清分類、模型訓練和評估指標，這套課可支援未來分析測試數據或建立簡單預測工具。若當前主要在用 Codex 改寫 Shell／Python 流程，先修 24 課的優先度較低；可把它作為需要機器學習時的索引，不必因為「AI」標籤全部讀完。

## 3. 使用情境

例如你累積了測試執行記錄，想判斷哪些特徵與失敗較相關，可從資料與機器學習的基礎課建立訓練／驗證區分，再用小型實驗檢查是否只是記住舊資料。另一種用途是閱讀倫理與偏差內容，避免把模型產生的分類結果誤當成客觀事實。

## 4. 我要怎麼用？

先從 README 的 Getting Started 選入門路線，直接點課程頁閱讀；需要本機跟做時 clone 倉庫，依每課 README 建立所需 Python／Notebook 環境並執行實驗。README 也提供 Binder 入口，可先在瀏覽器試教材。以該課的測驗與實驗輸出檢查學習效果，不需預先設定整套課程環境。

## 5. 值不值得研究？

可以先收藏，以後可能用到：適合填補一般 AI 基礎；眼前與你自動化工作最貼近的課程可挑選閱讀，其餘等到需要模型訓練再深入。
