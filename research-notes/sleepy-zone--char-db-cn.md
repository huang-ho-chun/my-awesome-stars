# char-db-cn｜GitHub 專案導覽

> 專案：https://github.com/sleepy-zone/char-db-cn

## 1. 這是什麼？

char-db-cn 是二次元角色換裝資料庫的中文檢索介面。它保留原站的 1,027 張縮圖，將名稱與分類翻成中文，同時保留 Danbooru 英文標籤；可從髮型、服裝、姿勢與組裝四個頁面搜尋素材。

介面能把髮型、瀏海、髮色、髮飾、眼睛、服裝和姿勢放入不同槽位，再選擇品質前綴、表情、構圖、背景與其他標籤，產生正向及負向提示詞。也能將選定項目用 Canvas 排成帶編號的參考圖，供使用者把提示詞與視覺參考一起交給生成工具。

## 2. 對我有什麼用？

- 用中文、日文或 Danbooru 標籤搜尋角色髮型、服裝與姿勢，降低記憶英文標籤的負擔。
- 把不同角色元素組成一致的提示詞骨架，減少每次從頭整理描述的時間。
- 收藏常用項目、複製標籤，並輸出一張有編號的視覺參考圖。
- 姿勢素材若提供線稿，可作為 ControlNet 等工作流程的輸入參考。
- 可直接雙擊 `index.html` 在本機使用縮圖搜尋與篩選；若另備原圖資料夾，亦可依 `config.js` 指向本機來源。

## 3. 使用情境

- 為原創二次元角色整理固定髮型、瞳色、服裝與姿勢的提示詞。
- 在大量服裝或姿勢縮圖中篩選候選項目，再輸出對照圖與編號給 AI 或合作對象。
- 用同一角色的固定描述，只替換服裝、姿勢和表情，建立系列圖片。
- 查找 Danbooru 標籤的中文意義，或用中日文字詞反查對應素材。
- 在離線環境瀏覽 repository 內的縮圖與分類資料。

## 4. 我要怎麼用？

1. 可使用 README 提供的線上站點，或下載 repository 後直接開啟 `index.html`；本機模式需讓 `thumbs/` 保持在相對位置。
2. 在髮型、服裝或姿勢頁使用中文、日文或 Danbooru 標籤搜尋，再收藏或加入組裝槽位。
3. 到組裝頁選擇模型品質前綴、表情、構圖、背景與追加標籤，複製產生的正向／負向提示詞。
4. 需要視覺對照時，將選中素材匯出成帶編號的參考圖。
5. 若本機已有原圖、線稿或服裝單品圖，可依 README 修改 `config.js` 的 `LOCAL_ORIGINALS` 路徑；透過 HTTP 或 HTTPS 開啟時會忽略這項本機設定。

使用時要留意兩項邊界：線上版本預設啟用 Microsoft Clarity 分析，可在 `config.js` 清空 analytics providers 關閉；素材可用於作品製作、商用、修改與參考，但禁止再分發、轉載或轉售圖片本體，也禁止用於表現真實人物或未成年人。

## 5. 值不值得研究？

如果經常需要組合二次元人物提示詞，值得先試用。它最實際的價值是將可視縮圖、三語搜尋、標籤複製、角色組裝與參考圖輸出放在同一個介面，不必只靠文字猜測服裝或姿勢名稱。

不過 repository 主要是中文檢索介面與縮圖，不是可自由再分發的完整素材庫；原圖、線稿與下載仍受原作者條件限制。建議先用線上或本機縮圖介面確認搜尋及組裝是否符合需求，並在任何公開或商業流程中遵守 README 的素材使用限制。
