# TwitterMediaHarvest｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/EltonChou/TwitterMediaHarvest/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

Media Harvest 是 Chrome、Edge 等瀏覽器中的 X/Twitter 媒體下載擴充。README 介紹一鍵保存圖片與影片、原尺寸、檔名格式和下載紀錄，沒有宣稱提供完整貼文或帳號封存。

## 2. 對我有什麼用？

若你有自己需要保存的 X 媒體，可省逐張另存時間；但你目前重點是 Facebook、Instagram，而非 X，因此與現有流程的直接關聯低。

## 3. 使用情境

試存一則有多張圖片的公開貼文，核對檔案解析度、順序、日期和來源 URL 是否能另行記錄；避免把只有媒體的資料夾誤當完整貼文備份。

## 4. 我要怎麼用？

從 README 連到 Chrome 或 Edge 擴充商店安裝，在 X 頁面用下載按鈕保存。先看擴充所要求的權限、預設檔名與下載路徑；小量測試後再決定是否批次使用。

## 5. 值不值得研究？

若未來真的要建立 X 封存，還需另外保存貼文文字、來源連結、發布時間與上下文。單獨下載影像或影片容易失去脈絡，也無法證明它是該貼文的完整內容；因此這個擴充較適合臨時保存特定媒體。

**對我目前用途不大。**目前沒有明確 X 媒體封存需求，且工具不涵蓋完整內容保存。
