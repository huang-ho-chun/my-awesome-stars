# last30days-skill 專案指南

來源：[mvanhorn/last30days-skill 官方 README](https://github.com/mvanhorn/last30days-skill/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

聚合近 30 天多個來源的研究 Skill。

## 2. 對我有什麼用？

適合查可能快速變動的工具、方案或產品討論；其報告可提供線索，但仍需核對官方來源與發表日期。

## 3. 使用情境

例如研究某個伺服器測試工具近期變更，先收集討論與連結，再逐條核對版本資訊和官方公告；把未確認的社群說法留作觀察。

## 4. 我要怎麼用？

Codex 可依 README 用 npx skills add 安裝。首次研究前依文件跑 bundled preflight，查看設定來源、瀏覽器 cookie 計畫與預計寫入；再提供問題、時間範圍與平台，閱讀引用後回原頁查證。

來源平台、資料取得方式與搜尋覆蓋會變動，每次研究仍要檢查本次實際讀到了哪些來源。

README 特別要求 Codex desktop 等資料夾模式宿主先執行 bundled preflight，查看設定來源、cookie 計畫、預計寫入及可選命令。這一步應在首次搜尋之前完成。

## 5. 值不值得研究？

有特定情境才有用：近期社群脈動很有價值，但對穩定技術文檔不必每次啟動。
