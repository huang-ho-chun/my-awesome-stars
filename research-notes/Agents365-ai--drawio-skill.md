# drawio-skill｜GitHub 專案導覽

## 1. 這是什麼？

drawio-skill 是給 Codex 等支援 Agent Skills 的工具使用的繪圖 Skill。你可以用文字描述系統，或提供程式碼、Terraform、Kubernetes、SQL、OpenAPI 等實際資料，讓它建立可在 draw.io 繼續編輯的 `.drawio` 圖。它也能把 Mermaid 或白板照片轉成可編輯圖表。

這個專案的重點是讓圖表能隨系統變動：它可更新既有圖並盡量保留手動調整過的版面，產生不同視角、比較差異，也提供架構規則檢查。成品可匯出為 PNG、SVG、PDF、互動 HTML、PPTX 等格式。它比較像「製圖與維護工作流程」，不只是圖片生成器。

## 2. 對我有什麼用？

你可以把正在研究的工具組合、Obsidian 知識流程、Agent 工作流程或專案架構，整理成可編輯的圖。例如，請 Codex 根據資料夾與設定檔畫出「資料進來後如何解析、分類、寫成筆記」，再自己修改標籤與位置。下次流程改了，可以同步更新，而不用從頭畫。

如果要向別人解釋系統，也可以從同一份模型做概要圖、詳細圖和簡報。相較於只產生一張點陣圖，`.drawio` 檔較容易校正、重用及長期維護。實際匯入能力依資料來源與格式而異，仍要人工確認圖是否忠實反映現況。

## 3. 使用情境

- **快速說明概念**：用自然語言生成流程圖、C4 架構圖、循序圖、ER 圖等。
- **現有專案盤點**：從支援的程式語言、基礎設施設定或 API 規格建立初稿。
- **知識與工作流程整理**：把筆記、資料處理、Agent 任務之間的關係畫給自己或協作者看。
- **變更追蹤**：程式或設定更新後同步圖表，檢查架構差異與規則。
- **對外展示**：輸出圖片、互動網頁或 PowerPoint，並保留原始圖供後續編輯。

## 4. 我要怎麼用？

1. 先安裝 draw.io Desktop；若要使用專案的匯出與轉換流程，需確認 draw.io CLI 可執行。README 建議使用 30 版以上。
2. 依 README 安裝 Skill，例如在支援的 Agent 環境使用 `npx skills add Agents365-ai/drawio-skill -g`；也可手動安裝。
3. 從一張小圖開始：告訴 Codex 想呈現的流程、受眾、輸出位置，並要求生成可編輯的 `.drawio`。
4. 開啟圖檢查元件、箭頭、文字及版面；需要分享時再匯出 PNG、PDF 或 PPTX。
5. 若圖表要長期維護，再導入實際程式或設定來源，使用同步、差異檢查與架構測試功能。

最適合你的起步方式是先用 Agent Skill 依文字生成一張熟悉的工作流程圖，確認編輯與匯出順暢後，再嘗試從專案資料自動建圖。

## 5. 值不值得研究？

**很適合需要反覆更新技術圖與流程圖時實際使用。** 可編輯檔、來源匯入與增量同步比單次生成圖片更有價值。若只是偶爾畫簡單草圖，直接用 draw.io 手動畫可能更省設定時間。
