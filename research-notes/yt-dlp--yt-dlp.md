# yt-dlp｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/yt-dlp/yt-dlp/blob/master/README.md)；查閱日期：2026-10-09。

## 1. 這是什麼？

yt-dlp 是跨平台的命令列影音下載工具，支援許多網站。你給它可存取的影音網址，它可列出或選擇格式，下載影片、音訊、字幕及縮圖，並透過選項控制檔名、資料夾與後處理。它是下載與整理素材的底層工具，沒有內建完整的桌面圖形介面；MeTube 等其他專案會用它提供網頁操作介面。

## 2. 對我有什麼用？

如果你需要保存自己有權下載的公開影片、課程、訪談或英文學習素材，yt-dlp 可把影音與字幕放到可控的本機資料夾。你也能用固定的檔名規則和設定檔，讓後續轉錄、筆記或歸檔流程更一致。它適合可重複、可自動化的下載；若你偶爾才下載一支影片，命令列選項可能顯得繁瑣。下載前仍需確認來源授權與平台條款，並保留來源網址供日後查證。

## 3. 使用情境

- **英文練習**：下載可合法保存的影片與字幕，供離線精聽。
- **知識保存**：把自己製作或取得授權的影音素材連同基本資訊歸檔。
- **批次整理**：為多支影片統一格式、檔名與儲存路徑。
- **其他工具底層**：由圖形介面或自動化腳本呼叫下載功能。

## 4. 我要怎麼用？

1. Windows 可從官方 Release 取得獨立執行檔；也可依 README 用 pip 等方式安裝。
2. 先用一個有權下載的網址執行基本命令，確認網站支援與下載結果。
3. 若想要指定品質、只取音訊或下載字幕，再依 README 增加對應選項；需要合併或轉檔時安裝 FFmpeg。
4. 確認結果後再設定輸出模板與設定檔，固定儲存位置和檔名。
5. 定期更新工具；網站格式改變時，舊版可能暫時無法下載。

初次使用先做單一網址下載即可，無須一開始閱讀全部選項。

## 5. 值不值得研究？

**若有合法影音歸檔或離線學習需求，很適合實際使用。** 它功能廣、容易納入自動化，但需要熟悉少量命令與網站限制。
