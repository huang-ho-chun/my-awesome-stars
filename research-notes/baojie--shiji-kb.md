# 史記知識庫｜GitHub 專案導覽

> 來源：[baojie/shiji-kb](https://github.com/baojie/shiji-kb) README；查閱日期：2026-10-19。

## 1. 這是什麼？

這是把《史記》轉成**可互動閱讀的知識庫**的專案。它對古籍文字標註人物、地名等實體和歷史事件，提供章節閱讀、詞條跳轉、段落連結、時間線與 Wiki。對一般讀者，它是探索《史記》的閱讀網站；對知識工程研究者，它也是一個如何將大型文本轉成連結知識的實例。

## 2. 對我有什麼用？

若你想查某位人物在《史記》哪些篇章出現、沿著事件和關係閱讀，這個網站比從頭翻一大段原文更容易探索。你也能參考它把「原始文本 → 實體標註 → 概念頁 → 互相連結」組織成知識庫的方式，思考自己的資料整理與 Obsidian 筆記連結。

不過它是《史記》專用資料庫，不能直接拿來匯入任意個人筆記。README 也列出自動標註可能出錯的原因及已知問題；做嚴肅史實判斷時應回到原文和可靠史料。

## 3. 使用情境

- **歷史讀者**：從人物或篇章進入，沿著高亮詞條和時間線探索事件。
- **內容創作者**：找相關人物與事件線索，再查證史料。
- **知識庫設計者**：觀察章節、段落、實體與 Wiki 如何互相串連。

## 4. 我要怎麼用？

先開啟 README 提供的 [線上閱讀器](https://baojie.github.io/shiji-kb)，挑熟悉的〈項羽本紀〉或〈孔子世家〉試讀；點擊人名、地名或段落連結，看看跳轉和分享是否符合你的用途。想看整體關係，可再看互動時間線或 Wiki。

若要本機研究或自行產生章節 HTML，README 提供 clone、安裝依賴與生成檔案的步驟；只是閱讀不需要先安裝。若打算重用內容，也要查看 repo 所列的授權條件。

## 5. 值不值得研究？

**可以先收藏，有閱讀古籍或知識圖譜需求時再深入。** 現成網站就能快速體驗；對你更普遍的價值，是觀察有來源的長篇文本如何變成可追溯的連結知識。
