# Shisei 姿勢｜GitHub 專案導覽

> 專案：https://github.com/wquguru/shisei

## 1. 這是什麼？

Shisei 是原創人偶姿勢參考圖庫。README 記載四個系列、280 組姿勢，每組規劃正面、斜側、側面、上方與下方五種視角；品質檢查未通過的視角會留空。圖庫另提供部分姿勢的黏土質感、深度與法線圖，可供支援 ControlNet 的工作流程參考。

網站提供日文、中文、英文、韓文名稱、分類與視角篩選；成人暗示性系列預設模糊。圖片採 CC0 1.0，程式與文件採 Apache 2.0；姿勢清單的選擇、編號與分類另有來源及授權界線，應參考 NOTICE。

## 2. 對我有什麼用？

在 AI 繪圖或分鏡前，可用不同角度的人偶線稿指定人物姿勢和鏡頭方向，減少僅靠文字描述姿勢的歧義。同一姿勢的多角度圖也適合規劃連續鏡頭。圖庫提供可下載的線稿包；多數使用者無需複製整個圖片 repository。

## 3. 使用情境

- 選一張姿勢線稿作為 AI 圖像工具的姿態參考。
- 為同一人物安排正面、側面與俯視鏡頭。
- 將深度或法線圖放入支援相應 ControlNet 模式的工作流程。
- 在四語名稱與分類中搜尋動作，整理分鏡參考。

## 4. 我要怎麼用？

1. 開啟 README 所連結的 Gallery，依系列、分類及角度瀏覽。
2. 選擇通過品質檢查的視角，下載線稿或 Release 中的套件。
3. 在圖像工具上傳參考圖，再用提示詞補充臉部、服裝與背景；需要時使用相應深度或法線圖。
4. 若要在本機部署 Gallery，可依 README 執行 `tools/build_site.py` 並啟動靜態伺服器。

素材為無臉人偶或 AI 產生的成人形象。README 明示不應用於描繪真實人物、未成年人或露骨內容；使用姿勢清單本身時也應留意 NOTICE 的來源說明。

## 5. 值不值得研究？

若常需要穩定的人物姿態和多角度構圖，值得試用。先從 Gallery 選一組姿勢，在常用的圖像工具中對比有無參考圖的成果；若需要更細的引導，再下載深度或法線素材。圖庫不是完整角色設計工具，角色外觀仍需另行提供。
