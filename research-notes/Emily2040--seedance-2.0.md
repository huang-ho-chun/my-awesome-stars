# Seedance 2.0｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/Emily2040/seedance-2.0/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

影片分鏡與參考素材規劃的 Agent Skill。README 清楚區分提示與分鏡規劃和實際影片生成：此 Skill 負責描述鏡頭、綁定參考、延續已核可片段，影片服務及費用由使用者另行提供。

## 2. 對我有什麼用？

它適合把影片構想拆成鏡頭、固定人物與參考素材規則，幫你在生成前明確定義成品。實際影像仍需另接影片生成服務，因此先確認所需服務和費用。

## 3. 使用情境

若你要做家人紀念或活動短片，它可協助保持主角與鏡頭連續性；對目前測試或知識庫任務關聯有限。

給定一段無敏感素材的 10 秒影片構想，要求它寫鏡頭、固定元素與下一段延伸條件；先評估腳本是否可交給你選定的生成服務。

## 4. 我要怎麼用？

依 README 複製專案，使用提供的 install_codex_skill.py 將 Skill 放入 Codex 的 user 或 project skills 位置；重新載入後從 Start Here 提示語開始，選擇相應工作流，核對輸出的提示與參考素材。生成影片需另接服務。

README 明確說明 Skill 只產出導演式提示，真正影片由外部供應商生成並計費；Codex 安裝腳本可選 user 或 project scope。先用 project scope 試一個鏡頭最容易清理。

## 5. 值不值得研究？

可以先收藏，以後可能用到：只有實際要做 AI 影片時才需安裝，生成服務與費用另計。
