# Motion Prompt｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/showheyohtaki/motion-prompt/blob/main/README.md)；查閱日期：2026-10-16。

## 1. 這是什麼？

Motion Prompt 是動態設計的「名稱與範例」資料庫，也是可供 Codex 使用的 Skill。它把動畫、鏡頭運動、UI 元件、網頁效果及照片風格整理成編號項目；每項都有動態示範、一句解釋與可直接用來請 AI 製作的說法。README 目前列出五組、共 120 項。它幫你找到準確的視覺語彙，並讓 Agent 依所選範例在現有影片或網站專案裡重做效果；它本身不是一鍵影片生成器。

## 2. 對我有什麼用？

當你知道「標題要有動感」卻說不出要怎麼動時，可以先看畫廊挑範例，再把編號交給 Codex。比起反覆寫「做得更有質感」，你能指出哪個元件、多久、往哪個方向移動。這對簡報開場、教學影片、網站或 UI 原型都可能有用。

資料庫目前主要有英文與日文名稱；專案也提供把名稱庫翻成中文或建立自己領域版本的提示詞。若只想查名字，不安裝 Skill 也能直接看畫廊與清單。

## 3. 使用情境

- **影片剪輯溝通**：挑選轉場、鏡頭或標題動畫，提供給 AI 或剪輯者。
- **網站與 UI**：用編號範例指定按鈕、區塊或頁面進場效果。
- **生成影片提示詞**：將示範動作轉述成給影片模型的明確指令。
- **建立自己的詞庫**：把某個熟悉領域的常用效果做成「名稱＋範例」資料庫。

## 4. 我要怎麼用？

1. 先打開 README 提供的線上畫廊，看五組示範並挑幾個編號。
2. 若只是找靈感，把名稱、時長、強度和動作方向寫進給 AI 的需求即可。
3. 若想讓 Codex 讀取所選範例並套到專案，準備 Node.js 18 以上，依 README 用 `npx skills add showheyohtaki/motion-prompt` 安裝 Skill。
4. 在 Codex 請它開啟 motion-prompt library；在畫廊按 Pick，選完後按 Send to AI，再說明要修改的影片或頁面。
5. 檢查生成結果是否與示範的節奏相符，並確認文字、色彩與圖片已換成自己的素材。

## 5. 值不值得研究？

**常需描述動態畫面時很值得收藏並使用。** 它最有價值的是把模糊的視覺想法變成可指認的範例；若目前不做影片、UI 或動態網頁，先收藏即可。
