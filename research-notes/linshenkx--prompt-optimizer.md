# Prompt Optimizer

> 專案：[linshenkx/prompt-optimizer](https://github.com/linshenkx/prompt-optimizer)｜依據：專案 README（2026-10-29 查閱）

## 1. 這是什麼？

這是用 AI 改寫、測試、比較與收藏提示詞的工具，提供線上網頁、桌面 App、Chrome 擴充及自行部署選項。它支援系統/使用者提示詞優化，也有模型比較與圖片提示詞模式；最終品質仍要看你實際用的模型與任務。

## 2. 對我有什麼用？

你可以把常用的研究、文件整理或 Coding Agent 指令放進去，產生不同版本並用同一個實例比較輸出，再留下有效版本。對你需要穩定重複的工作提示詞，比單次請 AI『幫我改好』更容易檢驗。

## 3. 使用情境

適合持續調整同一類任務提示詞、比較不同模型或保留範本。對一次性的簡短提問，設定模型與評估流程可能不划算。

## 4. 我要怎麼用？

最快可打開 README 提供的線上版，在 Model Manager 設一個可用模型，貼上原提示詞並試優化和比較；線上版資料存在瀏覽器。若要在 Windows 本機用，可從 Releases 安裝桌面版，再連接自己的模型或服務；自架選項另有 Docker 與 Web 部署文件。

## 5. 值不值得研究？

很適合你需要重用 Agent 指令與檢查提示詞效果的工作。建議先用一個已有輸入與預期結果的任務試前後版本，確認是否真的改善。
