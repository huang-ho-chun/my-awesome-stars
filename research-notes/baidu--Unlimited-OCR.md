# Unlimited-OCR｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/baidu/Unlimited-OCR/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

偏模型與推論程式的 OCR 專案，README 提供 Transformers、vLLM、SGLang 路徑，並區分單張圖片與多頁 PDF 的設定。它更像可整合進辨識管線的模型，不是一般使用者開箱即用的桌面 OCR。

## 2. 對我有什麼用？

若既有 OCR 在複雜頁面失準，可作為比較候選；但導入推論環境、模型與硬體的成本需要先衡量。對你的手寫日記，任何輸出都應保留不確定標記並逐頁對照原圖。

## 3. 使用情境

從幾張有繁體字、表格與手寫字的代表頁建立基準集，與目前工具比較漏字、錯字和版面順序；不要以單一漂亮案例判定能替代現有流程。

## 4. 我要怎麼用？

先閱讀 README 的 Inference 範例並取得所需模型。一般試驗可從 Transformers 的單圖推論開始；大量或服務化需求再評估 vLLM、SGLang。PDF 路徑會先轉頁影像，需確認頁碼對應與輸出保存方式。

## 5. 值不值得研究？

評估時也要記錄模型大小、推論時間、顯示記憶體需求與字形語種，避免只看展示圖片。README 的範例著重推論方式，尚不足以證明它對你特定的繁體手寫材料有穩定優勢，需自行建立人工核對的樣本。

**可以先收藏，以後可能用到。**只有當既有 OCR 明顯不足且願意維護模型服務時，深入投入才划算。
