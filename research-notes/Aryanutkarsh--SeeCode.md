# SeeCode｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/Aryanutkarsh/SeeCode/blob/main/README.md)；查閱日期：2026-10-13。

## 1. 這是什麼？

SeeCode 是給 Codex 等 Coding Agent 使用的圖解工具。Agent 先把內容寫成簡短的結構化規格，SeeCode 再排版並產生會動、可探索的圖。主要成品是單一 HTML 檔：讀者可以滑過節點看連線、點選元件看細節、逐步播放流程；也能匯出 SVG、PNG、GIF 或 MP4。它支援架構圖、流程圖、循序圖、資料圖表等多種類型，亦可做靜態圖。

它可以重新繪製 Mermaid、draw.io、Excalidraw、SQL、CSV 等既有資料，或先掃描程式庫再建立圖。匯入是依內容重新排版，來源的顏色、字型與座標不會原樣保留。

## 2. 對我有什麼用？

你可以把 Obsidian 知識整理流程、Agent 任務步驟或某個程式庫的運作方式做成可點擊的說明圖。例如展示「收藏資料如何擷取、分類、寫入筆記與檢查」，讓讀者逐步看資料流向。若要寫 README 或做簡報，再從同一張圖匯出清晰的 SVG 或 PNG。

相較於只貼一張圖片，互動 HTML 適合用來解釋複雜流程；對外分享前仍要確認圖中的步驟與資料來源正確。資料圖表可從 CSV 或 JSON 讀數值，避免要求模型憑記憶填數字。

## 3. 使用情境

- **專案導覽**：把元件、依賴及請求路徑做成可逐步探索的架構圖。
- **工作流程說明**：展示資料收集、分類、審核與歸檔的先後關係。
- **教學與簡報**：輸出靜態圖片或動態 GIF、MP4，配合講解節奏。
- **重繪現有圖**：將 Mermaid 或 draw.io 圖簡化，改成適合另一群讀者的版本。
- **資料圖表**：由 CSV、JSON 產生可查閱的圖表。

## 4. 我要怎麼用？

1. 準備 Node.js 20 以上，依 README 在 Codex 使用 `npx skills add Aryanutkarsh/seecode -g` 安裝；也可選擇其 Codex plugin 安裝方式。
2. 先請 Agent 畫一個你熟悉的小流程，說明目標讀者、要強調的路徑與輸出位置。
3. 開啟產生的 HTML，檢查節點、箭頭、文字與互動是否符合原資料；發現錯誤就要求修改。
4. 需要貼進 README 或簡報時，從圖內的 Export 選單輸出 SVG、PNG、GIF 或 MP4。命令列匯出圖片與影片時可能需要 Chrome 或 Edge。
5. 若已有 Mermaid、draw.io 或資料檔，再試匯入並核對重繪時是否省略了重要內容。

先做一張小圖最容易判斷是否符合你的呈現方式，不必一開始就把整個知識庫畫進去。

## 5. 值不值得研究？

**很適合需要向別人解釋系統或流程時實際使用。** 互動檢視和多格式匯出很有價值；若內容只是簡短清單或單一比較表，直接寫文字會更清楚。
