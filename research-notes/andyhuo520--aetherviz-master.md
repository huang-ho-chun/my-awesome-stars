# AetherViz Master｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/andyhuo520/aetherviz-master/blob/master/README.md)、[SKILL.md](https://github.com/andyhuo520/aetherviz-master/blob/master/SKILL.md)；查閱日期：2026-10-06。

## 1. 這是什麼？

AetherViz Master 是一份教學網頁生成指引，核心檔案是 `SKILL.md`。你向支援 Skill 的 Agent 提供教學主題，它會依指引規劃一個可互動的 HTML 教學頁面。指引建議用 Three.js 呈現立體場景、用 SVG 呈現函數與圖表，並加入公式、解說、學習目標和小測驗。

它適合將牛頓運動、三角函數、行星運動等抽象概念轉成可操作的視覺教材。這個倉庫目前只有 README、Skill 指引和授權檔，沒有預先完成的網站或一鍵生成程式；網頁內容仍需由 Agent 產生並由使用者檢查。

## 2. 對我有什麼用？

你可以用它快速做一頁式教學原型：例如把某個物理現象做成可調速度的動畫，或把數學函數做成有參數滑桿的圖表。若要整理學習筆記、設計課程或向別人解釋抽象觀念，互動頁面可能比靜態截圖更容易展示「改變參數後會怎樣」。

對你目前的用途，較適合把它當成視覺教學 Skill 範本和原型工具。專案所稱的自動辨識、流暢度與教學完整性屬 README 描述；每個生成頁面的概念正確性、控制器效果及手機顯示都需要實際驗證。

## 3. 使用情境

- **學習與複習**：把一個數學或科學概念做成能調整參數的頁面，觀察變化。
- **課堂示範**：讓學生旋轉 3D 模型、查看向量與公式的對應。
- **知識解說**：製作含圖表、步驟說明及小測驗的單頁教材。
- **內容原型**：先用 Agent 生成可操作版本，再由教師或開發者修正內容與視覺設計。

## 4. 我要怎麼用？

1. 閱讀倉庫的 `SKILL.md`，將它放到你所用 Agent 支援的 Skill 位置，或在對話中請 Agent 參照該檔案。README 提供 Claude Code 的呼叫範例。
2. 提供明確主題、目標讀者、要展示的變數及預期互動。例如：「做一個高中程度的牛頓第二定律頁面，可調質量與作用力，並同步更新加速度圖」。
3. 要求 Agent 輸出可開啟的 HTML，檢查 3D 場景、SVG 圖表、公式、按鈕與手機版面；對科學內容再用可信教材核對。
4. 需要分享時，先確認外部 CDN 資源可以載入，再把完成的 HTML 放到適當的靜態網站或課程系統。

README 列出啟動本機伺服器的方式，但目前倉庫根目錄沒有預建的 HTML 網站；應先由 Agent 生成頁面，才有內容可供伺服器展示。

## 5. 值不值得研究？

**有製作互動教材的需求時值得試用。** 它能幫你快速把主題轉成視覺化原型，尤其適合數學、物理和天文。若需要正式教學素材，應保留人工審查：檢查概念、公式、可及性與互動操作，並確認生成網頁依賴的外部資源符合使用環境。
