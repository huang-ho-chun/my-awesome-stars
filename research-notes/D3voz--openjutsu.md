# Openjutsu｜GitHub 專案導覽

> 專案：https://github.com/D3voz/openjutsu

## 1. 這是什麼？

Openjutsu 是以 Next.js 介面控制 ComfyUI 工作流程的本機影片編修專案。README 展示從角色照片替換影片主角、多角色替換、物件修改或移除，以及臉部與色彩後處理。它使用 MiniMax H3、SAM 3.1、視覺描述模型與多個 ComfyUI 自訂節點，並非單一輕量安裝程式。

## 2. 對我有什麼用？

製作實驗性影片或角色視覺原型時，可從原影片保留運鏡、動作與聲音，再替換人物外觀或局部物件。適合測試具體短片效果；輸出品質、連貫性與人物權利仍需人工檢查。

## 3. 使用情境

- 用自有短片及授權角色照片測試單人替換。
- 在多人鏡頭中指定不同角色，觀察每個鏡頭的匹配結果。
- 對小臉或色彩問題使用專案列出的後處理流程。

## 4. 我要怎麼用？

先核對 README 的 Requirements、Custom nodes 與 Models。它要求 NVIDIA GPU、ComfyUI 0.41.2 以上、Node.js 22.6 以上及 Python；README 的測試機為 16 GB VRAM、64 GB 系統記憶體。安裝對應自訂節點與模型後，依「Run it locally」啟動 ComfyUI 及前端。先用短片與單人模式試做，檢查模型檔、記憶體與輸出影格，再提高複雜度。使用人物影像時應取得必要同意。

## 5. 值不值得研究？

若已有 ComfyUI 與足夠 GPU 資源，值得試其本機影片替換流程。若只是偶爾剪輯，模型、節點與硬體成本較高；先用最小範例確認效果再投入安裝。
