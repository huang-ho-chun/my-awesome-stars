# aidlc-workflows 專案指南

來源：[awslabs/aidlc-workflows 官方 README](https://github.com/awslabs/aidlc-workflows/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

跨多種 Coding Agent 宿主的結構化 AI 開發流程。

## 2. 對我有什麼用？

將需求、設計、實作和驗證分成可檢查階段；支援 Codex CLI 等宿主。對你涉及測試、報告與客戶配置的變更，可協助保留決策脈絡。

## 3. 使用情境

選一個小型自動化需求，先記錄輸入、驗收條件與可能影響的腳本，再讓工作流產出方案與修改；比較它增加的紀錄是否真正幫助回顧。

## 4. 我要怎麼用？

依 README 使用對應作業系統的安裝方式，為專案建立設定，於 Codex CLI 以 $aidlc 啟動；讓它選擇工作流後逐階段檢視成果與驗收。先在非客戶資料的 repo 練習。

README 的流程是先安裝、再配置專案，最後由 Codex CLI 的 $aidlc 啟動工作流；同一核心也支援其他 Agent 宿主。可用一個小需求檢查各階段是否留下足夠的驗收證據。

## 5. 值不值得研究？

有特定情境才有用：較大或需多人交接的改動值得用，日常小修可能流程過重。
