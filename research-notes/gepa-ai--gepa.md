# gepa｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/gepa-ai/gepa/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

以 LLM 反思與演化搜尋最佳化文字參數的 Python 框架。

## 2. 對我有什麼用？

可最佳化提示詞、程式片段及 Agent 配置；前提是有可量測的品質指標。你的測試分類或報告摘要若已有標註樣本，較容易驗證效果。

## 3. 使用情境

準備一組已人工標註的故障摘要，先記錄原提示的錯誤率，再用 GEPA 調整並在未參與最佳化的樣本上檢查結果與成本。

## 4. 我要怎麼用？

README 提供 pip 安裝與 Quick Start；先定義待調整文字、評分函式和資料集，再跑簡單提示最佳化。若已有 DSPy 管線，也可看其整合；另有 Agent Skill 入口。

若沒有穩定的評分方式，最佳化可能只是迎合少數範例，對真實資料反而退步。

README 的 Quick Start 分簡單 prompt 最佳化、DSPy 整合和 optimize_anything。先從可重跑的單一提示任務開始，保留未參與最佳化的驗證資料。

## 5. 值不值得研究？

有特定情境才有用：只有任務可測量且重複執行，搜尋帶來的額外模型費用才容易合理化。
