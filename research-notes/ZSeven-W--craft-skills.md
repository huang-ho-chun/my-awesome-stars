# craft-skills｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/ZSeven-W/craft-skills/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

研究與評測驅動的 Agent Skills 集合。

## 2. 對我有什麼用？

README 強調觸發邊界、退出條件、原創案例及前向測試；現有內容偏視覺創作。對你最有用的是 Skill 設計方式，而非一定要安裝所有技能。

## 3. 使用情境

讀其中一個 Skill 的 SKILL.md，檢查它如何定義輸入、完工條件和來源限制；再以相同框架改進自己的報告產生 Skill。

## 4. 我要怎麼用？

依 README 可複製 repo 或指定的 Skill 目錄到宿主技能位置；先看各技能 README 與案例，再跑對應範例。若要貢獻或發布，參考其驗證腳本和發佈標準。

若只借鑑方法，可直接閱讀公開 SKILL.md，不一定要安裝整個技能集合。

README 列出的技能包括 Logo 語意融合、固定角色日記漫畫等，並標示實驗狀態。你可先閱讀其觸發邊界與發佈標準，判斷方法是否適合移植到技術 Skill。

## 5. 值不值得研究？

可以先收藏，以後可能用到：方法值得借鏡，但目前技能主題多偏圖像產出。
