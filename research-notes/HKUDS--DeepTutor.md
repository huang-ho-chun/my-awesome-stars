# DeepTutor

> 專案：[HKUDS/DeepTutor](https://github.com/HKUDS/DeepTutor)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是可自架的個人化 AI 學習平台，結合教材閱讀、知識庫、問答、學習路徑、測驗與學習紀錄。它是一套較完整的應用與 CLI，不只是單一聊天提示詞。

## 2. 對我有什麼用？

你可以把英文教材、技術文件或課程資料放進工作區，請 AI 依材料解說、出題並追蹤進度。對你已有的 Obsidian 與學習筆記，較有用的是把資料轉成互動練習，但需要評估維護與模型費用。

## 3. 使用情境

適合長期學一門技術、依文件建立學習路徑、對自己的資料做問答與複習。不適合只想偶爾問一題、且不願維護自架服務的人。

## 4. 我要怎麼用？

先看官方文件與 README 的 Get Started，可用 Docker 快速試跑；再設定模型服務，建立內容工作區並加入一小份教材，試問答、閱讀和測驗。若偏好自動化，可再看 CLI；正式使用前確認資料儲存位置與模型服務成本。

## 5. 值不值得研究？

有特定情境才有用，但很值得試一個小教材。若學習路徑與問答真的幫你持續複習，再投入完整部署。
