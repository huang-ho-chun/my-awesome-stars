# superpowers 專案指南

來源：[obra/superpowers 官方 README](https://github.com/obra/superpowers/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

由一組可組合 Skills 與起始指令構成的 Agent 開發方法。

## 2. 對我有什麼用？

涵蓋需求釐清、計畫、實作、除錯和驗證。你已在 Codex 使用相關技能，適合檢查哪些步驟真正提高品質，避免形式流程蓋過任務。

## 3. 使用情境

以一個跨多檔的小型腳本改動測試完整流程，觀察設計討論、檢查點與測試是否能抓到實際問題；再依任務大小調整使用程度。

## 4. 我要怎麼用？

README 對 Codex App/CLI 列官方 plugin marketplace 安裝路徑，也支援多個其他宿主。安裝後閱讀 Basic Workflow 與各 Skill 的觸發條件，在單一 repo 試用並核對實際修改。

README 將 Codex App/CLI 與其他宿主分開列安裝方法，基本流程從需求釐清與設計走到實作驗證。你可先在跨檔案任務使用，並記下哪些檢查點確實擋住錯誤。

## 5. 值不值得研究？

很適合我，可以實際使用：與你的審核、保存和驗證習慣一致，可選擇性採納。
