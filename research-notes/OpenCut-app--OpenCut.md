# OpenCut｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/OpenCut-app/OpenCut)；查閱日期：2026-09-16。

## 1. 這是什麼？

OpenCut 的目標是提供免費、開源、可在網頁與多平台使用的影片編輯器。專案 README 明確說明目前正從底層重寫；現階段可用的版本是連結到的 **OpenCut Classic**，新版本規劃 Editor API、外掛、無介面批次輸出與 Agent 串接等能力。因此它目前兼具可用舊版與正在開發的新平台兩種脈絡。

## 2. 對我有什麼用？

如果你偶爾要剪旅行或活動影片，可以先看 Classic 的介面是否合用。若你想把剪輯接入 Codex 自動化，README 列出的 API 與無介面模式仍屬重寫方向，不能當作已經可用的功能安排工作。

## 3. 使用情境

- **一般剪片**：先使用目前可用的 Classic 版試切、轉場與匯出。
- **開源編輯器觀察**：追蹤新版本的跨平台與外掛方向。
- **未來自動化**：等新版本功能正式可用後再評估 Agent 接入。

## 4. 我要怎麼用？

1. 先開 README 提到的 Classic 線上版本或對應專案，使用一段測試素材完成編輯與匯出。
2. 若想參與新版本開發，再依此 repo 的 Development 指南準備工具；不要把開發環境當成一般使用者的安裝步驟。
3. 檢查匯出品質、功能限制和本機／雲端處理方式後再決定是否使用。

## 5. 值不值得研究？

**可以先收藏，以後可能用到。** 你若有剪片需求可試 Classic；新 OpenCut 的自動化能力仍在重寫中。
