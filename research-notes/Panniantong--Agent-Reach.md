# Agent-Reach 專案指南

來源：[Panniantong/Agent-Reach 官方 README](https://github.com/Panniantong/Agent-Reach/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

替 Agent 配置多平台網路存取能力的安裝與檢查工具。README 列出不同網站的優先與備援後端，提供環境診斷、預覽以及明確允許系統安裝的模式；部分平台需要帳號或 cookie。

## 2. 對我有什麼用？

跨平台資料研究需要知道每個來源是否可用、是否需要額外依賴。這個工具可協助盤點環境；對你處理私人社群資料，登入狀態和資料保存仍應保留人工控制。

## 3. 使用情境

你做產品與資料研究時可能遇到網站取用差異；它可作為平台能力盤點，但不應把登入資料交給未審核的自動流程。

先用公開頁面測試搜尋、抓取與故障回報，對照官方網站結果；對私人 Facebook／Instagram 檔案仍延用既有人工登入與本地保存流程。

## 4. 我要怎麼用？

依 README 安裝 Python 套件後，先跑 agent-reach install 的預設唯讀檢查與 --dry-run，閱讀將安裝的外部工具；只有確認後才使用 --system。逐一設定需要的來源，使用 doctor 或對應檢查命令驗證。

README 將 install 的預設模式定為環境檢查，--dry-run 顯示預計動作，只有 --system 才安裝外部依賴。這三個層級可讓你先了解各網站需要什麼，再選擇是否改動系統。

## 5. 值不值得研究？

有特定情境才有用：需要跨站研究時可試診斷能力；只查官方文件時無須擴充平台。
