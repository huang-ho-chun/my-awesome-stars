# Pokémon Heartfelt Gold｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/Trinsic64/Heartfelt-Gold/blob/HEAD/README.md)；查閱日期：2026-11-20。

## 1. 這是什麼？

Pokémon Heartfelt Gold 是《Pokémon HeartGold》的非官方、非商業 ROM hack patch。它在 HeartGold Retiled 的地圖重製基礎上，調整野生寶可夢遭遇、訓練家隊伍、靜態遭遇及 hg-engine 的便利功能。Repository 只提供 patch、地圖資源與指南，不包含 Nintendo DS ROM、解包 ROM 或 DSPRE 專案。

## 2. 對我有什麼用？

若已合法擁有指定的美版 HeartGold ROM，可用 patch 體驗重新設計的地圖、遭遇與遊戲調整，並透過互動式玩家指南查詢招式、特性、進化、商店、遭遇及訓練家資料。對 ROM hacking 有興趣時，也可閱讀 repository 的地圖與矩陣資源說明；部分視覺錯誤與未完成細節仍可能出現。

## 3. 使用情境

- 在模擬器或 Nintendo DS 硬體上體驗重新設計的 HeartGold 流程。
- 依螢幕與硬體選擇預設或 Zoomed In patch。
- 使用線上或離線玩家指南查找改動後的遊戲資料。
- 研究地圖資源與 patch 發布方式，並回報具體位置的視覺問題。

## 4. 我要怎麼用？

先自行準備合法取得、未修改且雜湊符合 README 列值的《Pokémon HeartGold (USA)》ROM，並備份原檔。從 Releases 下載一個版本的 `.xdelta` patch，使用 xDelta UI 或 RomPatcher.js 套用到乾淨 ROM；預設版偏向有內部解析度放大的 PC 模擬器，Zoomed In 偏向原生解析度硬體或模擬器。不要疊加多個 patch，更新前也應備份遊戲存檔。

## 5. 值不值得研究？

若喜歡 HeartGold 或想了解完整 ROM hack 如何提供 patch、玩家指南與地圖資源，值得研究。它仍是進行中的同人專案，使用前要接受可能的地圖瑕疵，並嚴格遵守合法 ROM 與原始遊戲資產的限制。
