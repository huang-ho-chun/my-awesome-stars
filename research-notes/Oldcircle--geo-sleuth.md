# geo-sleuth｜GitHub 專案導覽

> 專案：https://github.com/Oldcircle/geo-sleuth

## 1. 這是什麼？

geo-sleuth 是讓 Agent 推查照片拍攝位置的 Skill。它結合照片中可見的橋梁、山脊、道路或樹木等線索，查詢 OpenStreetMap、地形高程、衛星影像和街景資料；腳本篩選候選位置，Agent 檢視較有希望的結果。輸出包含推定座標、相機朝向、誤差半徑、信心等級與證據圖。

README 展示了鐵路橋與山脊、沙漠電線與地形、街道樹木與街景等案例。案例成績是特定照片與模型執行紀錄，不能視為每張照片都能達到相同精度。

## 2. 對我有什麼用？

若要核對一張照片的地點，它提供可追溯的搜尋流程和證據檔，而不只給一個看似合理的地名。對研究 Agent 工作流程而言，也能觀察如何先用程式大量篩選，再讓模型判讀少數候選，並清楚標示位置誤差。

## 3. 使用情境

- 查核照片宣稱的拍攝位置，對照地形、建物或道路形狀。
- 在沒有 GPS、招牌或車牌的照片中，嘗試用山脊和地理資料縮小範圍。
- 為開放資料或影像研究建立可複查的線索與證據圖。
- 比較同一張照片在不同線索與搜尋區域下的候選結果。

## 4. 我要怎麼用？

1. 依 README 使用 `npx skills add Oldcircle/geo-sleuth` 安裝到支援 Agent Skill 的工具。
2. 準備 Python 3.10 以上、`uv` 與 `curl`；首次使用先執行 Skill 的 `scripts/doctor.py` 檢查環境，必要時加 `--network` 檢查資料服務。
3. 提供照片並請 Agent 尋找拍攝位置；若知道大致區域，可將它作為線索，但仍需由資料核對。
4. 檢視輸出的座標、方向、誤差半徑與證據圖，確認每項結論有對應的查詢或檔案。

資料查詢需要網路；資料覆蓋、模型判讀與服務可用性都會影響結果。對涉及私人住所或他人行蹤的照片，應先評估隱私與使用目的。

## 5. 值不值得研究？

若常做地理影像查核或想研究有證據鏈的 Agent，值得閱讀。建議先用已知地點的公開照片測試，觀察候選縮減與誤差估計；若只需要辨識知名地標，完整安裝與地形計算的成本可能較高。
