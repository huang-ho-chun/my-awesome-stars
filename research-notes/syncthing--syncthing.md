# syncthing｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/syncthing/syncthing)；查閱日期：2026-09-16。

## 1. 這是什麼？

Syncthing 是讓多台裝置持續同步檔案的開源工具，設計目標是由你控制資料和同步對象，而不是先把所有檔案放到單一雲端帳戶。它在裝置上背景執行，配合 Web 管理介面或其他 GUI 設定資料夾與對等裝置。它是同步工具，不等於歷史版本完整的備份系統。

## 2. 對我有什麼用？

你有 Windows 電腦、Obsidian 筆記和本機工作資料。若要在自己控制的兩台裝置間同步非機密檔案，Syncthing 可能省去手動複製；但你的 Obsidian vault 也可能同時用 Git 或其他同步方式，導入前要釐清每個資料夾的唯一同步策略，避免重複改寫。

## 3. 使用情境

- **兩台電腦的筆記同步**：讓指定資料夾自動保持一致。
- **本機與家用設備**：同步照片或文件，不必每次手動傳輸。
- **多裝置工作流**：只同步需要的子資料夾，避免把暫存輸出也帶過去。

## 4. 我要怎麼用？

1. 從官方文件的 Getting Started 取得各裝置的安裝方式，先用測試資料夾試用。
2. 在兩台裝置互相加入對方，設定資料夾方向與同步規則。
3. 建立、修改、刪除少量測試檔，觀察衝突和刪除行為；確認後再考慮正式筆記，並保留獨立備份。

## 5. 值不值得研究？

**有特定情境才有用。** 需要跨裝置持續同步時很實用；如果目前只有單一主要裝置或已有穩定同步方式，暫時不必加入新層。
