# M3E Canvas｜GitHub 專案導覽

> 專案：https://github.com/lnkiai/m3e-canvas

## 1. 這是什麼？

M3E Canvas 是在瀏覽器中草擬 Material 3 Expressive 介面的開源畫布。可拖放元件、連結多個手機或桌面畫面、預覽點擊流程，並把設計轉成給 Coding Agent 的文字提示。README 說基本功能在瀏覽器中運作，無須帳號或伺服器；可選的 AI 協助需要自備金鑰。

## 2. 對我有什麼用？

在請 Agent 開發介面前，可先用可點擊的草稿釐清元件、畫面跳轉、色彩與操作邏輯，再複製生成的提示詞。這比只用文字描述更容易發現流程缺口，但生成的程式仍須自行檢查。

## 3. 使用情境

- 草擬手機 App 的多畫面流程並實際點選測試。
- 比較手機與桌面版的元件安排，將同名畫面寫成兩種寬度的需求。
- 將畫布、元件行為註記與主題設定交給 Codex 等工具實作。

## 4. 我要怎麼用？

開啟 README 所連結的 [線上畫布](https://lnkiai.github.io/m3e-canvas/)。拖入按鈕、清單等元件，設定文字與點擊目標，建立其他畫面並用 Preview 試走流程。確認後複製整個設計或單一畫面的提示詞，貼到所用 Coding Agent。可選的 AI 協助會從瀏覽器直接向所選供應商發出請求；啟用前先確認金鑰與資料使用範圍。

## 5. 值不值得研究？

若常用 AI 協作製作介面，值得用一個小型流程試驗。它特別適合先確認 Material 3 Expressive 的畫面與互動；實際成品的版面、無障礙及跨裝置表現仍需驗收。
