# RuView｜GitHub 專案導覽

> 專案：https://github.com/ruvnet/RuView

## 1. 這是什麼？

RuView 是使用 WiFi Channel State Information（CSI）與 ESP32 感測節點研究空間感知的開源平台。README 展示有人偵測、活動辨識、呼吸與心率估計、姿勢推測，以及與 Home Assistant 等智慧家庭系統整合的方向。它仍是 beta 軟體；README 明列韌體及 API 可能改變，並指出無攝影機姿勢估計的準確度有限。

## 2. 對我有什麼用？

若想研究不架攝影機的房間佔用感測，這個專案提供從硬體節點、資料收集到自動化整合的參考。適合做實驗與原型，不能把其生命徵象或跌倒風險輸出當作可靠的醫療或安全警報。

## 3. 使用情境

- 在可控環境測試房間有人與移動狀態，觀察 WiFi 訊號變化。
- 將測試結果接入 Home Assistant，驗證智慧家庭規則。
- 比較單節點與多節點的空間解析度，記錄誤報與漏報。

## 4. 我要怎麼用？

先讀 [user guide](https://github.com/ruvnet/RuView/blob/main/docs/user-guide.md) 與 ESP32 節點文件，選擇示範或實際硬體路徑。實際量測需要相容的 CSI 裝置、部署與校準；README 說原始 ESP32、ESP32-C3 不支援，單一節點的解析度有限。先用公開示範和自己的測試資料驗證一項簡單的有人偵測，再考慮智慧家庭整合。涉及人體資料時，先取得場域中的知情同意。

## 5. 值不值得研究？

若關心無攝影機感測與邊緣裝置，值得研究其實驗流程與限制。若目標是可直接部署的健康監測，現階段應審慎：README 對姿勢精度與真實資料驗證仍有明確保留。
