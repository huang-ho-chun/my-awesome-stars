# 動手學大模型（Lordog/dive-into-llms）

資料來源：[官方 README](https://github.com/Lordog/dive-into-llms/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

由大學課程講義延伸的免費中文實作教程。README 把微調與部署、提示學習與思維鏈等主題列成表格，提供課件、教學文件及 Notebook／腳本，並持續加入新主題。它是多條實驗路線的集合，各章環境與硬體條件可能不同，不能把整個倉庫視為一鍵可跑的課程。

## 2. 對我有什麼用？

若你想從實際程式理解 API 呼叫、提示方法和模型輸出，這份材料比只讀概念更貼近你熟悉的 Python 工作方式。對你現階段最有用的是低門檻的提示與推論章；微調、部署或進階研究應在有明確產品需求時再投入。

## 3. 使用情境

例如準備讓模型分類測試失敗原因，可選提示學習一章，看示例如何組織任務、上下文和輸出格式，再用幾筆已匿名化的失敗訊息做小實驗。比較不同提示下是否能穩定留下原始證據與「無法判定」，把結果納入人工覆核，不以課件中的效果當作你資料上的保證。

## 4. 我要怎麼用？

先在 README 的教程目錄選一個主題，依連結讀該章課件與 README；若要操作，再開同列 Notebook／腳本，照章節要求準備 Python 相依套件、模型或 API。先跑倉庫提供的例子，確認輸出符合教學描述，再替換成自己的非敏感樣本。README 沒有跨全章統一的安裝步驟，必須逐章查要求。

## 5. 值不值得研究？

有特定情境才有用：有實驗素材可直接觀察概念如何落地。先選一章完成並記錄成本與困難；若只需使用 Codex，不必把整套微調和部署內容排進近期計畫。
