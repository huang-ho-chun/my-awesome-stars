## 1. 這是什麼？

chinese-novelist-skill 是引導 AI 寫中文長篇小說的 Agent Skill。它先問題材、主角和核心衝突，再可選擇補充世界觀、視角與章數；接著建立大綱、人物檔案和寫作計畫，逐章產出內容，最後檢查字數與連貫性。README 描述可寫 10 至 50 章，支援中斷續寫、偏好記錄及多種寫作模式。它是創作工作流程，不是現成的出版平台。

## 2. 對我有什麼用？

若你想把故事點子發展成長篇初稿，它能幫你先定人物與衝突，避免寫了幾章後失去方向。每章獨立成 Markdown，方便你之後在自己的筆記或編輯環境裡修改。對你的家庭回憶或個人紀錄，則應先判斷是否真的要改寫成虛構小說；它的「每章衝突、結尾留懸念」規則會改變原始素材的性質。

它的自動檢查可發現篇幅與部分前後不一致問題，但不等於文學品質保證。人物、語氣和細節仍需要你審稿。

## 3. 使用情境

- **從點子到初稿**：先確定題材、主角、衝突，再寫出完整章節。
- **連載規劃**：用章節大綱、人物檔案及懸念安排維持方向。
- **中斷後續寫**：依已存的計畫與章節摘要接回創作。
- **風格實驗**：以同一個大綱試寫不同敘事語氣或視角。

## 4. 我要怎麼用？

1. 依 README 用 `npx skills add PenglongHuang/chinese-novelist-skill` 安裝，並確認 Skill 已放在你使用的 Agent 可讀的位置。
2. 提供一個小說點子，回答必要的題材、主角及核心衝突問題；其他設定可以稍後補。
3. 先審閱大綱、人物檔案和章數，再決定串行或其他寫作模式。初次使用建議先採串行、少量章節。
4. 讓 Agent 寫一兩章試讀，檢查人物動機、語氣與事實連續性，再決定是否繼續整部作品。
5. 將輸出的 Markdown 章節另行編修，保留你認可的版本。

## 5. 值不值得研究？

**有長篇小說創作計畫時才值得投入。** 它能降低規劃與維持進度的負擔；若目的是忠實整理真實筆記或寫短文，這套網文式長篇流程並不合適。
