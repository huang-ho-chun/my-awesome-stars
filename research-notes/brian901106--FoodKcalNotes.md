# FoodKcalNotes

> 專案：[brian901106/FoodKcalNotes](https://github.com/brian901106/FoodKcalNotes)｜依據：專案 README（2026-10-29 查閱）

## 1. 這是什麼？

這是繁體中文、本機運行的飲食熱量日誌 PWA，針對台灣常見食物設計。你可拍照、選照片或輸入文字；AI 辨識品項與份量，熱量資料優先取自營養標示、本機食物庫或可核對的網路來源，再由程式依重量計算。它是記錄與估算工具，照片推測的份量仍可能不準。

## 2. 對我有什麼用？

如果你想掌握每天吃了什麼，可把手機拍的餐點記到自己電腦上的日誌，查看每日總量並修正重量或食物名稱。重複餐點會累積到本機食物庫，後續可減少重新查詢；不設定 AI 也能手動記錄。

## 3. 使用情境

適合在意餐點紀錄、想檢查估算依據、常吃台灣早餐或小吃的人。若你只想偶爾查單一食物熱量，自架服務的成本可能較高。

## 4. 我要怎麼用？

先確認電腦有 Node.js 24 以上；Windows 依 README 下載專案後執行 `start.bat`，打開本機頁面。先手動記一餐，再選擇設定自己的 ChatGPT 登入或 Claude API 供照片辨識；檢查每項來源與克數，必要時修正並匯出 JSON 備份。手機連線可另外設定 Tailscale。

## 5. 值不值得研究？

有特定情境才有用。若你希望長期記錄飲食、自己保管資料，值得試用；任何熱量與減重推估都應視為估算，不能代替個別健康建議。
