# Harness Engineering 學習指南｜GitHub 專案導覽

> 依 [專案 README](https://github.com/deusyu/harness-engineering) 於 2026-09-16 整理；著重用途與使用判斷。

## 1. 這是什麼？

這是一份關於 Harness Engineering 的中文學習資料庫，彙整概念、研究文章、翻譯與實作路線。它探討如何為長時間工作的 AI Agent 提供工具、上下文、檢查和控制，使成果更可靠；並非上一項 Harness 公司的 DevOps 產品，也不是一鍵安裝的 Agent 外掛。

## 2. 對我有什麼用？

你已在調整 Codex 的 Skills、工作規範與自動化流程。這份指南可幫你理解哪些改進應放在提示詞、上下文、工具介面或驗證環節。例如一個報告任務經常跑偏時，可以先找出缺的是輸入資料、明確的驗收標準，還是失敗後的恢復步驟。

## 3. 使用情境

- **方法學閱讀**：建立 Agent 工作環境的整體概念。
- **現有流程回顧**：用一個失敗任務對照指南，找出缺少的檢查點。
- **團隊討論**：選少數經驗轉成可驗證的共用規範。

## 4. 我要怎麼用？

1. 從 README 的學習路線或線上閱讀入口開始，先讀總覽與核心概念。
2. 選一個你熟悉的 Codex 任務，寫下目前會失敗的情況和可觀察結果。
3. 只套用一項做法，重跑同類任務比較，確認有用後再加入自己的工作規範。

## 5. 值不值得研究？

**很適合我，可以實際使用。** 與你目前改進 AI 協作的方向高度相符，閱讀與小實驗的門檻也低。
