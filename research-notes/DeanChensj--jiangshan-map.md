# 江山時序｜GitHub 專案導覽

> 來源：[DeanChensj/jiangshan-map](https://github.com/DeanChensj/jiangshan-map) README；查閱日期：2026-10-26。

## 1. 這是什麼？

江山時序是一個互動歷史地圖網站，讓讀者拖動時間軸，查看戰國至現代的歷代疆域與地名變遷，並追蹤古城、人物與詩文路線。它比較像可探索的歷史圖譜與視覺教具，而非一般 GIS 編輯器。README 也提供可分享的指定年份或地點連結、命令列查詢與 GeoJSON 匯出。

## 2. 對我有什麼用？

當你讀《史記》、中國史或古詩文，遇到「當時的長安、建康、黃州在哪裡」之類問題，可以用地圖先建立空間感。若你在研究知識庫或互動教材，也可參考它如何結合時間、地點、人物與可分享連結。地圖邊界屬示意與重建，不能直接作為精確史學或法律邊界依據。

## 3. 使用情境

- 拖動年份，比較不同時期的疆域與政權。
- 點選古城或人物，連到地名沿革與歷史事件。
- 準備歷史導覽或教學時，分享指定年份和地點的畫面。
- 開發地圖應用時，研究其 GeoJSON 輸出與連結方式。

## 4. 我要怎麼用？

先打開 [線上展示](https://deanchen.me/jiangshan-map/?lang=en)，拖動時間軸，再點熟悉的地點，例如長安，查看它在不同年代的名稱與關聯。只閱讀不需安裝。若要本機使用，clone 專案後用 Python 靜態 HTTP 伺服器開啟；README 表示不需建置。若要把地圖向量資料用於自己的程式，可依說明執行 `node scripts/export_geojson.js`，但要先確認資料授權和示意邊界的限制。

## 5. 值不值得研究？

**對歷史閱讀與互動視覺化有興趣時很適合先玩線上版。** 它也能提供知識圖譜介面設計靈感；若目前沒有相關需求，收藏即可。
