# MeTube｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/alexta69/metube/blob/master/README.md)；查閱日期：2026-10-09。

## 1. 這是什麼？

MeTube 是可自行架設的影音下載網頁介面，底層使用 yt-dlp。你在瀏覽器貼上支援網站的連結，就能把影片、音訊、字幕或縮圖下載到自己的主機。它支援單支影片、播放清單、頻道，以及訂閱頻道或播放清單後定期加入新內容；每次下載也可選品質、格式與資料夾。它比較像「自己的下載工作站」，不是影音串流平台。

## 2. 對我有什麼用？

如果你經常把有權保存的英文學習影片、教學或訪談放進本機知識庫，MeTube 可讓貼網址、排隊和管理下載更容易，不必每次寫 yt-dlp 指令。你也能用訂閱功能追蹤固定來源的新內容。它適合已經有 Docker 或長時間開機的電腦／伺服器；若只偶爾下載，直接用 yt-dlp 會少一層部署與維護。

## 3. 使用情境

- **個人影音收件匣**：貼入單支影片，集中存到指定資料夾。
- **系列課程**：下載有權保存的播放清單，依標題整理檔案。
- **頻道追蹤**：訂閱固定來源，定期排入新上傳內容。
- **家庭或多裝置使用**：在區域網路透過瀏覽器操作同一個下載主機。

## 4. 我要怎麼用？

1. 準備 Docker 主機及下載資料夾；依 README 的 Docker 或 Compose 範例掛載資料夾並啟動容器。
2. 在瀏覽器開啟主機的 8081 連接埠，貼入一個有權下載的測試網址。
3. 選擇影片或音訊、品質和儲存資料夾，確認完成後能在掛載位置找到檔案。
4. 想長期使用時再設定固定檔名、佇列、訂閱與 yt-dlp 選項；保留來源連結以便回查。
5. 若要讓其他裝置存取，依專案 Wiki 規劃網路與存取控制，不要把管理頁面隨意公開。

## 5. 值不值得研究？

**若你想長期用瀏覽器管理影音下載，很值得使用。** 它把 yt-dlp 包成方便的網頁流程，特別適合固定來源與下載佇列；偶爾下載則不必架服務。
