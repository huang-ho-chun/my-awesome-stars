# The System Design Primer

> 專案：[donnemartin/system-design-primer](https://github.com/donnemartin/system-design-primer)｜依據：專案 README（2026-10-30 查閱）

## 1. 這是什麼？

這是一份大型系統設計的開放學習資源，整理可擴充性、可用性、一致性、快取、資料庫等主題，也附有系統設計面試題、範例解法、圖示、學習指南與 Anki 卡片。它偏向閱讀與練習資料庫，不是安裝後自動設計系統的軟體。

## 2. 對我有什麼用？

你在設計自動化測試系統或處理客戶伺服器問題時，可以用其中的觀念檢查容量、故障模式與資料流；若準備工程職涯或英文系統設計面試，也可用範例題練習清楚表達取捨。專案內容很廣，先按當前問題選章節即可，不必從頭讀完。

## 3. 使用情境

適合規劃服務架構、討論高流量或高可用需求，以及練習系統設計面試。例如先自己設計 URL 短網址或網路爬蟲，再對照 repo 中的討論、圖與解法，找出遺漏的需求和限制。

## 4. 我要怎麼用？

直接從 README 的 Study guide 選短、中或長期路線；先看主題索引與「如何回答系統設計題」，挑一道範例題，依序列出使用情境與限制、畫高階設計、說明關鍵元件與擴充方式，最後再對照範例解法。需要複習時可使用附帶的 Anki 卡片；主要內容在線上閱讀即可，無需安裝。

## 5. 值不值得研究？

很適合你當作工程設計與面試準備的長期參考。建議先選一個與目前工作相關的題目實作練習，再視需要延伸到其他章節。
