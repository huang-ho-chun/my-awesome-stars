# VoiceStudio

> 專案：[debpalash/VoiceStudio](https://github.com/debpalash/VoiceStudio)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是本機運行的語音製作 App，可做語音複製、聲音設計、文字轉語音、影片配音、聽寫與轉錄，也有本機 API/MCP。README 提供 Windows、macOS、Linux 下載及模型管理方式；不同功能和語言支援取決於所選引擎。

## 2. 對我有什麼用？

你可用它為教學影片配音、把訪談轉錄成文字，或做自己的旁白草稿。資料可留在本機，對不想把聲音上傳外部服務的情境有價值。

## 3. 使用情境

適合內容創作者的旁白與多語配音、會議/訪談轉錄、需要批次語音處理的工作流。模仿他人聲音時應先取得對方同意。

## 4. 我要怎麼用？

Windows 10/11 可從 Releases 下載安裝程式，先用預設模型測一小段文字與音檔，再視需求在 Model Manager 安裝其他引擎。CPU 可用但較慢；有合適 GPU 可依官方 Windows 指南設定加速。手機版目前為 Preview。

## 5. 值不值得研究？

很適合你若要做教學或短片配音，可以先在 Windows 用預設模型試一段繁體中文旁白。
