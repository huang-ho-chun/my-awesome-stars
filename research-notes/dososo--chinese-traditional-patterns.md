# 中國傳統紋樣圖鑑（dososo/chinese-traditional-patterns）

資料來源：[官方 README](https://github.com/dososo/chinese-traditional-patterns/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

把傳統紋樣整理成可搜尋圖錄與資料集的專案。README 提供線上網站、分類、卡片 PNG、`patterns.json`／`patterns.csv` 元資料和使用方式，內容含名稱、寓意、視覺關鍵詞與應用建議。圖像是原創生成與再設計素材；README 區分程式碼與圖像內容授權，圖像內容受非商業條款限制。

## 2. 對我有什麼用？

若你設計 Obsidian 封面、個人筆記或家庭活動素材，可從紋樣類型、寓意和配色找視覺靈感。對測試自動化與伺服器報告幾乎沒有直接技術價值；若要放進對外或商業交付文件，先檢查內容授權與是否符合用途。

## 3. 使用情境

例如想做一張傳統節慶的私人活動海報，可先在網站選一款寓意符合主題的圖案，讀其來源說明與配色，再下載素材試排版。若要自己用資料管線分類素材，可讀 CSV 欄位並只挑關聯類別；不應因為「傳統」標籤就假設每個圖案都代表相同文化含義。

## 4. 我要怎麼用？

最容易從 README 連到 `wenyang.net`，按類別搜尋、看詳細卡片與下載；也能在倉庫取用 PNG 與 `data/patterns.json` 或 CSV，透過 Python 讀取資料後依標籤篩選。這是素材與資料集，瀏覽使用不需安裝；若在產品中使用，先依 README 的程式碼 MIT 與內容 CC BY-NC 條款分別確認權利。

## 5. 值不值得研究？

對我目前用途不大：適合偶爾做個人視覺作品，與目前自動化及職涯學習主線關聯低。
