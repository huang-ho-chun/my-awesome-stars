# 高性價比人生指南｜GitHub 專案導覽

> 來源：[eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter) README；查閱日期：2026-10-26。

## 1. 這是什麼？

這是一份可搜尋的中文生活指南，把健康、時間、金錢、工作、家庭、急救和法律等問題整理成逐條建議。每條列成本、可能收益、證據等級和原始來源。可在網頁閱讀，也提供離線 HTML、PDF、EPUB、Anki 牌組，以及按書中內容查找的 Agent Skill。它是供篩選和查證的參考書，不是人人都要完成的待辦清單。

## 2. 對我有什麼用？

你可用「要付多少時間、金錢與精力，可能換到什麼」的角度，快速尋找值得進一步核對的做法。例如挑工作時間、育兒、健康習慣或個人財務相關章節，先讀一兩條，再追到原始資料。指南的法律、醫保與社保制度主要依中國大陸規定撰寫，不能直接套用台灣情況；醫療及財務決策也要按個人情況核實最新專業資訊。

## 3. 使用情境

- 遇到具體生活問題時，按關鍵字和證據等級查資料。
- 比較某項做法的成本與預期收益，再決定是否深入研究。
- 離線閱讀、使用 Anki 複習自己選的主題。
- 用附帶的 Skill 查出書中相關條目及引用位置。

## 4. 我要怎麼用？

最簡單是開 [線上檢索頁](https://eternity4719.github.io/HowToLiveBetter/)，用關鍵字、章節、證據等級或成本條件篩選；先看條目的「說人話」，再查「收益」「來源」「備註」及原始文獻。README 也連到可直接下載的單檔離線 HTML、PDF、EPUB 與 Anki。只閱讀不用 clone 或安裝；若要自己跑靜態網站，可 clone 後用 `python -m http.server 8000` 開啟。

## 5. 值不值得研究？

**可作為有用的查找入口，但每條建議都要看適用人群、證據與地區。** 對你的生活與職涯議題有潛在價值；涉及醫療、法律或金錢時，不能只依書中的摘要採取行動。
