# animate

> 專案：[cth9191/animate](https://github.com/cth9191/animate)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是 Claude Code 的程序式動畫 Skill：AI 用程式繪製 Canvas 畫面並渲染短影片，內建七種風格，也可參考你提供的樣式。它重視故事、視覺與分鏡的確認過程。

## 2. 對我有什麼用？

你可以用來做產品功能展示、社群短動畫，或把抽象概念改寫成簡短視覺解說。對你而言，最有價值的是把文字構想變成可反覆修改的影片草稿。

## 3. 使用情境

適合有明確主題、想控制畫面與節奏的短片。若只需要快速剪現有影片，這套從程式生成動畫的流程會較重。

## 4. 我要怎麼用？

依 README 安裝 Claude Code、Node.js 18+、Playwright Chromium 與 ffmpeg，再安裝 animate plugin。提出主題與輸出比例，依序確認故事、畫風與分鏡，最後取得 MP4；旁白功能另有 Python 或語音服務需求。

## 5. 值不值得研究？

有特定情境才有用。你若想做教學或產品動畫，值得試一支極短片；一般影片剪輯則可先用現有工具。
