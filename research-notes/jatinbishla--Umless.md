# Umless｜GitHub 專案導覽

> 專案：https://github.com/jatinbishla/Umless

## 1. 這是什麼？

Umless 是在裝置上運行的開源語音輸入工具。按住指定按鍵說話、放開後，它會用語音辨識與本機語言模型整理口頭停頓、自我更正和語氣，再將文字輸入游標所在的應用程式。它提供 Lite、Standard、Max 三種模型組合，對應不同的容量、速度與語言支援。

README 表示 macOS、Windows 和 Linux 均可使用基本語音輸入；讀取畫面文字來拼寫人名及依上下文改寫，目前只在 macOS 提供。Windows 與 Linux 桌面版本較新，測試程度也較低。

## 2. 對我有什麼用？

撰寫較長的 AI 提示詞、郵件或聊天訊息時，可以先自然口述，再讓工具整理成適合目前應用程式的文字。音訊、轉錄及整理模型在本機執行；依 README，口述時不需要帳號或雲端服務。常見姓名和術語可加入字典，減少反覆修正。

## 3. 使用情境

- 口述給 Codex 或聊天工具的需求，整理停頓和中途更正後輸入提示詞。
- 在郵件或訊息應用程式草擬內容，再自行檢查並送出。
- 在常用專有名詞字典中指定姓名或產品名稱的拼寫。
- 用本機 CLI 對音訊檔進行轉錄，或測試不同模型等級的辨識表現。

## 4. 我要怎麼用？

1. 檢查裝置與空間：支援 macOS 13 以上的 Apple Silicon、Windows 10／11 x64，以及 Linux X11／Wayland；不同模型約需 1–6 GB 可用空間。
2. 依 README 在目標系統複製 repository 並執行對應安裝程式。安裝會從原始碼建置並下載所選模型，可能需要 Rust、C++ 建置工具等相依項。
3. Windows 安裝後，在一般應用程式按住 `Ctrl + Win` 說話，放開後等待文字輸入；macOS 預設按住 `Fn`，Linux 使用 `Ctrl + Super`。
4. 先在不重要的文字欄位測試辨識與更正，再根據需要選擇模型等級及設定術語字典。

Windows 不能把文字輸入以系統管理員身分執行的應用程式；目前也沒有 macOS 的畫面脈絡功能。README 的速度和準確率數字來自作者列出的測試條件，實際結果需以自己的語音及硬體驗證。

## 5. 值不值得研究？

若想在本機口述工作文字，值得先試 Lite 等級的短句與日常提示詞。這個專案把辨識、口語整理、應用程式風格和術語字典連成一個流程；但首次建置與模型下載成本較高，而且 Windows 功能尚未與 macOS 完全一致。先確認按鍵、輸入焦點與常用應用程式是否順手，再投入更大的模型。
