# last30days-skill-cn 專案指南

來源：[Jesseovo/last30days-skill-cn 官方 README](https://github.com/Jesseovo/last30days-skill-cn/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

針對中文網路平台的近 30 天研究 Skill。

## 2. 對我有什麼用？

可補上中文社群和中國平台的討論視角；對台灣購物或法規資訊，平台樣本不一定具代表性，仍須另查台灣官方來源。

## 3. 使用情境

若研究某個中文 AI 工具的使用回饋，先取得有來源的近期摘要，再核對原貼文時間與地區；不要把熱門討論直接當成功能現況。

## 4. 我要怎麼用？

README 建議以 npx skills add 安裝到 Agent 宿主，也列 Cursor、Claude Code、OpenClaw 等方式。閱讀配置指南後先只啟用必要來源，確認 crawler、帳號與 cookie 權限，再輸入具體研究問題檢查引用。

README 提供多種 Agent 宿主安裝，也說明中國平台的來源與爬取變動。研究台灣話題時可把它當補充資料，不宜把大陸平台熱度直接套用到本地市場。

## 5. 值不值得研究？

有特定情境才有用：研究中文平台時可試，對日常客戶伺服器工作關聯較低。
