# MinerU｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/opendatalab/MinerU/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

文件解析與讀取工具。現行 README 介紹把 PDF、掃描圖、Office 等轉成可供 Agent 逐頁或逐區塊讀取的內容，包含 OCR、表格、公式、版面定位與本機文件庫；它本身不是向量資料庫或聊天知識庫。

## 2. 對我有什麼用？

你處理手寫日記 PDF、報告與技術文件時，可用它先做結構化擷取，並保留頁面或區塊定位供人工核對。對手寫內容仍要看原圖，不應把模型補字直接寫回原件。

## 3. 使用情境

挑一份有表格、雙欄和掃描頁的 PDF，逐頁比對輸出的文字順序、表格及圖片定位；再以原 PDF 回查幾個專名或數字。

## 4. 我要怎麼用？

依 Quick Start 在獨立 Python 環境安裝相容 MinerU 版本，先跑 `mineru version --json`；使用 `mineru parse "document.pdf" --json` 取得讀取結果，必要時以 `mineru read` 續讀定位。先了解解析 tier、本機與遠端選項，敏感文件只用合適的本機路徑。

## 5. 值不值得研究？

你可以保存原檔雜湊、頁面影像和解析 JSON，建立可重現的對照紀錄。對手寫日記尤其要把無法辨識的字明確標出，不能讓後續 LLM 因語意看似順暢就替原文補寫。此工具的價值在可回查，而不只是輸出一篇漂亮的 Markdown。

**很適合我，可以實際使用。**正對你現有 PDF 與 OCR 工作；採用前先以原檔做準確度驗證。
