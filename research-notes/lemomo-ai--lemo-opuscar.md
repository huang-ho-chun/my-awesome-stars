# lemo-opuscar

> 專案：[lemomo-ai/lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是 Claude Code 的程式製片風格工具箱。每種風格附提示與示範影片，讓 Agent 用程式繪製畫面並組合聲音，而非直接呼叫影片生成模型。

## 2. 對我有什麼用？

你可以先從風格庫挑接近目標的樣式，再讓 Agent 依你的主題製作短片；也可把常用視覺語言改成自己的風格。對簡報式解說、短片或社群內容特別有參考價值。

## 3. 使用情境

適合已有文字腳本但缺少視覺方向的影片，或想維持系列影片一致畫風。若只需現成素材快速剪接，製作流程偏重。

## 4. 我要怎麼用？

先在 README 看示範，選一種風格；按官方方式安裝 Claude plugin 或複製專案，準備 Node.js 20+、ffmpeg、Python 3.11+ 或 uv。向 Claude Code 描述內容並指定風格，檢查分鏡、成片與修改需求；執行會花費時間與模型額度。

## 5. 值不值得研究？

有特定情境才有用。若你打算用 Coding Agent 做系列短片，值得先試一種風格。
