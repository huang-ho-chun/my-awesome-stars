# ai-agent-book｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/bojieli/ai-agent-book/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

以「LLM、上下文、工具」為核心的中文開源書，從設計原理談到工程實作。README 提供線上閱讀、PDF／EPUB、繁體中文版本與十章內容，另有大量配套實驗。書中涉及記憶、互動、評估、後訓練等層次，閱讀與實作的投入差異很大。

## 2. 對我有什麼用？

你已在 Codex 中處理多步任務，適合用它釐清工具權限、上下文、人工確認與評估怎麼設計。尤其對客戶伺服器設定與報告自動化，能借用它的工程問題清單：哪些動作可自動執行、哪些結果需要人審、失敗時如何恢復。但不必把書中的大型模型訓練實驗搬進現有工作。

## 3. 使用情境

可先讀 Agent 基礎與評估章，將既有測試流程畫成「觀察輸入→選工具→執行→檢查→停止」；針對一個具體失敗案例列出 Agent 可能誤操作的位置，並設計可觀察的成功判準。這比只讓 Agent 重試直到看似成功，更能驗證它是否可靠。

## 4. 我要怎麼用？

純閱讀可在官方網站選繁體中文或下載 PDF／EPUB。要跑實驗則 clone 倉庫，使用 Python 3.11–3.13；在根目錄按章節用 `uv sync --locked --extra ch1`，或 `python -m pip install -e ".[ch1]"`，再依該章 README 執行對應腳本（README 示例為 `uv run python chapter1/context/main.py`）。不同實驗另需瀏覽器、模型服務或硬體，應逐項核對輸出。

## 5. 值不值得研究？

很適合我，可以實際使用：與你正在建立的 Codex 工作方法高度相關。先讀上下文、工具與評估，等有真實需求再跑大規模實驗。
