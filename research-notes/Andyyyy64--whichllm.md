# whichllm｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/Andyyyy64/whichllm)；查閱日期：2026-09-16。

## 1. 這是什麼？

whichllm 是評估本機硬體能執行哪些 LLM 的命令列工具。它偵測 CPU／GPU／記憶體，估算模型及量化版本能否放入記憶體、可能的速度，也可模擬另一張 GPU 做比較。它幫你篩候選，並不是模型本身或保證真實速度的效能測試。

## 2. 對我有什麼用？

你接觸 GPU 與伺服器，也會考慮本機 AI 工具。與其只看模型宣傳的參數量，你可以先用 whichllm 在自己設備上估算可行範圍，再選少數模型親自測試。若你想比較一台工作站升級前後的可用模型，模擬 GPU 功能也很直觀。

## 3. 使用情境

- **本機模型選擇**：找符合目前 VRAM／RAM 的候選。
- **硬體升級評估**：模擬不同 GPU，看看可用模型差異。
- **腳本整合**：將建議輸出成結構化資料供後續工具參考。

## 4. 我要怎麼用？

1. 依 README Quick start 透過 `uvx` 先跑一次，不必建立專案；常用時才安裝成工具。
2. 檢查它偵測到的硬體是否正確，並比較一兩個目標模型或模擬 GPU。
3. 再實際載入候選模型，量測你的任務、上下文長度和速度，校正工具估計。

## 5. 值不值得研究？

**有特定情境才有用。** 你若要選本機 LLM 或評估硬體很有用；平常只用雲端模型時用不到。
