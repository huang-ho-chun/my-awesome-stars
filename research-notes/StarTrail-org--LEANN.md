# LEANN 專案指南

來源：[官方 README](https://github.com/StarTrail-org/LEANN/blob/HEAD/README.md)｜查閱日期：2026-09-16

## 1. 這是什麼？

本機向量索引與個人 RAG 工具。README 主張以選擇性重算等方法降低索引儲存量，支援文件、程式碼及多種個人資料來源，也提供給 Agent 使用的整合方式。儲存節省數字是專案宣稱，實際效果要用自己的資料測。

## 2. 對我有什麼用？

你有 Obsidian 筆記、文件與程式專案，若本機語意搜尋索引逐漸變大，LEANN 值得作為索引層試驗。它處理的是找相關內容，不會自動保證回答正確，也不能取代來源核對。

## 3. 使用情境

取一個已備份的小型筆記子資料夾與幾篇 PDF，建立索引後試找不同說法的同一概念；再比較關鍵字搜尋的命中、磁碟空間與查詢時間。

## 4. 我要怎麼用？

依 README 先備好 `uv` 與相容 Python，在隔離環境安裝 `leann`；用 Quick Start 建立索引、搜尋並試問。文件流程另有 `apps.document_rag`，程式流程有 `apps.code_rag`。先將輸出與原檔分開，確認索引增量更新和來源路徑。

## 5. 值不值得研究？

採用前應測你在意的中文與英文混合搜尋，並量測新增、修改、刪除檔案後的索引一致性。若索引小而且關鍵字搜尋已足夠，儲存節省率再高也不會轉化成日常時間收益。

**有特定情境才有用。**當本機資料量與語意檢索需求足夠大時有價值；目前可先做小樣本基準。
