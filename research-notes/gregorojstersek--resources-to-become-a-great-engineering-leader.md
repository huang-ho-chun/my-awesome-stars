## 1. 這是什麼？

一份工程領導者的資源索引，README 把書籍、部落格、電子報和人物依系統設計、管理、軟體工程、產品思維、資料、AI、教練與溝通等主題整理。它主要指向外部材料，不提供統一課程或工具安裝；各連結的品質與更新狀態仍需自行查核。

## 2. 對我有什麼用？

若你正在考慮職務成長，這份清單可幫你區分「技術深度」「與人協作」「帶團隊」等不同能力，而非假設升職只代表管理人數增加。你目前重視可持續工時和家庭時間；是否走管理路線，還要看實際職責、工時和技能可轉移性，資源清單本身不能替你下結論。

## 3. 使用情境

例如希望在跨團隊測試專案中擴大影響力，可先選「溝通」和「系統設計」兩類各一篇材料，嘗試寫一份讓非原開發者看懂的風險與決策摘要。若連續幾次協作有改善，再考慮更深入的領導課題。

## 4. 我要怎麼用？

先讀 README 的 How to start 建議，回顧目前技能並指出一個最需要補的缺口；再進入相應分類挑少量來源。閱讀後記下可以在現有工作試行的做法與觀察期限，勿一次訂閱全部電子報。這是連結清單，無需 clone、安裝或執行；成果應是經過篩選的個人學習清單。

## 5. 值不值得研究？

有特定情境才有用：若你要承接技術領導或跨團隊協作，可快速找材料；職務方向未定時不必大量投入。
