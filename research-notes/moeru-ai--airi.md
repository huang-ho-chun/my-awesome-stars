# airi｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/moeru-ai/airi)；查閱日期：2026-09-16。

## 1. 這是什麼？

Project AIRI 是開源的 AI 虛擬角色／陪伴互動專案，結合文字、語音和可視化角色，並有瀏覽器、桌面及其他平台的開發路線。它比較像可自行探索的角色互動平台，不是一般工作助理，也不會因為是開源就自動具備你需要的知識管理能力。

## 2. 對我有什麼用？

對你的工作任務，它目前關係不大；若你想體驗語音與虛擬角色如何結合，或研究 AI 互動產品的界面，可以當作興趣專案。與家人共用或輸入私人內容前，應先理解模型供應商與資料流向。

## 3. 使用情境

- **體驗角色互動**：用公開展示感受文字、語音和角色呈現。
- **前端產品研究**：觀察跨平台 AI 角色的互動設計。
- **個人客製**：只有確定要長期使用時才評估本機部署和模型設定。

## 4. 我要怎麼用？

1. 先從 README 的瀏覽器版本或展示入口了解目前能用的功能。
2. 若要本機執行，再看桌面版本的 Development 指南與所需模型服務。
3. 用非敏感內容試對話、語音與延遲，確認體驗符合目的後再配置更多服務。

## 5. 值不值得研究？

**對我目前用途不大。** 它偏娛樂與互動研究，與你現階段的自動化、筆記和工作目標距離較遠。
