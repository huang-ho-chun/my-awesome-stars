# openhuman 專案指南

來源：[tinyhumansai/openhuman 官方 README](https://github.com/tinyhumansai/openhuman/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

以持續記憶、工具、排程和多訊息通道為核心的人機協作 Agent 平台。

## 2. 對我有什麼用？

README 強調圖形化設定、可檢視工作流與多通道互動；若你未來要常駐助理管理資訊，它有參考價值，但又是一套獨立平台。

## 3. 使用情境

先在個人非敏感資料環境建立一個提醒或研究工作流，檢查它如何呈現執行紀錄、審核步驟與記憶更新，再與現有 Codex 自動化比較。

## 4. 我要怎麼用？

README 提供網站安裝入口與從原始碼開發說明；先試圖形介面，設定模型與所需通道，只啟用一個可回溯的工作流。確認權限、儲存位置與停用方式後再擴充。

尤其要確認排程、記憶與多通道資料的保存和刪除方式是否符合你的使用習慣。

README 強調可在畫布上審查工作流、由不同層級 Agent 分流任務，並支援訊息通道。可先試一個需要人工核可的簡單流程，觀察提案、執行和紀錄是否清楚。

## 5. 值不值得研究？

可以先收藏，以後可能用到：常駐個人 Agent 的價值取決於你是否真的需要多通道和長期記憶。
