# HermesOffice｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/criptogus/HermesOffice/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

支援文件、試算表、簡報等格式的開源 AI 辦公軟體。

## 2. 對我有什麼用？

README 提供 Windows、macOS、Linux 安裝與自帶 API key 等選項。對測試報告交付為 Word、Excel 或 PowerPoint 時可能方便，但需核對格式保真。

## 3. 使用情境

用一份沒有敏感內容的 DOCX 或 XLSX 複本試編輯、匯出及重新開啟，檢查公式、表格與圖形是否保留；再評估 AI 功能的資料送出範圍。

## 4. 我要怎麼用？

依 README 下載對應作業系統的發行版，Windows 可使用安裝程式；開啟一份樣本文件，選擇 AI 提供者或不啟用 AI，完成少量修改再比對原檔。若要從原始碼開發，README 另列 npm 工作區步驟。

README 將 Word、Excel、PowerPoint、PDF 與 Markdown 編輯置於同一套應用中，並提供自帶模型金鑰模式。試用時先核對 Office 格式來回儲存，而非只看 AI 編輯展示。

## 5. 值不值得研究？

有特定情境才有用：當你需要可編輯辦公文件且願意驗證相容性時值得試。
