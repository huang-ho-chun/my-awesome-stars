# 大模型基礎（ZJU-LLMs/Foundations-of-LLMs）

資料來源：[官方 README](https://github.com/ZJU-LLMs/Foundations-of-LLMs/blob/HEAD/readme.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

浙江大學團隊撰寫的中文大模型教材。README 列出語言模型基礎、大模型架構、Prompt 工程、參數高效微調、模型編輯與檢索增強生成六章；提供整本 PDF、分章 PDF 和各章論文清單。它重在原理與文獻脈絡，並非一套可直接部署的 LLM 框架。

## 2. 對我有什麼用？

若你想理解 RAG、模型架構或微調在技術上各解決什麼問題，這份教材能避免只依產品宣傳選工具。對目前以 Codex、測試自動化、報告管線為主的工作，Prompt 與 RAG 章節的短期相關性高於模型編輯、微調。讀到數學或訓練細節時，可先記下決策上用得到的概念，不必立即實作。

## 3. 使用情境

例如你考慮讓大量內部文件供 Agent 查詢，可先讀 RAG 章，拆出「切分、索引、檢索、生成、評估」各環節，再針對少量可公開文件試作。若只是想改善一篇報告的措辭，教材會顯得過重，直接改善輸入資料與驗收準則通常更快。

## 4. 我要怎麼用？

從倉庫首頁開啟《大模型基礎》完整 PDF，或選分章 PDF；依需求選 Prompt 或 RAG 章，沿著章末／對應資料夾的 Paper List 查原始論文，再把理解整理成 Obsidian 筆記。README 沒有宣稱統一安裝或執行命令，這是閱讀型教材，成果應是問題清單與可核對的技術選擇，而非預期跑出服務。

## 5. 值不值得研究？

有特定情境才有用：適合建立扎實理解，尤其在評估文件問答方案時。暫不需要從第一章到最後一章通讀，挑當前決策相關章節比較符合你的時間預算。
