# IELTS Atlas（ielts-practice）｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/gtiipoi/ielts-practice/blob/master/README.md)；查閱日期：2026-09-22。

## 1. 這是什麼？

IELTS Atlas 是一套面向雅思閱讀與聽力的純前端練習系統。下載完整專案後，可以直接用 Chrome 或 Edge 開啟 `index.html`，不需要後端服務。它提供題庫搜尋與篩選、單篇和套題練習、成績統計、錯題分析、學習熱力圖、詞彙輔助、資料備份與自訂題庫匯入。

練習記錄主要保存在瀏覽器的 IndexedDB 和本機儲存空間。它比較像可自己保管資料的**雅思機考練習網站**，不是英語課程，也不會替你講解完整的備考策略。

## 2. 對我有什麼用？

如果你正在準備 IELTS，這個專案可以把閱讀與聽力練習、成績和錯題集中在同一個本機介面。你可以每天挑一篇練習，完成後看答案、解析和定位高亮，再用錯題題型分布決定下一次要補強的部分。套題模式也適合在考前模擬連續作答。

它也支援把練習歷史匯出成 Markdown，方便你保存到 Obsidian，另外整理容易錯的題型、單字或解題規則。因為資料依瀏覽器、路徑、協定和網域分開保存，定期匯出備份很重要；清除瀏覽器資料或換環境可能讓記錄看起來消失。

若你目前只是一般英文學習，沒有 IELTS 閱讀或聽力需求，這套系統的題型與流程會比較侷限，不必因功能多就勉強使用。

## 3. 使用情境

- **每日練習：** 依題型或關鍵字挑一篇閱讀或一段聽力，完成後檢查答案和解析。
- **錯題複習：** 用歷史記錄、錯題雷達和閱讀背題模式回顧常犯錯誤。
- **考前模擬：** 以套題模式連續完成多個單元，查看總分、耗時與中斷記錄。
- **進度追蹤：** 看近期趨勢、練習熱力圖和分類進度，安排下一階段練習。
- **個人題庫：** 匯入自己合法取得的閱讀或聽力材料，建立私人練習環境。

## 4. 我要怎麼用？

1. 下載並完整解壓專案，保留所有資料夾和相對路徑。
2. 使用最新版 Chrome 或 Edge 雙擊開啟根目錄的 `index.html`；首次練習時允許彈出視窗。
3. 到「題庫瀏覽」確認閱讀與聽力列表正常，再挑一題完成並檢查成績是否寫入「練習記錄」。
4. 在設定中建立備份，並定期把資料或練習歷史匯出保存。
5. 若 `file://` 模式出現音訊、PDF、彈窗或跨視窗問題，再改用本機靜態伺服器執行。

普通發布內容可能沒有完整聽力資源，需要自行匯入合法取得的材料。題源、音訊、PDF、圖片與解析可能涉及第三方版權；專案明確要求自行部署、個人使用、控制分享範圍，避免公開散布或商業使用。

## 5. 值不值得研究？

**有特定情境才有用。** 正在準備 IELTS，尤其想在本機練閱讀、聽力並追蹤錯題時，很值得實際試用；若目前目標是生活英文、口說或一般單字學習，可以先收藏，不必優先安裝。
