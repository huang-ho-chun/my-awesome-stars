# sakurai-skill｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/kociden/sakurai-skill/blob/HEAD/README.md)；查閱日期：2026-11-20。

## 1. 這是什麼？

sakurai-skill 是一套非官方、日文的 Agent Skill。作者將 YouTube「桜井政博のゲーム作るには」全本編 257 支影片的自動字幕整理成遊戲製作原則，主 Skill 分成 14 章，具體數值、案例與步驟則放在分類參考文件，並保留影片編號與標題以便回查。內容是 AI 摘要，不是櫻井政博的逐字發言，也可能保留字幕辨識錯誤。

## 2. 對我有什麼用？

在用 Coding Agent 製作或檢視遊戲時，可從企劃、難度、獎勵、操作感、鏡頭、動畫、特效、UI、聲音、除錯與團隊協作等角度提出具體問題。它適合把「手感不對」或「遊戲顯得拖沓」這類模糊回饋轉成可逐項檢查的設計假設，但不應取代實際玩家測試。

## 3. 使用情境

- 在原型階段請 Agent 檢視核心玩法、風險與回饋循環。
- 針對跳躍、命中停頓、鏡頭或特效等操作感問題列出調整方向。
- 在關卡、UI 或難度修改前，先以相關章節做一次設計審查。
- 從條目附的影片編號回到原影片，核對重要原則的語境。

## 4. 我要怎麼用？

依 README 將 `skills/sakurai` 複製到所用 Agent 的 Skills 目錄；Claude Code 的示例是先 clone repository，再複製到 `~/.claude/skills/`。安裝後可用「櫻井會怎麼做？」或「檢視這個遊戲的手感」這類問題觸發。先拿一個小型遊戲原型測試，要求 Agent 指出引用的章節與影片編號，重要結論再回看原影片確認。

## 5. 值不值得研究？

若正在做遊戲原型或想建立固定的遊戲設計檢查流程，值得試用；它的範圍完整且可追溯到影片編號。由於來源是自動字幕與 AI 摘要，最適合作為提問與檢查清單，而不是權威引文或不經驗證的設計規則。
