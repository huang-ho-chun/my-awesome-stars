# career-ops｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/career-ops-hq/career-ops)；查閱日期：2026-09-16。

## 1. 這是什麼？

career-ops 是在本機 AI coding CLI 內運作的求職管理流程，可評估職缺、調整履歷、追蹤申請與整理公司資訊。README 強調它是幫人篩選少量值得投入的機會，而不是大量自動投遞。它可與 Codex 等 CLI 協作，但履歷、評估標準與最後決定仍由你掌握。

## 2. 對我有什麼用？

你目前重視穩定工時、家人時間和可轉移技能，尚未決定要立即換工作。這套工具最有用的部分可能是把職缺與你真正在乎的條件做結構化比較，而不是立刻開始投遞。將來有外商或其他具體機會時，可用它整理職缺、履歷和跟進狀態。

## 3. 使用情境

- **機會篩選**：比較工時、工作內容、技能成長與家庭成本。
- **履歷調整**：針對少數職缺整理可證明的經歷。
- **申請追蹤**：確實開始求職後再記錄每個進度。

## 4. 我要怎麼用？

1. 依 README Quick Start 在本機設定專案，先用範例或不含敏感資料的測試履歷。
2. 把你重視的工作條件明確寫進個人設定，再輸入一份真實職缺描述做評估。
3. 檢查它的評分理由是否符合你的優先順序；只有在你確認後才使用產出的履歷或採取申請動作。

## 5. 值不值得研究？

**可以先收藏，以後可能用到。** 你目前在探索選項，不必建完整求職管線；有具體職缺時再用更有價值。
