# 紫微斗數排盤引擎｜GitHub 專案導覽

> 來源：[Renhuai123/ziwei-doushu](https://github.com/Renhuai123/ziwei-doushu) README；查閱日期：2026-10-26。

## 1. 這是什麼？

這是紫微斗數排盤的開源程式與資料集，包含曆法和排盤規則、四化與格局資料、古籍原文、示範網頁，以及可另外下載的命盤解讀資料集。它偏向傳統命理工具與研究材料。開源版可在瀏覽器中排盤和瀏覽內容，但 README 說明後端 AI 解讀 API、商業站介面與完整斷語內容不在倉庫內。

## 2. 對我有什麼用？

若你想了解紫微斗數排盤如何處理真太陽時、夏令時間、閏月與晚子時，這個專案提供可操作的示範和明確的排盤口徑。若只是想看一次命盤，可先使用 README 所連的線上版，不必下載大型資料集。命理推論並無可靠科學證據可作為人生決策依據；更適合作為文化、傳統文本或軟體規則建模的研究材料。

## 3. 使用情境

- 看傳統命理排盤介面，理解不同規則選項如何影響結果。
- 研究把古籍和規則表整理成可查詢資料的做法。
- 開發者用開源排盤引擎做原型；解讀服務需另行實作。

## 4. 我要怎麼用？

先從 README 連到的線上體驗頁試排盤與古籍閱讀器。要在本機使用，clone repo、`npm install`、`npm run dev`，即可開啟示範網頁；純排盤不需 API key。README 明確指出，開源版的 `/api/interpret` 等後端路由沒有提供，單純填入模型金鑰不會讓 AI 解讀可用。大型解讀資料集可選擇性下載，先確認容量與各資料授權再決定是否需要。

## 5. 值不值得研究？

**有傳統命理或規則建模興趣時才有用。** 若只是想體驗，線上版足夠；若想依它做人生判斷，應避免把命理結果當作可信預測。
