# ClaudeAnimationBase

> 專案：[JohnHeibel/ClaudeAnimationBase](https://github.com/JohnHeibel/ClaudeAnimationBase)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是手繪風角色動畫的起始專案，包含 Clawd 角色、表情、場景範例與 `ANIMATION_GUIDE.md`。Coding Agent 可以依指南設計分鏡、製作鏡頭並輸出影片。

## 2. 對我有什麼用？

你可以用它試作有固定角色的教學、故事或社群動畫。比起從零寫動畫，範例與角色素材能降低起步成本；但若需要寫實影片，風格不合。

## 3. 使用情境

適合 2D 角色短片、動態貼文或測試 Agent 在分鏡與動畫上的表現。已有自己的角色圖時也可嘗試替換。

## 4. 我要怎麼用？

複製 repo 並在 Claude Code 或其他 Coding Agent 開啟，請它先讀 `ANIMATION_GUIDE.md`，再描述想做的短片。自行渲染需 Node.js、Chrome 和 ffmpeg；先跑示範確認能輸出 `out/video.mp4`，再修改角色、場景與節奏。

## 5. 值不值得研究？

有特定情境才有用。若你要持續做手繪角色影片，可從示範開始；偶爾做單張圖則不需這套。
