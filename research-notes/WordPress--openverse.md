# Openverse｜GitHub 專案導覽

> 專案：https://github.com/WordPress/openverse

## 1. 這是什麼？

Openverse 是搜尋開放授權圖片與音訊的服務；此 repository 收錄網站前端、API、資料目錄與匯入流程等應用程式碼。一般使用者可直接在 [openverse.org](https://openverse.org) 搜尋，不需先自行部署整個 monorepo。

## 2. 對我有什麼用？

製作簡報、文章、影片或教學內容時，可從一個搜尋入口找可使用的圖片與音訊。若要做程式化查詢，也可參考專案列出的 API 文件。搜尋結果雖標示開放授權，實際使用仍須核對個別作品的來源、授權條款及署名要求。

## 3. 使用情境

- 為部落格或簡報尋找可授權使用的插圖。
- 為影音作品尋找音訊素材，記錄原作者與授權資訊。
- 在應用程式中使用 Openverse API 搜尋媒體候選項。

## 4. 我要怎麼用？

到 Openverse 網站輸入主題，檢視候選媒體的授權、來源與作者，再開原始頁面確認條件與檔案是否仍可取得。需要程式整合時，閱讀 README 指向的 [API 文件](https://api.openverse.org/v1/)，先用小量查詢測試回傳資料。若要研究貢獻或自架架構，再分別閱讀 repository 中的 frontend、API、catalog 與 ingestion 文件。

## 5. 值不值得研究？

若經常找可合法重用的圖片或音訊，網站值得直接使用。開發者若需要媒體搜尋 API 或開放授權搜尋架構，也值得研究；素材權利判斷仍須逐件確認。
