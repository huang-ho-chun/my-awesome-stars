# egos-2000｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/yhzhang0128/egos-2000)；查閱日期：2026-09-16。

## 1. 這是什麼？

egos-2000 是教學用的微型作業系統。專案的目標是讓學生能讀完一整套作業系統的程式碼，並配有 EGOS 教材和練習，能在 QEMU 或 RISC-V 板上執行。它是系統程式設計教材，不是給日常工作電腦安裝的新 OS。

## 2. 對我有什麼用？

你有伺服器與 Linux 經驗，若想補齊作業系統底層概念，這個小型專案比直接讀大型核心容易入門。不過它偏 C 與系統內部實作，和你目前重視的測試自動化、文件整理及職涯技能沒有立即連結。

## 3. 使用情境

- **課程學習**：跟教材理解行程、記憶體等作業系統概念。
- **RISC-V 實驗**：有相應環境時用模擬器先測，再碰硬體。
- **程式碼閱讀練習**：以可讀完整專案為目標，建立底層直覺。

## 4. 我要怎麼用？

1. 先看 README 連結的 EGOS 書與課程安排，確認需要的 C、建置工具及 QEMU 知識。
2. 在隔離的學習環境照教材跑最小示範，不需改動工作電腦系統。
3. 若真的喜歡底層內容，再依章節完成一個練習並核對執行結果。

## 5. 值不值得研究？

**可以先收藏，以後可能用到。** 適合專門學作業系統時投入；目前不是你的首要工作工具。
