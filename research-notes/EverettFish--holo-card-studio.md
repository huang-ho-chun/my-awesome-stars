# holo-card-studio 專案指南

來源：[EverettFish/holo-card-studio 官方 README](https://github.com/EverettFish/holo-card-studio/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

用 Codex Skill 建立全息卡牌、Blender 工程及 Three.js 互動頁面的創作工具。

## 2. 對我有什麼用？

適合個人活動或視覺紀念品，與測試自動化沒有直接關聯；它的分層素材與結果驗證流程可作為創作參考。

## 3. 使用情境

用一張有權使用的照片做單張人物卡，保留主要人物，檢查拖曳旋轉、翻面、手機版和輸出的 Blender 原始檔；控制文字與相片授權。

## 4. 我要怎麼用？

依 README 安裝 Skill 並準備所需 Blender、Python 與網頁環境，向 Codex 描述卡片主題和固定元素；Skill 會建立素材與設定、跑 pipeline、啟動本機頁面，最後交付網頁、渲染圖與 .blend。

README 的交付包括 Three.js 互動頁、card.blend 和渲染圖，並有 holographic 與 lenticular 模式。先做單卡、驗證手機拖曳和翻面，再考慮多卡展廳。

## 5. 值不值得研究？

可以先收藏，以後可能用到：只有在活動素材或個人創作時才需要完整 3D 流程。
