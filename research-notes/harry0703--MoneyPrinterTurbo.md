## 1. 這是什麼？

MoneyPrinterTurbo 是自架的 AI 短影片製作工具。輸入主題或關鍵字後，它可產生腳本、尋找或使用自備素材、加入旁白、字幕和配樂，再輸出直式、橫式或方形影片。它提供 Web UI、API、命令列、Docker 與 Windows 一鍵啟動包；可以接雲端模型與素材服務，也能使用部分本機或免費元件。不同功能需要的服務與設定並不相同。

## 2. 對我有什麼用？

如果你想把已整理的知識文章、工具介紹或英語學習重點做成短影片，可以先用它快速產生一個可觀看的草稿，再手動校對腳本、畫面、字幕和配音。你已經有照片、影片或旁白時，也可以提供自己的素材，減少自動搜尋畫面與內容不符的風險。

它適合測試「某個主題是否值得做成影片」或反覆製作相似格式。成品仍需要人工確認事實、來源與素材使用權；雲端模型和生成服務可能產生費用。

## 3. 使用情境

- **知識短片**：把一篇有來源的文字稿轉成直式解說影片。
- **教學預覽**：快速試不同旁白、字幕與畫幅，挑選合適版本。
- **自備素材剪輯**：用自己的圖片、影片或配音合成短片。
- **批次內容製作**：透過 API 或 CLI 對多個題目重複同一套流程。

## 4. 我要怎麼用？

1. 若你在 Windows 想先試用，可從官方 Release 的 Assets 下載一鍵啟動 `.7z` 包；解壓路徑避免中文、空格和特殊字元。README 建議先執行 `update.bat`，再執行 `start.bat`。
2. 開啟 Web UI，先選一個短主題，檢查腳本與素材來源；按所選服務填入必要 API 設定，憑證只留在本機設定介面。
3. 選擇畫幅、旁白、字幕及素材方式，先做一支短片。
4. 播放成片，逐段核對文字、配音、圖片與授權，再決定是否發布。
5. 若之後要自動化，再研究 Docker、API 或 CLI；原始碼部署需要 Python 3.11 以上。

## 5. 值不值得研究？

**有規律製作短影片的需求時值得試。** Web UI 和 Windows 啟動包降低起步門檻，但多種模型與素材服務的設定仍需時間；只做偶爾一支精細影片，手動剪輯可能更可控。
