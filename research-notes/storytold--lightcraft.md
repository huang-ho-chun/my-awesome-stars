# LightCraft｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/storytold/lightcraft/blob/main/README.md)、[最新發行版](https://github.com/storytold/lightcraft/releases/latest)；查閱日期：2026-10-07。

## 1. 這是什麼？

LightCraft 是開源照片管理與修圖應用，可在 macOS、Windows、Linux 使用，也提供 WebAssembly 網頁版本。它以 Rust 實作，提供相片匯入、相簿與評分、RAW 顯影、曝光與色彩調整、曲線、裁切、遮罩、預設集和批次匯出。編輯採非破壞式流程，原始照片不會因調整滑桿而被改寫。

它也提供命令列工具與 MCP server，讓支援 MCP 的 Agent 匯入、查詢、修圖、套遮罩、預覽和匯出照片。因此它既是圖形介面的照片工具，也能成為自動整理或批次處理照片的元件。

## 2. 對我有什麼用？

若你有大量旅行、家庭或其他照片，可以用它集中評分、標記、建立相簿與搜尋，再對選中的照片做曝光、白平衡、色彩及局部遮罩調整。Windows 有 MSI 安裝檔與免安裝 ZIP，適合先用少量照片試用。

如果你想把照片整理交給 Agent，MCP 與 CLI 可讓它協助挑片、套用修圖設定和匯出，同時保留可撤銷的編輯紀錄。實際交付前仍要逐張檢查膚色、構圖、局部遮罩和匯出品質。專案主打本機運作，README 表示不需帳號、雲端或訂閱。

## 3. 使用情境

- **旅行或家庭照片整理**：匯入資料夾，標記精選、評分並建立相簿。
- **RAW 與 JPEG 修圖**：調整曝光、色溫、色彩、曲線、裁切和細節。
- **局部修飾**：用筆刷、線性／放射漸層或亮度與色彩範圍遮罩調整特定區域。
- **整批輸出**：複製或同步修圖設定，再依尺寸與格式批次匯出。
- **Agent 輔助流程**：透過 MCP 或 CLI 執行可重複的挑片、處理與匯出步驟。

## 4. 我要怎麼用？

1. 在 Releases 頁選 Windows x64 的 MSI 或 portable ZIP。先拿幾張可備份的 JPEG 和你相機的 RAW 檔測試，不必一開始匯入整個照片庫。
2. 開啟應用程式，匯入照片資料夾；用評分、旗標和相簿挑出要處理的照片。
3. 在編輯介面先調整曝光與白平衡，再視需要使用色彩混合、曲線、預設集、遮罩與裁切。利用前後比較確認效果，最後匯出 JPEG、PNG 或其他支援格式。
4. 想由 Agent 操作時，再依 README 與 MCP 文件設定 `lightcraft-cli`。先在測試照片庫執行少量命令並核對結果，再考慮批次處理。

專案仍在快速開發。README 指出 DNG、JPEG 與部分 Nikon／Sony／較舊 Canon RAW 的日常使用較成熟；CR3 與部分壓縮 RAW 目前可能只顯示內嵌預覽，其他相機的色彩校準也仍有限。先用你的實際相機檔案驗證顯影結果。

## 5. 值不值得研究？

**有照片整理或本機修圖需求時值得試用。** 它具備完整的圖形操作與 Agent 介面，Windows 也有現成安裝包；對想保留照片在本機的人很有吸引力。若要取代既有 Lightroom 工作流程，先確認你的 RAW 格式、色彩、匯出與大量照片庫表現是否符合要求，尤其不要只憑功能清單判斷可完全替代。
