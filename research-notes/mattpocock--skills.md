# mattpocock/skills｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/mattpocock/skills/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

面向工程工作的 Agent Skills 集合。

## 2. 對我有什麼用？

涵蓋設計、除錯、測試、溝通與工作流程。你已有 Codex Skills；可挑一兩個確實改善結果的技能，避免一次裝整包造成指令重疊。

## 3. 使用情境

先挑與目前最常見問題相符的 Skill，例如除錯或任務拆解，在同一個小任務中比較安裝前後的產出與額外步驟；保留真正有幫助的規則。

## 4. 我要怎麼用？

README 提供 plugin 與 npx skills 安裝，再建議執行 setup-matt-pocock-skills 讓技能了解 repo 慣例。先讀每個 SKILL.md 的觸發條件，於單一專案試用，確認它不會改寫既有規範。

README 建議安裝後執行 setup-matt-pocock-skills，讓技能了解專案的問題追蹤與文件慣例。對你來說先讀 Engineering 和 Productivity 類別，再只挑確實需要的一項較容易比較效果。

## 5. 值不值得研究？

很適合我，可以實際使用：你已在使用 Codex Skills，選擇性導入能直接改善工程協作。
