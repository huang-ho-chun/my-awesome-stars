# flint-chart｜研究說明

**專案**：[microsoft/flint-chart](https://github.com/microsoft/flint-chart)

## 你當時問的重點

你想知道 Flint 如何讓 AI 比直接產生圖表程式碼更穩定地做資料視覺化。

## 先前說明

Flint 位於 Agent 與圖表工具之間。Agent 描述欄位的意義、資料型態與想要的圖，Flint 再處理比例、座標軸、標籤、圖例與版面等決策。先前回答特別強調 semantic type：它希望理解數值代表溫度、價格或其他量，而不只知道它是數字。

## 對你的用處與用法

適合你的測試數據到報告流程。可取一份含 GPU、吞吐量或頻寬的 CSV，要求 Agent 畫比較圖，再核對分類、單位、刻度與原始數據。

## 使用前要核對

圖表看起來漂亮不等於解讀正確；尤其要檢查單位、聚合方式與比較基準。
