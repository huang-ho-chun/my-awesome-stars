## 1. 這是什麼？

huashu-art-motion 是讓 Coding Agent 用程式碼製作藝術動畫的 Skill。它提供 35 張藝術風格配方卡及對應場景、轉場與渲染工具，並附解說影片的動畫語法：白板、資訊拼貼、動態文字、圖表等。你可以拿自己的口播、主題或參考動畫，讓 Agent 先拆出鏡頭與節奏，再製作動畫片段。它側重「畫面中的元素真的動起來」，不是把靜態圖片排成投影片。

## 2. 對我有什麼用？

若你想把知識筆記、工具介紹或口播內容做成有辨識度的短片，這套 Skill 可提供現成的視覺語法與可修改的動畫工程。例如將一段技術解說做成白板示意，或用圖表語法呈現數據隨時間變化。它也適合研究一支動畫為什麼順暢：拆解腳本能量測轉場、節拍與動作，再由 Agent 依機制重做。製片仍需要挑素材、看成片與修正視覺錯誤。

## 3. 使用情境

- **口播配畫面**：把已有旁白搭配白板、資訊拼貼或動態文字。
- **藝術風格短片**：使用配方卡與場景程式做會動的風格畫面。
- **長卷轉場**：讓角色穿過不同畫風的場景，形成連續鏡頭。
- **參考動畫研究**：先拆出節奏與運動，再製作自己的版本。

## 4. 我要怎麼用？

1. 依 README 安裝 Skill；準備 uv、FFmpeg 與 Playwright Chromium。
2. 先看風格總覽與解說動畫示範，選一種與內容相稱的視覺語法。
3. 交給 Agent 一段短口播或單一場景需求，先產出鏡頭表與一小段預覽，而非直接做整支影片。
4. 檢查文字、構圖、動作、節奏與產生素材的使用權，修改後再渲染正式片段。
5. 若要加入自己的聲音或圖像，參考專案的可選媒體能力文件，依所用工具接入。

README 說明部分整片範例是參考程式碼快照，可能需要自備角色素材，不能假設直接執行就有完成品。

## 5. 值不值得研究？

**想持續製作解說動畫時很值得研究。** 現成風格卡、片段與拆解方法能縮短探索時間；若只需要簡單字幕加照片，這套程式動畫流程會比較費工。
