# Atlas of Physics｜GitHub 專案導覽

> 專案：https://github.com/nathanliow/atlas-of-physics

## 1. 這是什麼？

Atlas of Physics 是以互動 3D 圖解呈現 AP Physics 1 與 AP Physics C 的開源教材。每章聚焦一種物理運動或概念，以紙張質感的立體物件、墨線、向量、座標軸和圖表呈現；捲動頁面會推進章節與鏡頭，滑鼠停留可高亮物件，點擊則能把向量、圖表等內容拆解成分量、斜率或面積。

教材涵蓋運動學、牛頓力學、圓周運動、能量、動量、振盪、轉動、流體，以及 AP Physics C 的靜電、高斯定律、電位、電容、電路、磁學與電磁感應。每章還包含 AP 類型練習題、解答說明與跨章概念連結。

## 2. 對我有什麼用？

- 用可操作的 3D 物件和向量理解抽象物理概念，而不只閱讀公式與靜態圖。
- 將運動、力、能量、圖表與方程式放在同一頁面觀察其關係。
- 透過選擇題、解答與跨章比較進行 AP Physics 1 或 AP Physics C 複習。
- 參考如何把教科書內容設計成捲動敘事、互動拆解與手機友善頁面。
- 對建立教育型互動網頁的人，可作為 three.js 圖解、章節模型驗證與 UI 測試的完整案例。

## 3. 使用情境

- 學習拋體運動時，同時查看物體軌跡、速度／加速度向量和相關圖表。
- 複習牛頓力學、能量、動量或轉動等 AP Physics 1 單元。
- 複習靜電、電路、磁學與電磁感應等 AP Physics C E&M 主題。
- 課堂展示時，點開向量分量或圖表斜率，逐步說明物理意義。
- 研究互動教科書如何在桌面與手機上安排圖形、文字、練習題與深層連結。

## 4. 我要怎麼用？

1. 下載 repository 後，在根目錄執行 `python3 -m http.server 8137` 或其他靜態伺服器。
2. 開啟 `http://127.0.0.1:8137/`，從目錄選擇章節。
3. 捲動或使用左右方向鍵翻頁；將游標停在圖形上查看高亮，點擊物件可展開拆解，按 Esc 還原。
4. 在章節頁完成內建練習題，並使用跨章比較與 equation sheets 連結回到相關頁面。
5. 若要執行截圖、UI、效能或頁面檢查工具，先執行 `npm install`，並提供可用的 Chrome 路徑。

教材本身可由靜態伺服器開啟，但 three.js 會從 jsDelivr 載入，因此一般使用時仍需網路連線。專案採 MIT License；AP 是 College Board 的商標，此專案不代表獲其背書。

## 5. 值不值得研究？

值得，特別適合偏好視覺化與操作式學習的人。它把多個 AP Physics 章節、互動圖解、練習、方程式索引與跨章類比整合成一致介面，比單一概念示範更接近完整教材。

如果目標只是快速查公式，傳統筆記可能更省時間；若想真正理解向量、圖表和物體運動如何互相對應，這種可拆解 3D 教材更有價值。建議先選一個熟悉章節測試互動與練習，再決定是否拿它作為長期複習或教學輔助工具。
