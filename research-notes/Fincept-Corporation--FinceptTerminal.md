# Fincept Terminal｜GitHub 專案導覽

> 依 [專案 README](https://github.com/Fincept-Corporation/FinceptTerminal) 於 2026-09-16 整理；著重用途與使用判斷。

## 1. 這是什麼？

Fincept Terminal 是提供市場資料、研究與分析介面的桌面金融終端。README 區分開源版本與另外的 Enterprise 服務；兩者功能和資料權限不相同。它較接近投資研究工作台，不是單純的個人記帳軟體，也不保證資料和分析適合任何市場或投資目的。

## 2. 對我有什麼用？

如果你之後要比較不同金融市場的資料來源與研究工具，可用開源版本觀察介面與工作流程。你目前沒有明確的量化研究或交易需求，為了它而投入資料服務或付費方案可能太早。

## 3. 使用情境

- **市場資訊瀏覽**：檢查自己關心的標的、新聞或指標是否在開源版提供。
- **研究工具比較**：與既有資料來源比對數值、延遲和可追溯性。
- **團隊研究**：只有在確認 Enterprise 功能和費用後再評估。

## 4. 我要怎麼用？

1. 從 README 的 Install 區選自己的平台；Windows 有發行版安裝程式，開源版可直接先試。
2. 用非敏感的示例或公開市場資料，走一次查詢和分析流程。
3. 核對資料授權、來源、時區及開源版可用功能；若要連接帳戶或交易服務，再另行審查權限。

## 5. 值不值得研究？

**可以先收藏，以後可能用到。** 它的主要價值在持續的市場研究；目前對你更重要的是先確定問題和資料需求。
