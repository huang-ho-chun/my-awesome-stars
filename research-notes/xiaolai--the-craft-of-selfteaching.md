## 1. 這是什麼？

這是李笑來《自學是門手藝》的早期 Repository，以 Jupyter Notebook 編排內容，從自學觀念、閱讀方法與刻意練習開始，再透過 Python 的值、流程控制、函式、容器、檔案、測試、類別和正則表達式等題材練習自學。

README 另指向 `selfteaching/the-craft-of-selfteaching` 的 Markdown 版本。你的收藏中已經有那個新版倉庫，因此兩者內容高度重疊；這一份的主要差別是 Notebook 閱讀與實作形式。

## 2. 對我有什麼用？

它不是只教 Python 語法，而是把「閱讀不懂的材料、處理過早出現的概念、動手產出、刻意練習」放進實際學習過程。當你想建立自主學習習慣，或想藉程式設計練習如何拆問題時，可以按章閱讀並完成 Notebook。

你已收藏 Markdown 版本，若閱讀文字與整理筆記是主要目的，保留其中一個版本即可；若想直接執行範例和練習，Notebook 版本才有額外價值。

## 3. 使用情境

- 初學 Python，同時練習如何自行查資料和解決卡點。
- 對「知道」和「能做出來」之間的差距進行刻意練習。
- 用 Jupyter Notebook 邊讀、邊執行、邊寫自己的答案。
- 重新檢查目前學習流程是否有產出、回饋和重複練習。

## 4. 我要怎麼用？

先讀 README 指定的 Jupyter 安裝附錄，準備 JupyterLab，再從前言和自學方法依序閱讀。每遇到程式章節就自己執行、修改範例並留下結果，不要只滑過文字。若不想安裝環境，改讀已收藏的 Markdown 版本會更簡單。

建議先比較兩個 Repository 的目錄和閱讀體驗，選一個當主版本，另一個只作備用，避免重複維護兩套筆記。

## 5. 值不值得研究？

**可以先收藏，以後可能用到。** 內容本身值得讀，但你已有同書的 Markdown Repository；除非需要 Notebook 互動練習，沒有必要把兩份都完整研究一次。
