# book-to-skill｜研究說明

> 依先前對話重整的研究筆記，非逐字稿。專案功能可能隨版本改變。

**專案**：[virgiliojr94/book-to-skill](https://github.com/virgiliojr94/book-to-skill)

## 你當時問的重點

你想知道如何把技術書或文件變成 Agent 長期可用的知識，而不只是做一次摘要。

## 先前說明

book-to-skill 將 PDF、EPUB、DOCX、Markdown 或文件目錄整理成 Agent Skill。核心指引放在 `SKILL.md`，章節、術語與速查資料分開保存，讓 Agent 只在需要時讀相關部分。先前討論將它視為「建立可查閱的結構」，而非單篇讀書摘要。

## 對你的用處與用法

可先選一本常查的 Linux、系統效能或軟體架構資料，轉成一個 Skill，再用你工作上會問的問題測試：能否找到正確章節、保留原書脈絡、回答可回查。

## 使用前要核對

轉換結果需要抽查章節對應、專有名詞與來源；原書若受授權限制，也要依原有使用條件處理。
