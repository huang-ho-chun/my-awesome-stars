# 30u30｜GitHub 專案導覽

> 來源：[Ojhaharsh/30u30](https://github.com/Ojhaharsh/30u30) README；查閱日期：2026-10-19。

## 1. 這是什麼？

30u30 是一份以 **30 篇基礎 AI 論文**為主軸的自學教材。專案把論文按主題安排成 30 天，提供解說、程式實作、Notebook、練習與解答，範圍從早期神經網路到 Transformer、生成模型及強化學習。它比較像有練習題的讀書路線，不是能直接解決日常工作的 AI 工具。

## 2. 對我有什麼用？

如果你想了解「模型為什麼能做現在這些事」，而不只會用 Agent 或現成 API，這份教材讓你按順序接觸經典觀念。你可以只挑 Transformer 或感興趣的主題，透過 README 與 Notebook 補足概念，再決定是否做完整實作。

若你的當前目標是快速篩選 GitHub 工具、改善 Codex 工作流程，完整 30 天挑戰的投入相對高；先挑與手上問題相關的一兩篇會更實際。

## 3. 使用情境

- **AI 初學者**：按 Day 1 起順序閱讀，逐步建立基本概念。
- **有 Python 基礎的開發者**：跑 Notebook、完成練習，檢查自己能否解釋模型行為。
- **已有主題的學習者**：跳到特定論文，用筆記與程式對照理解。

## 4. 我要怎麼用？

先在 GitHub 看總目錄，挑一篇感興趣的論文；閱讀該日 README 與筆記，再開對應 Notebook 或實作、做練習、對照解答。README 建議基本 Python 能力；完整挑戰是一日一篇，也可以按自己的時間放慢。若要在本機執行，就 clone 此 repo 並依各篇的程式需求準備環境；只閱讀內容可直接從網頁開始。

官方提出三條路徑：先理論、先程式，或先練習。你可從「先 README，再看 Notebook」開始，避免一口氣承諾完成全部 30 篇。

## 5. 值不值得研究？

**有學習 AI 原理的目標時值得研究。** 對日常工具選型的直接幫助較少；想補理論時，這是容易開始、又能逐步深入的收藏。
