# Wenyi｜GitHub 專案導覽

> 依 [專案 README](https://github.com/BigDawnGhost/wenyi) 於 2026-09-16 整理；著重用途與使用判斷。

## 1. 這是什麼？

Wenyi 是為書籍與長篇文字設計的 AI 翻譯工作流程。它先建立整本書與章節脈絡，翻譯時維護術語表，之後可進行潤飾與對照原文的複查；支援中斷續跑與多種模型服務。它是 Python 命令列工具，目標在長文一致性，不是貼一段文字即翻即走的網頁翻譯器。

## 2. 對我有什麼用？

若你要閱讀外文長篇技術資料或整理自己有權處理的文本，它可比逐章丟進聊天視窗更容易維持術語一致。對日常短篇 GitHub README，普通翻譯工具已夠；這套流程只有在一本書或長系列文件時才值得設置。

## 3. 使用情境

- **長篇閱讀**：把可使用的 EPUB／文字資料轉成一致的譯稿。
- **術語密集文件**：用詞彙表統一名稱和關鍵概念。
- **分段審閱**：先翻譯、再對照原文與最終術語表複查。

## 4. 我要怎麼用？

1. 依 Quick Start 準備 Python 3.10+ 與 `uv`，下載專案並完成設定。
2. 選擇模型供應商與來源文件，先用一小段測試解析、翻譯和術語表。
3. 確認譯文風格與專有名詞後處理全書；利用進度保存續跑，最後人工抽查重要段落。

## 5. 值不值得研究？

**有特定情境才有用。** 當你確實要處理長篇文本時有價值；短文或一次性資料不需要這套管線。
