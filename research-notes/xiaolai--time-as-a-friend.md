# 把時間當作朋友（xiaolai/time-as-a-friend）

資料來源：[官方 README](https://github.com/xiaolai/time-as-a-friend/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

李笑來《把時間當作朋友》的開放閱讀倉庫。README 將重點放在思考能力、接受現實、長期累積與成長，正文以章節 Markdown 呈現。它屬觀念與行動方式的讀物，沒有安裝需求，也沒有可直接替你排程或追蹤時間的工具。

## 2. 對我有什麼用？

你重視可持續工時、家庭時間與長期能力，因此可以用書中「累積」的角度檢視自己是否把時間放在可持續的技能與關係上。書中的強烈論述應當作作者觀點，而非直接套到你生活的標準；尤其你已有明確的休息、家庭與工作邊界，不能用持續努力的口號壓過它們。

## 3. 使用情境

例如評估一個新職務時，可記錄每週投入、是否影響可支配時間、能否累積可轉移技能，再用一個月後的實際感受核對。讀這本書的價值是幫你提出更好的問題，不是讓你接受某套固定日程。

## 4. 我要怎麼用？

在 README 的閱讀說明後，按章節連結從頭閱讀，或挑與當前問題相關的章節。每章記錄一個你認同、一個你保留的觀點，再把可驗證的行動寫入 Obsidian，隔一段時間回看。這是文字教材，不需要執行任何程式；產出可以是一份自己的取捨準則。

## 5. 值不值得研究？

可以先收藏，以後可能用到：在重新檢視工作與生活安排時可參考，但目前無須為它安排整本通讀。
