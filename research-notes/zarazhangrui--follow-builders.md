# Follow Builders｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/zarazhangrui/follow-builders/blob/main/README.md)；查閱日期：2026-09-28。

## 1. 這是什麼？

Follow Builders 是給 Agent 安裝的資訊摘要 Skill，集中追蹤 AI 建構者在 X 的公開貼文、AI 播客與官方技術部落格，再產生每日或每週摘要。它可輸出英文、中文或雙語，並支援在聊天中查看或配送到訊息管道。
內容由集中來源抓取，使用者本機主要保存排程、語言、配送偏好與閱讀狀態。

## 2. 對我有什麼用？

你可以用它降低主動追蹤 AI 新聞的時間，把較偏實作、產品與工程觀點的來源整理成固定摘要。這個專案已符合你想以繁體中文、固定時段、在 Codex 內按需閱讀的需求。
它的來源是專案預先挑選的名單，適合當訊號入口；重要消息仍應開啟原始連結核對，避免只靠摘要做決策。

## 3. 使用情境

- 每日摘要：快速掌握 AI 工程師、研究者與創辦人的新觀點。
- 每週回顧：把一週內容壓縮成較低干擾的閱讀清單。
- 主題追蹤：調整來源或摘要提示，偏重 Agent、產品或研究。
- 聊天內查閱：不設定 Telegram 或 email，直接在支援的 Agent 中取得摘要。

## 4. 我要怎麼用？

1. 把專案的 Skill 安裝到支援的 Agent；README 提供 OpenClaw 與 Claude Code 安裝方式。
2. 呼叫 `/follow-builders` 或要求 Agent 設定 Follow Builders，選擇頻率、時間、語言與配送方式。
3. 先用聊天內輸出測試摘要品質，再決定是否設定外部訊息服務。
4. 之後可用自然語言修改頻率、語言或來源。若啟用 Telegram／email，相關憑證依文件保存在本機設定檔。

## 5. 值不值得研究？

**很適合你持續追蹤 AI 建構者。** 它能節省蒐集時間，而且可直接在聊天中使用。建議維持繁體中文、固定時區與低干擾頻率，並保留原文連結供需要時查證。
