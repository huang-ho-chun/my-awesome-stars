# Phasyn Studio｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/phasyn/phasyn-studio/blob/HEAD/README.md)；查閱日期：2026-11-20。

## 1. 這是什麼？

Phasyn Studio 是在自己的電腦上執行的 AI 影片製作工作室。它能以文字描述生成帶聲音的短片、以自有圖片、片段或聲音作為參考、生成與編修圖片，並在時間軸排列鏡頭、剪輯、加入轉場、文字、字幕及音樂後輸出影片。介面支援英文、繁體中文與日文。

## 2. 對我有什麼用？

若希望影片素材與生成流程留在本機，並已有符合需求的 NVIDIA GPU，可用它把「生成單一片段」延伸成選 take、排鏡頭與完成輸出的工作流程。它也適合比較同一鏡頭的不同生成結果，再把選定片段接成短片；代價是模型、顯示記憶體、系統記憶體與磁碟空間需求較高。

## 3. 使用情境

- 為短篇故事或概念影片生成數個鏡頭並比較不同 take。
- 將自有圖片、影片及聲音作為參考，製作一致性較高的片段。
- 在本機時間軸修剪鏡頭、加入字幕與音樂，再輸出成片。
- 先以圖片工作區測試角色或場景，再決定是否投入影片生成。

## 4. 我要怎麼用？

README 要求 Linux、支援 CUDA 13.0 驅動的 NVIDIA GPU，以及充足記憶體與磁碟；已測試 RTX 3060、RTX 5080 與 DGX Spark，其他 RTX 30、40、50 系列未保證。先 clone repository，執行 `./install.sh --dry-run` 查看硬體配置、模型與授權計畫，確認後再執行 `./install.sh`。正式生成前先用短鏡頭測量速度、記憶體占用與輸出品質。

## 5. 值不值得研究？

若已有 Linux NVIDIA 工作站，並想在本機完成 AI 生成與基本剪輯，值得用小型短片試驗。若主要使用 Windows、沒有 NVIDIA GPU，或只需要一般時間軸剪輯，它目前的硬體與安裝條件會比現成剪輯器更高，應先看 dry-run 計畫再決定。
