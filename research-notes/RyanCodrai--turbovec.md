# turbovec｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/RyanCodrai/turbovec/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

Rust 製作的向量索引，提供 Python 綁定，依 TurboQuant 演算法壓縮向量並支援逐批加入、搜尋、存檔與按 ID 篩選。它是 RAG 的索引元件，不會負責產生 embedding、解析文件或回答問題。

## 2. 對我有什麼用？

如果你日後建立大量本機語意索引，又遇到記憶體或查詢速度瓶頸，可把它接到 Python 管線比較。README 的速度和壓縮結果屬特定測試條件，應使用自己的資料驗證。

## 3. 使用情境

用一批已去識別的筆記段落產生向量，與現有索引比較記憶體、檢索品質、增量寫入及刪除後結果。特別檢查來源 ID 能否穩定回連原檔。

## 4. 我要怎麼用？

先 `pip install turbovec`，在 Python 建 `TurboQuantIndex` 或需穩定 ID 時用 `IdMapIndex`；加入 `float32` 向量、`search()` 查詢、`write()` 或 `sync()` 保存。另需自行選 embedding 模型與存放原文，避免把索引視為完整知識庫。

## 5. 值不值得研究？

若實測，應固定同一批向量、查詢與 `k` 值，比較檢索命中、延遲、記憶體、索引檔大小；還要確認增量寫入與刪除後的來源 ID。只有你的資料規模真的造成資源壓力時，替換索引才可能抵過整合成本。

**可以先收藏，以後可能用到。**目前沒有明確大規模向量索引瓶頸，不必先換底層元件。
