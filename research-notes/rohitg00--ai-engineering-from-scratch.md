# AI Engineering from Scratch（rohitg00/ai-engineering-from-scratch）

資料來源：[官方 README](https://github.com/rohitg00/ai-engineering-from-scratch/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

這是一套範圍很大的 AI 工程自學課程，README 將數學、機器學習、深度學習、LLM、Agent 和部署等主題分階段安排，並以每課的實作產物或證據檢查學習。它同時提供網站閱讀、Git 倉庫內容與可安裝給 Agent 的學習 Skill；不是單一函式庫或速成班。

## 2. 對我有什麼用？

你已有 Python、自動化和實際客戶問題經驗，可跳過一些初階程式課，挑模型評估、資料管線、Agent 工程等單元補足技術廣度。README 的課程規模非常大，若照表全部完成會占去許多時間；要以近期可用的技能為軸，避免把「可學項目多」誤認為「都值得現在學」。

## 3. 使用情境

例如想替測試報告加入可解釋的異常摘要，可先選資料管理、模型評估或 LLM 評估相關課，照課程產出一份小型實驗紀錄，再判斷是否真的改善原流程。若任務只需固定規則統計，用你熟悉的 Shell／Python 腳本更直接，不必引進模型。

## 4. 我要怎麼用？

先使用 README 的 Start here 表格，依目前程度選起點；每課按固定結構讀概念、動手執行並留下驗證產物。可在線上網站閱讀；要本機跟做則 clone 倉庫，依 Phase 0 前置條件準備 Python 等工具。另有 `npx skills add rohitg00/ai-engineering-from-scratch` 作為 Agent 學習入口，這與直接讀課程或執行範例是不同路徑。

## 5. 值不值得研究？

有特定情境才有用：當你決定補 AI 工程能力時可作課程地圖，但目前應先挑與工作直接相連的一兩課。
