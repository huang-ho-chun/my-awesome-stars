# mg-styles-15

> 專案：[Vincentwei1021/mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是動態設計作品集與可重用範例庫，收錄 15 支各 10 秒的不同風格影片。每支都提供風格說明、提示詞和完整來源，畫面主要由 SVG、Canvas、WebGL、Three.js 或 Blender 等程式工具製作。

## 2. 對我有什麼用？

你可以先看畫廊選喜歡的動畫語言，再複用提示詞讓 Agent 產生相似的解說或產品動畫。它適合作為視覺參考，不能期待打開後直接輸入一句話就自動出片。

## 3. 使用情境

適合找短片風格、研究動效構圖、建立系列視覺參考；也可比較同一內容換不同風格的感覺。

## 4. 我要怎麼用？

先在線上畫廊看 15 支影片，選一支閱讀對應 prompt、style notes 與 demo source。若想自己輸出，再依 README 的 Run the source 流程安裝與渲染；只取靈感則不必部署。

## 5. 值不值得研究？

可以先收藏，而且值得先看畫廊；要製片時再選一個範例深入。
