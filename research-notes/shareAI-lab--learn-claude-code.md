# 從零理解 Claude Code Harness（shareAI-lab/learn-claude-code）

資料來源：[官方 README](https://github.com/shareAI-lab/learn-claude-code/blob/HEAD/README.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

以逐課實作方式拆解 Coding Agent 的執行環境：工具、知識、觀察、權限、上下文壓縮、子任務和工作流程。README 強調模型與 harness 共同構成可用的 Agent 產品，並列出逐步增加能力的課程。雖以 Claude Code 為例，許多觀念可跨到 Codex；它不是 Codex 官方教材。

## 2. 對我有什麼用？

你常與 Codex 協作，這套材料有助於理解為何明確的工具邊界、資訊載入和結果回讀比堆疊提示詞更重要。對自動化測試、伺服器設定與報告管線，可借用其中的觀察與權限設計，讓 Agent 每一步都有可檢查的外部結果；但不應把其特定 Claude API 程式直接視為 Codex 設定方法。

## 3. 使用情境

例如你想讓 Agent 批次修改測試設定，可先讀最基本的工具循環，再閱讀權限與工作樹相關課程，對照現有流程列出讀取、寫入、審核與回滾。用單一可撤銷案例檢查是否能在出錯時停下，而不是先建整套多 Agent 系統。

## 4. 我要怎麼用？

先從 README 的課程順序與核心 agent loop 入手，按單課說明準備 Python／模型 API 與相依套件，再在各課的獨立實作中執行、觀察工具呼叫和輸出。此倉庫含多個漸進版本；應按所選課的 README 操作，避免把不同階段的命令混用。也可先只閱讀示例程式，無需立即配置付費 API。

## 5. 值不值得研究？

有特定情境才有用：對你理解 Codex 工作方式與設計可靠自動化很有幫助。實作部分屬額外工程學習，先讀工具與權限階段即可。
