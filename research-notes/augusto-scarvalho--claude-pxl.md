# claude-pxl

> 專案：[augusto-scarvalho/claude-pxl](https://github.com/augusto-scarvalho/claude-pxl)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是把像素圖、場景及動畫寫成程式描述的工具。CLI 可將 `.px.js` 檔輸出成 PNG、sprite sheet、GIF 等素材，也可讓 Coding Agent 修改並檢視結果。

## 2. 對我有什麼用？

你可以用它製作網站或遊戲的像素插畫、角色素材與小動畫，保留可重複調整的來源檔。若你偏好手繪即時塗改，程式化流程未必更快。

## 3. 使用情境

適合有固定尺寸、配色或系列化需求的像素素材；也適合讓 Agent 按文字需求迭代畫面。

## 4. 我要怎麼用？

先看範例畫廊與文件，安裝 Node.js 後用 README 的 npx 指令建立或渲染 `.px.js` 檔。可先在本機 viewer 預覽，再輸出圖片或動畫；若要交給 Agent，依 `docs/agents.md` 安裝 Skill。

## 5. 值不值得研究？

有特定情境才有用。當你需要可重製的像素風素材時值得實際試用。
