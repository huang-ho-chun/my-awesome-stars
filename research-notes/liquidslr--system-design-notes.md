# System Design Interview 筆記（liquidslr/system-design-notes）

資料來源：[官方 README](https://github.com/liquidslr/system-design-notes/blob/HEAD/Readme.md)；查閱日期：2026-09-16。

## 1. 這是什麼？

以《System Design Interview》卷一、卷二為基礎的非官方筆記倉庫。README 列出從容量估算、限流、一致性雜湊、鍵值儲存，到聊天、搜尋、訊息佇列、監控、支付等系統設計題目，並標示筆記仍在編寫中。它是章節索引與外部參考集合，不是可部署的系統架構樣板。

## 2. 對我有什麼用？

你處理伺服器設定與報告流程時，容量、故障、佇列與監控的思考方式可直接借用。若只是管理單機腳本，複雜分散式設計可能過度；可在有擴充、可靠性或面試準備需求時，挑問題閱讀並以自己的負載和限制重新推導。

## 3. 使用情境

例如你有多個客戶的測試報告要定時生成，可借「訊息佇列」與「監控」題目思考：任務失敗會否重跑、重跑是否重複寄出、如何知道積壓、最慢可接受多久。即使最後仍用簡單腳本，這些問題也能改善驗收與例外處理。

## 4. 我要怎麼用？

直接在 GitHub `Readme.md` 目錄點題目資料夾，或開 README 指向的線上筆記站；選一題先閱讀，再畫出自己的需求、數量估算與折衷。遇到原理細節，查看 README 的延伸參考，並回查原始資料。沒有安裝步驟或統一執行結果；成果是可討論的設計草圖與假設。

## 5. 值不值得研究？

有特定情境才有用：面試或處理規模化問題時可查；日常小型自動化不需要系統性研讀全部題目。
