# Awesome Opus 5.5 Videos｜GitHub 專案導覽

> 來源：[專案 README](https://github.com/yihui-dev/awesome-opus5-5-videos/blob/main/README.md)；查閱日期：2026-10-02。

## 1. 這是什麼？

Awesome Opus 5.5 Videos 是一份持續更新的影片案例與提示詞收藏，整理使用 Claude Opus 5.5 生成的動態圖形、解說動畫、3D 場景、遊戲與互動作品。每個項目通常會連到原作者貼文、預覽或重製頁面，以及專案內保存的提示詞檔案。

這個倉庫本身不是影片生成器。它更像案例索引與提示詞資料庫：使用者挑選喜歡的作品，閱讀作者公開的提示詞，再讓支援 Opus 5.5 的工具產生單一 HTML 頁面，最後自行錄製頁面成影片。部分作者只公開部分提示或成果描述，對應檔案會標示資料不完整。

## 2. 對我有什麼用？

你可以用它快速觀察 AI 以 HTML、Canvas、SVG、GSAP 或 Three.js 製作視覺內容時常見的提示方式，找出適合簡報、教學、社群短片或互動展示的表現形式。相較只看成品，它保留了提示詞，能幫助你理解畫面結構、動作、節奏和技術選擇如何被描述。

對你來說，最實用的做法是把案例當作靈感與拆解材料，再依自己的主題重寫內容和視覺規則。提示詞並不保證在不同模型、工具或時間點重現完全相同的結果，也不應直接複製作者的品牌、素材或受保護內容。

## 3. 使用情境

- **動態簡報靈感**：參考文字進場、圖表動畫和段落轉場。
- **教學解說影片**：研究如何把抽象概念拆成連續的視覺步驟。
- **互動展示原型**：查看 Canvas、SVG、Three.js 或 GSAP 的生成案例。
- **提示詞學習**：比較不同作者如何指定構圖、風格、鏡頭與動態。
- **模型能力評估**：用同一類提示測試模型是否能穩定產生可執行的 HTML。

## 4. 我要怎麼用？

1. 從 README 的 Motion graphics、Explainers、3D scenes 或 Games & interactive 分類挑選案例。
2. 打開對應提示詞檔案，先確認它是完整提示、部分提示，還是只有結果描述。
3. 將提示貼到 Claude Opus 5.5、Claude Code 或其他執行該模型的 Agent，要求輸出單一 HTML 檔案。
4. 在隔離或可檢查的環境開啟產生的 HTML，確認外部資源、效能、版面與互動行為，再錄製成影片。
5. 需要公開或商用時，替換原案例的文字、圖片、品牌和音樂，並確認素材與原作者授權。

## 5. 值不值得研究？

**適合收藏作為視覺案例與提示詞參考。** 如果你想做動態解說、互動頁面或 AI 生成影片，這份清單能快速提供方向；但它不提供一鍵完成的製作流程，最終仍需檢查產生的 HTML、錄影與後製。建議挑 3 至 5 個最接近需求的案例實驗，不必完整研究整個清單。
