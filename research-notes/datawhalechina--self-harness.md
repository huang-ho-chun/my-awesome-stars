# self-harness｜GitHub 專案導覽

> 依 [專案 README](https://github.com/datawhalechina/self-harness) 於 2026-09-16 整理；著重用途與使用判斷。

## 1. 這是什麼？

self-harness 是中文的 AI Agent 工作環境實戰指南，從提示詞工程、上下文工程談到長時間任務的 Harness Engineering，並用 miniMaster 專案展示工具、工作記憶與驗證閉環。README 標示 Alpha 內測，適合拿來學觀念和做練習，不宜預設範例已可直接搬進正式流程。

## 2. 對我有什麼用？

你希望 Codex 逐步掌握專案規範，又不想讓小任務背負過重流程。這份教材可幫你區分：哪些問題用更清楚的請求即可，哪些需要文件、工具或持續的進度記錄。miniMaster 也可作為比較自己 AI 工作方式的具體例子。

## 3. 使用情境

- **學習路線**：按章理解提示詞、上下文與 Harness 的差異。
- **小型練習**：看 miniMaster 如何把工具與驗證接起來。
- **回顧現有工作流**：將學到的概念套在真實 Codex 任務上比較。

## 4. 我要怎麼用？

1. 從 README 連結的線上版讀總覽和目錄，先選一個你目前最常遇到的問題。
2. 跟做與該問題對應的章節或 miniMaster 範例，不必一次通讀全部。
3. 記下修改前後的實際差異；因為專案仍在內測，重要方法應用自己的任務再驗證。

## 5. 值不值得研究？

**有特定情境才有用。** 你想系統學 Agent 工程時值得讀；日常已有成熟工作法時不必全部照搬。
