# HyperFrames

> 專案：[heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)｜依據：專案 README（2026-10-28 查閱）

## 1. 這是什麼？

這是以 HTML/CSS/網頁元件描述影片的框架，讓 Coding Agent 產生畫面，再預覽並渲染成影片。它包含 CLI、元件與 Agent Skills，偏向可程式控制的影片製作。

## 2. 對我有什麼用？

你可以把文件、簡報或產品畫面轉成可修改的動態影片。熟悉網頁技術或常用 Coding Agent 時，能把版面與動畫保留為可維護的來源。

## 3. 使用情境

適合產品介紹、資料視覺化片段與需要多次更新的模板化影片。不適合以剪輯既有長影片為主要工作。

## 4. 我要怎麼用？

先安裝 Node.js 22+，依 README 用 `npx hyperframes skills update` 安裝核心 Skills，再讓 Codex/Claude 等 Agent 建立一段短片。確認 HTML 預覽、素材與節奏後使用 CLI 渲染；也可先閱讀官方 quickstart。

## 5. 值不值得研究？

很適合你探索 Agent 製片與可重用模板，但先做 5–10 秒樣本即可判斷是否值得納入流程。
