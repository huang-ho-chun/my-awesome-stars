# Niamos｜GitHub 專案導覽

> 依 [專案 README](https://github.com/pricklywiggles/niamos) 於 2026-09-16 整理；著重用途與使用判斷。

## 1. 這是什麼？

Niamos 是作者公開的 Obsidian vault **組織系統**：包含改造過的 PARA 分類、範本、Bases／Dataview 查詢、儀表板與 Claude Code Skills。個人的目標、專案和日記內容被排除在 repo 外；公開的是運作規則。它不是單一功能的小工具，也不是把它複製進現有庫就會自動完成整理。

## 2. 對我有什麼用？

你已有自己的 Obsidian vault，並重視保留原筆記與歷史結構。Niamos 可供你參考「目標、領域、專案與日記如何連結」以及 Agent 如何建立／歸檔頁面；但整套分類有作者的偏好，不應直接覆蓋你現有資料。

## 3. 使用情境

- **庫結構參考**：比較自己的目錄與它的內容生命週期。
- **模板研究**：觀察不同筆記類型的 frontmatter 和視圖。
- **Agent 工作流**：參考 create-page、archive、audit 等 Skills 的分工。

## 4. 我要怎麼用？

1. 先在獨立資料夾複製 repo，作為**新測試庫**打開，不對現有 vault 動手。
2. 按 README 安裝所需 Obsidian 社群外掛，閱讀 `wiki/system/manual/` 的規則和範本。
3. 建立幾篇測試筆記，看導覽、Bases 和 Skills 如何配合；只挑真正解決你問題的部分手動移植。

## 5. 值不值得研究？

**有特定情境才有用。** 你想調整 Obsidian 結構時很值得看；整套採用可能與既有分類和習慣衝突。
